## 解决什么问题

代数与方程一次只解一个未知数，可日子撞上的题往往是"几个未知数、几条条件同时成立"：三亩地分给三家、三种粮配成一份饲料、三个人干一天的活该各记多少工——**几个数一起定，条件互相咬**。线性代数给的就是这套"多未知数联立"的通用套路。本篇回答四件事：

- **向量**：把几个数捆成一捆一起搬，这捆东西加减乘数的规矩；
- **矩阵**：把多未知数的系数排成一张表，整表地算；
- **线性方程组**：几张条件同时满足，怎么解、怎么判断有没有解、有几个解；
- **行列式与特征值**：一张表的"总缩放倍数"，以及哪些方向算起来最省。

读完本篇你能做到：把"几件事一起定"的题排成表、用消元法解出全部未知数、判断解是唯一还是无穷还是没有，并知道每一步的误差与限制出在哪。

前置与分工：四则与配比见[数与算术](02_numbers_arithmetic.md)；解一次方程见[代数与方程](04_algebra_equations.md)；函数与图像见[函数与三角](26_functions_trigonometry.md)；本篇管"多未知数联立"，后续应用散见各技术领域。

## 核心知识与原理

### 向量：把几个数捆成一捆一起搬

零基础定义：**向量**就是一列排好的数，通常竖着写，叫它"一个量的几个分量"。例如一块田的"长 30 步、宽 20 步、深 1 尺"可以捆成一个向量 (30, 20, 1)——**向量只是把几个数钉在一起，本身不神秘**。（来源：Wikipedia "Linear algebra"，Vector spaces 节——向量空间的元素可为元组、序列、函数、多项式、矩阵等，线性代数研究它们共有的性质。）

**向量的两种运算**（来源同上，向量空间公理表）：
- **加法**：两捆对应的数分别相加——(30,20,1)+(5,3,2)=(35,23,3)。意义：两块田并起来。
- **数乘**：一个数乘进每一格——2×(30,20,1)=(60,40,2)。意义：整块放大到两倍。

**零向量**：每一格都是 0 的那捆，加它不动——(0,0,0)。它好比"没分到东西"。

### 线性组合、无关与基：搭积木的三句话

**线性组合**：把几捆向量各自乘个数再加起来——a₁v₁+a₂v₂+⋯+aₖvₖ。意义：用几样基本材料配出一个新东西。

**线性无关**：一捆向量里，**没有哪一捆能由其余的配出来**，就叫它们线性无关。判断土法：把它们排成表，逐个看——新加入的那一捆能不能由前面的配出？能，就是多余的。

**基**：一组"又够用、又不啰嗦"的向量——**能配出整个空间的一切向量（张成），同时彼此之间没有多余的（无关）**。（来源：Wikipedia "Linear algebra"，basis 节——基是同时为极小生成集与极大无关集的集合；任何两个基的元素个数相同，这个数就是空间的**维数**。）三维空间的一个基就是三根互相垂直的单位杆——任何位置都能用"走多少、走多远、爬多高"三个数表示。

### 矩阵：把系数排成一张表

**矩阵**就是一张数表， rows 是行、columns 是列。（来源：Wikipedia "Linear algebra"，Matrices 节——矩阵用来显式操作有限维向量空间与线性映射；"matrix"一词由 Sylvester 于 1848 年引入，拉丁文意为"子宫"。）

一张 m 行 n 列的矩阵，把一个 n 维向量变成一个 m 维向量。**矩阵乘法**的规矩：结果表第 i 行第 j 列的数，等于左表第 i 行与右表第 j 列"对乘再加"。（来源同上——两矩阵的积等于对应线性映射的复合；矩阵与列向量的积等于把该线性映射作用到那个向量上。）算例：两表相乘时，左边一行的三个数分别乘右边一列的三个数，再加起来，得一个数。

**矩阵加法**：对应格相加。**数乘**：每个格乘同一个数。

### 线性方程组：几张条件同时满足

几个未知数、几张条件，写成**线性方程组**。（来源：Wikipedia "Linear algebra"，Linear systems 节——线性方程组是线性代数的根本部分，历史上线性代数与矩阵理论就是为解这类系统发展起来的。）

把系数排成矩阵 A，未知数排成列向量 X，等号右边排成列向量 b，整个系统写成一句话：

**AX = b**

算例（来源同页的三元例）：2x+y−z=8、−3x−y+2z=−11、−2x+y+2z=−3，系数矩阵 A=[[2,1,−1],[−3,−1,2],[−2,1,2]]，右端 b=(8,−11,−3)，解就是满足 AX=b 的 X=(x,y,z)。（该例的解为 x=2、y=3、z=−1，代回验算：2×2+3−(−1)=8 ✓、−6−3−2=−11 ✓、−4+3−2=−3 ✓。）

### 消元法：一张表的土法解算

**高斯消元法**是解线性方程组最直接的套路：把系数矩阵通过"行操作"逐行化简，直到每行只剩下一个未知数。（来源：Wikipedia "Linear algebra"，Linear systems 节与 Matrices 节——Gaussian elimination 是找这些初等操作的基本算法；行操作对应基变换。）历史出处：**同一算法用算筹解联立方程，见于中国古籍《九章算术》第八章"方程"**，是现存最早的消元法记载。（来源同上 History 节——该程序以算筹解联立线性方程，今称 Gaussian elimination，见于《九章算术》"方程"章，含 2～5 个方程的 18 道例题。）

**行操作三类**（只做这三类，方程组的解不变）：
1. 互换两行；
2. 一行乘以一个非零数；
3. 把一行的倍数加到另一行。

**土法流程**：先用第一行把下面各行第一个数消成 0；再用第二行把下面各行第二个数消成 0；依此类推，最后从下往上逐行回代，每个未知数依次定出来。

**三种结果**：
- 化简后每行都剩一个未知数且不矛盾 → **唯一解**；
- 化简后出现"0=非零" → **无解**；
- 化简后出现全零行（0=0），未知数比方程多 → **无穷多解**（解中带自由参数）。

### 消元法的手工细节与土法替代

高斯消元法在沙盘上操作时，有几处细节最容易出错，先钉死：

**主元为 0 时必须换行**。消第 i 列时，如果第 i 行第 i 列是 0，不能拿它当主元去消下面（会除以 0）。土法：在它下面找第一个非零的行，整行互换，再继续。这就是"行操作第一类：互换两行"的用武之地。

**化简目标：行阶梯形**。消完后，每行第一个非零数（主元）依次右移，像台阶一样。这时从最后一行往上回代：最后一行只剩一个未知数，直接定出来；倒数第二行代入已知的，再定一个；依此类推。

**土法替代：代入法**。两三个未知数的小系统，直接从第一条方程把一个未知数用其余表示，代进第二、第三条——这就是消元法的算术版，沙盘上更直观：先解出 x，把 x 的表达式抄到另外两行里，再解剩下的。两未知数的系统用代入法比摆表更快。

**验算的硬规矩**：解出全部未知数后，**逐条代回原方程组的每一条**，全部成立才算解完。消元过程中任何一步抄错、算错，代回立刻暴露——这一步不能省。

### 矩阵运算的实用算法（乘法、单位阵、转置）

矩阵的加减数乘简单（对应格相加、每格乘同一数），真正需要练的是**矩阵乘法**。规矩：结果表第 i 行第 j 列的数 = 左表第 i 行与右表第 j 列"对乘再加"。

**算例**：A=[[1,2],[3,4]]，B=[[2,0],[1,3]]，则 A·B 的第 1 行第 1 列 = 1×2+2×1 = 4；第 1 行第 2 列 = 1×0+2×3 = 6；第 2 行第 1 列 = 3×2+4×1 = 10；第 2 行第 2 列 = 3×0+4×3 = 12。结果 A·B = [[4,6],[10,12]]。注意：**B·A 是另一个结果**（矩阵乘法不交换），验算时两个都写出来对照。

**单位阵 I**：对角为 1、其余为 0 的方阵。任何矩阵乘 I 或 I 乘它，都等于它自己——I 好比矩阵世界的"1"。2×2 的单位阵是 [[1,0],[0,1]]。

**转置**：把矩阵的行列互换——第 i 行变成第 i 列。A=[[1,2],[3,4]] 的转置 Aᵀ=[[1,3],[2,4]]。用途：列向量变行向量，方程组写成 AX=b 时有时要把行向量转成列向量。

**土法**：矩阵乘法用"行列对乘再加"的口诀，每次只算一个格；两表相乘时先在沙盘上把右表的列抄到左表每行旁边，逐格对乘相加，写完再核一遍。

### 齐次系统与解的结构

把右端全变成 0 的系统叫**齐次系统** AX=0。它永远至少有一个解——全零解（每一格都是 0）。（来源同上。）关键是：齐次系统的解集本身也是一个向量空间（**解空间**），它的维数等于未知数个数减去系数矩阵的秩。这个结构是后面一切"多解怎么算"的根据。

**解的三种结局（消元后看）**：
- 化简后每行都剩一个未知数且不矛盾 → **唯一解**；
- 化简后出现"0=非零" → **无解**（几条条件互相打架，比如"三人共做 5 个工日"与"每人每天 2 个工日"同时成立）；
- 化简后出现全零行（0=0），未知数比方程多 → **无穷多解**（解中带自由参数，要写成"某某参数取任意数"的形式）。

### 行列式：一张表的"总缩放倍数"

**行列式**是一个数——把一张方阵代表的线性变换作用在"单位方块"上，它把这块的体积放大（或缩小、翻转）了多少倍。（来源：Wikipedia "Linear algebra"，Endomorphisms 与 Determinant 节——行列式衡量线性变换对体积的缩放。）

**二阶行列式**的算法（ad−bc）：[[a,b],[c,d]] 的行列式 = a×d − b×c。三阶与更高阶有展开公式，手工算用消元法更省事。

**行列式的三个用处**：
- **判断可逆**：行列式不为 0，矩阵才有逆；为 0 就没有逆（这时变换把空间"压扁"了）；
- **判断唯一解**：方阵系统 AX=b 有唯一解，当且仅当 A 的行列式不为 0；
- **求逆矩阵**：行列式不为 0 时，可用伴随矩阵法求出 A⁻¹，满足 A·A⁻¹=I（I 是单位阵，对角为 1、其余为 0）。

### 特征值与特征向量：算起来最省的方向

一个方阵 A 作用在一个向量 v 上，如果结果只是 v 的某个倍数——A·v=λ·v——那 v 就叫 A 的**特征向量**，那个倍数 λ 叫**特征值**。（来源：Wikipedia "Linear algebra"，Eigenvalues and eigenvectors 节。）

**为什么有用**：特征向量是"变换之下方向不变"的特殊方向，特征值告诉你沿那个方向拉伸了多少倍。找特征值就是解特征方程 det(A−λI)=0。它在振动分析、种群增长、稳态判断上都是第一工具。

## 从零实现路径

依赖链：会四则与配比（[数与算术](02_numbers_arithmetic.md)）→ 会解一次方程与移项（[代数与方程](04_algebra_equations.md)）→ 有量具与计时（[单位与计量](03_units_measurement.md)）。以下全部用算筹、沙盘、绳结完成，无需现代器材。

**第一步：把题排成表（矩阵的土法）**。几张条件、几个未知数，把每个未知数对齐一列，系数逐格填进沙盘上的格子，右端另起一列。排表三纪律：未知数顺序全组统一；同一格不填两个数；右端列与系数列严格分开。

**第二步：做一张"系数抄本"（矩阵的实物版）**。把排好的表抄到一块木板上，格子用绳钉成方格，每格放对应数量的小石子。加减整行时直接搬石子——这就是矩阵加减与数乘的实物版。

**第三步：消元解全系统（高斯消元法）**。用第一行把下面各行第一个数消成 0（行操作三类，只做这三类）；再用第二行消下面；依此类推，最后回代。每一步把操作记在旁边，以便查错。

**第四步：判断解的三种结局**。化简后看：每行都剩一个未知数且不矛盾→唯一解；出现"0=非零"→无解；出现全零行→无穷多解（写出自由参数）。

**第五步：求行列式（判断可逆与唯一解）**。方阵算 ad−bc（二阶）或展开（三阶）。不为 0 才有唯一解、才有逆阵。

**第六步：验算（代回原题）**。把解出的每个数代回原方程组的每一条，全部成立才算解完。**这一步不能省**——消元过程中任何一步抄错、算错，代回立刻暴露。

## 方法与应用

以下六张速查卡，每张都是"排表→消元→回代→验算"的完整一路，全部可用算筹、沙盘完成。

### 场景一：三家人分一块地（联立一次方程）

三家按地力分 30 亩，甲得乙的一半、乙得丙的三分之二、三家共 30 亩。设丙 x，则乙 2x/3、甲 x/3，x+2x/3+x/3=30 → 2x=30 → x=15。丙 15、乙 10、甲 5，代回验算：15+10+5=30 ✓、10 是 15 的 2/3 ✓、5 是 10 的一半 ✓。

### 场景二：三种粮配饲料（十字法进阶到联立）

两种原料的十字法是单方程，三种原料就要两张条件联立。排成表、消元解出每样各多少份，成品的蛋白落在两原料之间才算列对（十字法的验算口诀见[代数与方程](04_algebra_equations.md)）。

### 场景三：三个人一天的活该各记多少工（齐次结构）

总工日固定时，"每人每天的活量"是一组解；若活量有富余，解就不唯一。先排齐次系统 AX=0 找基础解，再加一条总量条件定出具体分配。

### 场景四：判断有没有解（行列式）

方阵系统先算行列式：不为 0 → 唯一解；为 0 → 无解或无穷解，要回到消元法看化简结果。

### 场景五：求逆矩阵（行列式不为 0 时）

方阵 A 的逆 A⁻¹ 满足 A·A⁻¹=I。手工用伴随矩阵法：A⁻¹=(1/det A)·adj A。它用来"反解"——已知结果求输入。

### 场景五点五：用矩阵核对多方交易的找平（线性系统的现实版）

多人多方的账，每方"应收多少、应付多少"是一组条件，排成表后就是一个线性系统。土法：把每人的应收记一行、应付记一列，系数表排好，消元解出每人的实付额；解完用" everyone 的实付 − everyone 的实收 = 0"这条总量守恒验算——应收总和必须等于应付总和，不等就是某笔抄错。

### 场景六：验算四步

排表→消元→回代→**代回原题每一条**。任一步对不上，退回重排，不许"差不多"。

### 教人线性代数：从摆石子开始

先用石子摆一张 2×2 的表，演示"对应格相加""每格乘同一个数"；再摆一个 2×2 乘一个 2×1 的列向量，看结果怎么算出来；然后做消元——用第一行消下面，回代出解。三件事用同一套路讲透：**排成表、整表地算、消元定出每个数**。

## 常见错误与限制

- **消元时只动系数、忘了动右端。** 为什么错：行操作必须整行一起动；后果：右端没跟着变，解出的数全错；正确做法：把右端当作第 n+1 列，整行一起操作。
- **除以 0。** 为什么错：某行第一个数是 0 时，不能拿它当"主元"去消下面；后果：除零出错或消元中断；正确做法：先与下面非零的行互换，再继续。
- **行列式为 0 当成可逆。** 为什么错：行列式为 0 的方阵没有逆；后果：求逆时除以 0；正确做法：先算行列式，为 0 就别求逆，回到消元法看解的情况。
- **无穷解当成唯一解。** 为什么错：化简后有全零行，说明有自由参数；后果：只报一个数，漏掉整族解；正确做法：写出自由参数，用它表示全部解。
- **矩阵乘法行列放反。** 为什么错：结果表第 i 行第 j 列要用左表第 i 行、右表第 j 列；后果：积算出来全错；正确做法：先默念"左行右列"再对乘相加。
- **齐次系统忘掉全零解。** 为什么错：以为齐次系统可能无解；后果：解的结构说错；正确做法：AX=0 永远有全零解，至少这一个。
- **限制**：本篇只讲实数域上的有限维线性代数；向量空间的严格公理证明（8 条公理）、无限维空间、模理论、张量代数、勒贝格型测度空间上的泛函分析均超出范围；特征值的高次方程解法（四次以上无通解公式）超出本文；行列式与逆矩阵的严格理论（余子式、伴随矩阵的完整推导）本文只给运算口径。
