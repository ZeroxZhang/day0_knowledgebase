## 解决什么问题

前面几篇把"已知的算已知的"、"设盒子解未知数"、"一个量跟着另一个量变"都建起来了，但还缺最关键的一跳：**变化有多快、一共变了多少**。同一条河，上游水位一寸寸涨（变化率），下游的田总共被淹了多少（累积量）——这两件事是同一枚硬币的两面。本篇回答三件事：

- **极限**：无限逼近的那个数到底是什么，怎么判断它"到齐了"；
- **导数**：函数在某一点的变化率（斜率），以及怎么从变化率反推总量；
- **积分**：把无数小份加起来的极限，面积、体积、总功、总流量都算它。

读完本篇你能做到：判断一个量是不是"在变快"、用斜率估变化、用"变化率反推总量"的口诀算面积与总量，并知道每一步的误差出在哪。

前置与分工：函数与图像见[函数与三角](26_functions_trigonometry.md)；极限的直觉与斜率概念来自它；代数与方程的开方、配比是本篇算例的工具；26 篇管"关系与换算表"，本篇管"变化率与累积"，后续[线性代数](28_linear_algebra.md)见其连续侧准备。

## 核心知识与原理

### 极限：无限逼近的那个数

零基础定义：**极限**说的是——喂进去的输入离某个位置 a 越来越近时，函数值会离某个数 L 越来越近，那 L 就叫"x 趋近 a 时 f(x) 的极限"，记作 lim_{x→a}f(x)=L。关键是：**极限只看 a 附近、不看 a 本身**——f(a) 甚至可以根本不存在或等于别的数，极限照样是 L。

就地演示（走两步停一步）：你在离柱子 10 步处起步，每走一步离柱子近一半——5 步、2.5 步、1.25 步……你永远走不到柱子（每步只走剩下的一半），但"离柱子多远"这个数会无限逼近 0。这个 0 就是极限。你实际永远停在离柱子一点点处，但数学上就说它"趋近 0"。

判断极限的土法：把输入一段段缩小（每次取前一次的一半），看函数值是不是一段段"定下来"——前后两段的差小到你可接受（比如小于你量具的最小刻度），就认为它到齐了。**前后差不再缩小，说明极限不存在**，就别硬凑一个数。

### 导数：函数在某一点的"斜率"

零基础定义：**导数**是函数在某一点的变化率——输入每动一小点，输出跟着动一大点，两份变动的比值就是导数。几何上，导数等于函数图像在那一点的**切线斜率**。（来源：Wikipedia "Derivative"——导数是函数对自变量的敏感度量，在一点的导数等于该点切线的斜率；定义式 f'(a)=lim_{h→0}[f(a+h)−f(a)]/h。）

**导数定义式**（来源同上，为该页核心公式）：

f'(a) = lim_{h→0} [f(a+h) − f(a)] / h

就地理解：把函数值 f(a) 与 f(a+h) 想成曲线上相隔 h 的两个点，连一条割线——这条线的斜率是"平均变化率"。h 越缩越短，割线越靠向一条固定的线，那条线就是**切线**，它的斜率就是导数 f'(a)。

**幂函数的导数（最重要的一条，已核对）**：f(x)=x² 的导数是 f'(x)=2x。（来源：Wikipedia "Derivative"，推导节——平方函数的差商 [(a+h)²−a²]/h = 2a+h，h→0 时极限为 2a，故导数为 2x。这条由原文推导确认，不是待核验。）口诀：**xⁿ 的导数是 n·xⁿ⁻¹**——x³ 的导数是 3x²，x 的导数是 1（常数的导数是 0）。

**导数 tells you 三件事**：
- 正负：导数为正，函数在涨；导数为负，函数在跌；导数为 0，函数在"平"（峰顶、谷底或平段）；
- 大小：导数绝对值越大，变化越快——陡的地方变化快，平的地方变化慢；
- 极值：导数从正变负处是峰，从负变正处是谷（这是下一节"反推总量"的钥匙）。

### 从导数反推总量：微积分基本定理

这是整个微积分最实用的一句：**变化率与累积量互为逆运算，就像加减、乘除一样**。（来源：Wikipedia "Integral"，微积分基本定理节——∫_a^b f'(t)dt = f(b)−f(a)，即导数的累积等于函数值之差；也见 "Derivative" 页的 Fundamental theorem of calculus 条目。）

土话版：**如果你知道每时每刻的变化率（导数），把它们"加"起来就得到总变化量**。反过来，**总量的"变化率"就是导数**。所以：

- 已知速度 v(t)（=位置的导数），从 t=a 到 t=b 的总位移 = ∫_a^b v(t)dt；
- 已知水流入水箱的速率 r(t)，一段时间内的总入水量 = ∫ r(t)dt；
- 已知曲线下的"高度"函数 f(x)，a 到 b 之间的面积 = f(b)−f(a)。

**不定积分**：∫f(x)dx 表示"导数是 f(x)的那一族函数"（原函数），各族之间只差一个常数。**定积分**：∫_a^b f(x)dx 是一个数（面积），有上下限。

### 积分：把无数小份加起来的极限

零基础定义：**积分**是求"曲线下的面积"的极限做法——把区间切成 n 小段，每段上用一个矩形近似那一小片面积，矩形面积之和是近似值；段切得越细（n 越大），近似值越靠向一个固定的数，那个数就是积分值。（来源：Wikipedia "Integral"，Riemann 积分与解释节——定积分是有符号面积；以 √x 从 0 到 1 为例，5 段右端近似 0.7497、12 段左端近似 0.6203，段数趋于无穷时极限为 2/3，即 ∫_0^1√x dx = 2/3。）

**积分的记法**：∫_a^b f(x)dx。∫ 是拉长的 S（拉丁文 summa"总和"，Leibniz 1675 年引入，来源同上历史节）；a、b 是积分上下限；dx 是"每小段的宽"。

**积分的三条直观**：
- 面积：f(x)≥0 时，∫_a^b f(x)dx = 曲线下方到 x 轴的面积；f(x) 为负的部分算负面积；
- 累积：任何"每单位的量"在一段区间上的总量，都可用积分求和；
- 逆运算：∫f'(x)dx = f(x)+C，积分是求导的逆。

**几条最常用的积分结果**（由幂函数导数口诀直接反推，本文自算，未逐条查原文）：
- ∫xⁿ dx = xⁿ⁺¹/(n+1) + C（n≠−1）；
- ∫k dx = kx + C（k 为常数）；
- ∫(u+v)dx = ∫u dx + ∫v dx（积分的线性，来源同上 Properties 节 linearity）。

### 变化率的实测与二阶直觉

把"变化率表"再加工一层，就是二阶变化率——**变化率本身的变化率**。相邻两个变化率相减，得每段"变化率的增减"：

- 变化率在变大（如 2、3、5、7）：函数**凹向上**，越涨越快，像碗口朝上；
- 变化率在变小（如 7、5、3、2）：函数**凹向下**，越涨越慢，像碗口朝下；
- 变化率不变（如 5、5、5、5）：函数是**一条直线**，变化率恒定。

**为什么有用**：凹凸性告诉你"加速还是减速"。备料赶工时，凹向上的活越到后面越吃力（要提前加人）；凹向下的活越到后面越省（可以收工）。落石是凹向上的（越掉越快），所以估井深时"秒数自乘再乘 5"的数会越估越大——知道是凹向上，就明白为什么不能用"匀速"来估。

### 导数的更多实用算法：变化率表定位极值

没有导数公式时，算导数全靠**变化率表**——在曲线上每隔等距取点，算相邻两点的"值差÷间距"，那一列就是各段的导数值。用它定位极值的土法：

1. 在变化率表上找**正负号翻转**的那一行；
2. 由正转负处：函数在那一段从涨变跌，中间必有**最高点**（极大值）；
3. 由负转正处：函数从跌变涨，中间必有**最低点**（极小值）；
4. 变化率为 0 而附近不翻转：可能是平段，不是极值。

**为什么有用**：分粮按存粮峰值备仓、防洪按水位峰值备料、用工安排在"变化率最大"的时段省力——极值定位是这些决策的数学根据。变化率表的间距越小（取点越密），极值位置定得越准。

### 常见函数的导数表与积分表（手工速查）

把最常用的几条导数与积分列成一张小表，刻在木板上，算变化率与面积时直接查，不必每次从定义推。以下由幂函数导数口诀 xⁿ→n·xⁿ⁻¹ 直接反推（n=2 已由 Wikipedia 原文确认，其余为本文自推，未逐条查原文）：

| 函数 f(x) | 导数 f'(x) | 不定积分 ∫f(x)dx |
| --- | --- | --- |
| 常数 k | 0 | kx + C |
| x | 1 | x²/2 + C |
| x² | 2x | x³/3 + C |
| x³ | 3x² | x⁴/4 + C |
| √x | 1/(2√x) | (2/3)x^(3/2) + C |
| 1/x | −1/x² | ln\|x\| + C（超出本篇，仅列不推） |

**用法**：算变化率查左列，算面积查右列；复杂函数先拆成这几项的和（积分的线性：∫(u+v)=∫u+∫v），逐项查表再相加。算完用"总量变化=终点值−起点值"验算。

### 微积分基本定理的算术版（不用符号也能用）

微积分基本定理 ∫_a^b f'(t)dt=f(b)−f(a) 的土话是：**总量变化 = 各段变化量之和**。没有导数符号时，它照样能用：

- 手上有**每段的变化量**（如每天水位涨几寸）：直接相加，得总变化；
- 手上有**每段的变化率**（如每天每小时涨几寸）：变化量 = 变化率 × 段长，再相加；
- 手上有**每段的起点值与终点值**：变化量 = 终点值 − 起点值，各段相加 = 最后一个值 − 第一个值。

**验算口诀**：总变化量必须等于"终点值减起点值"——不管中间怎么涨跌，只要首尾对得上，累加就没错。这条口诀是积分计算的最后防线：各段变化量之和若不等于首尾之差，说明某段抄错或漏段。

**为什么这是微积分基本定理**：导数是变化率，积分是累加；累加变化率就回到原函数的值——这就是"导数与积分互为逆运算"的算术版，也是 Wikipedia 页上 ∫_a^b f'(t)dt=f(b)−f(a) 的离散版本。

### 积分的更多实用算法（梯形法与夹逼）

除了网格法与割补法，还有一条更省事的：**梯形法**。把曲线下的区间切成若干小段，每一段用一个梯形近似（上底与下底是这段两端的函数值，高是段长），梯形面积=（上底+下底）÷2×段长，各段相加即得积分近似。它比矩形法准，因为两端都用了。

**梯形法的土法流程**：在曲线上每隔等距钉桩，记下各桩处的函数值 f₁、f₂、…、fₙ，段长为 d。近似面积 = d×[(f₁+fₙ)÷2 + f₂+f₃+…+fₙ₋₁]。口诀：**两头取半、中间全加，再乘段长**。

**夹逼定真值**：把同一块地用左端矩形法、右端矩形法、梯形法各算一次。左端法通常偏小、右端法通常偏大（单调函数时），梯形法夹在中间。三者差一成以内才采信；否则把段长缩小一半再算一遍，直到两次结果的差值缩小一半以内——这就是极限思想的实地版。

### 就地验证与自制"算面积"法

没有纸笔积分表的年代，算面积靠三条：

**第一步：网格法（粗算）**。把地块按方格纸的格子描，数格子——整格算 1，破格两两拼成整格。格子越密越准。这是积分"切细段"思想的实物版。

**第二步：割补法（中等精度）**。把不规则图形切成几个已知形状（矩形、三角形、梯形），分别算面积再相加。三角形面积=底×高÷2（高用[几何与测量方法](05_geometry_basics.md)的 3-4-5 法作直角定出）。

**第三步：变化率反推总量（最省事，当知道变化率时）**。如果手上有"每单位时间的变化量"的记录（如每天水位上涨几寸），总量变化=各段变化量相加——这就是积分"加小份"的离散版，也是微积分基本定理的算术版。

**误差说明**：以上三法都是积分的近似。切得越细越准；段数不够时，近似值可能偏大（用右端高）也可能偏小（用左端高），两头夹逼才能定出真值——这正是 Wikipedia 页里 √x 例子讲的事。

## 从零实现路径

依赖链：会读图与算斜率（[函数与三角](26_functions_trigonometry.md)）→ 会开方与配比（[代数与方程](04_algebra_equations.md)）→ 有量具与计时（[单位与计量](03_units_measurement.md)）。以下全部用绳、桩、沙盘、滴漏完成，无需现代器材。

**第一步：做一张"变化率表"（导数的土法）**。在一条直线上每隔固定距离（如每 5 步）钉桩，记录某量（如水位、粮堆高度）在各桩处的值；相邻两桩的"值差÷桩间距"就是这一段的平均变化率。把各段变化率抄成一张表——这张表就是你的第一张"导数表"。

**第二步：找峰与谷（极值定位）**。在变化率表上找"由正转负"和"由负转正"的那两行——正转负处是最高点，负转正处是最低点。这一步是后面所有"最多/最少"问题的根据（分粮峰值、水位峰值、用工最省的时刻全靠它）。

**第三步：从变化率反推总量（积分的离散版）**。把各段变化率乘上该段长度（=该段的变化量），再全部加起来——总变化量=各段变化量之和。这就是微积分基本定理的算术版：**总量变化=各段变化率×段长 的和**。算例：水位每 5 分钟涨 2 寸、再 5 分钟涨 1 寸、再 5 分钟跌 3 寸，总变化=2+1−3=0 寸，水位回到原高。

**第四步：网格法算面积（积分的图形版）**。把不规则地块按方格描，数整格、拼破格。格子画得越密（桩距越小），面积越准。这是没有积分表时算地亩的主力。

**第五步：割补法算面积（积分的分块版）**。把地块切成矩形、三角形、梯形，分别算面积再相加。三角形的高用 3-4-5 法作直角定出（见[几何与测量方法](05_geometry_basics.md)）。

**第六步：验算与误差夹逼**。同一块地用网格法与割补法各算一次，两头夹逼——两法结果差一成以内才采信；只用一种法子时，把格子加密一倍再算一次，两次差值缩小一半以内才算"到齐"（极限思想的实地版）。

## 方法与应用

以下六张速查卡，每张都是"量取→算变化率→累加/求面积→验"的完整一路，全部可用绳、桩、沙盘完成。

### 场景一：判断量在不在"变快"

相邻几段的变化率如果越来越大（如 2、3、5、7），函数在"凹向上"（越涨越快）；越来越小（如 7、5、3、2）则"凹向下"（越涨越慢）。口诀：**变化率本身也在变，二阶导数 tells you 弯向**（二阶导数就是"变化率的变化率"，本文不展开，只给直觉）。

### 场景二：估极值（分粮、防洪、省工）

在变化率表上找正负号翻转处。峰值处停止增加、谷值处停止减少——分粮按峰值备仓、防洪按峰值备料、用工安排在变化率最大的时段。

### 场景三：算总位移（知道速度时）

各段速度×段长=各段位移，相加得总位移。与"量步数×步长"同理，只是速度随时间变。

### 场景四：算面积（网格法）

方格描图，数整格、拼破格。格子越密越准。

### 场景五：算面积（割补法）

切块成已知形状，分别算再相加。三角形高用 3-4-5 作直角。

### 场景六：算总入水（知道流入速率时）

各段流入速率×段长=各段入水量，相加得总入水。与水位变化互为校验（入水−出水=水位净变化×水面面积）。

### 教人微积分：从"走两步停一步"开始

先用"每步走剩下的一半"演示极限（永远走不到但趋近 0）；再用沙盘上量"相邻桩的高差÷桩距"演示导数（变化率）；最后用"各段变化量相加"演示积分（累积）。三件事用同一套路讲透：**切细、看变化率、加起来**。

## 常见错误与限制

- **把极限值当成"达到"。** 为什么错：极限是"无限逼近"，不是"走到"；后果：把永远走不到的柱子当成已到，据此量距全错；正确做法：只用"趋近"的口径，量具够细就收手。
- **用单点斜率代替变化率。** 为什么错：只看一处的高低，不看相邻差；后果：漏掉峰谷，分粮、防洪全错；正确做法：一律做变化率表，看正负翻转。
- **积分忘了"有正有负"。** 为什么错：把曲线下的面积全当正数；后果：净变化算成总变化，水位先涨后跌算成只涨；正确做法：涨的部分算正、跌的部分算负，相加得净变化。
- **近似值不夹逼就收。** 为什么错：只用一种切法、一段段数；后果：面积偏大偏小都说不准；正确做法：左右两端各算一次（一个偏大一个偏小），两头夹逼，或加密一倍复查。
- **导数口诀记错幂次。** 为什么错：xⁿ 的导数是 n·xⁿ⁻¹，记成 n·xⁿ 就全错；后果：变化率、极值、面积全错；正确做法：用 x²→2x 这一条原文确认过的做锚，其余自己推一遍。
- **积分与导数方向搞反。** 为什么错：以为积分是"求导"；后果：总量与变化率对调，算出"变化率"当总量；正确做法：记住"导数是变化率、积分是累积"，互为逆运算。
- **限制**：本篇只讲一元函数的导数与积分（极限、导数、积分的严格 ε-δ 定义、多元函数偏导数、重积分、曲线曲面积分、勒贝格积分均超出范围）；幂函数导数口诀的严格证明（n 为任意实数时）超出本文；微积分基本定理的严格条件（函数连续、可积）本文只给运算口径，不给证明。
