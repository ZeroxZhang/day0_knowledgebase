## 解决什么问题

前面几篇处理的都是"一个数"或"几个数"，但生活里大量问题是**一群东西之间的关系**：哪些东西是一伙的、两群之间有多少公共的、从一个地方到另一个地方怎么走。本篇回答两件事：

- **集合论**：把东西归堆的规矩——怎么归、怎么比大小、怎么算公共与多余，以及"所有集合的集合"这类话为什么要小心；
- **图论**：把关系画成点与线——两点之间有没有线、怎么走最省、一块地能不能不交叉地连起来。

读完本篇你能做到：把一群东西按规矩归堆并做集合运算、判断两群的大小、把关系画成图、判断图里有没有绕不开的堵点、找出最省的连线与走法，并知道每一步的误差与限制出在哪。

前置与分工：四则见[数与算术](02_numbers_arithmetic.md)；本篇管"成群东西的结构与关系"，是所有组织、路线、网络问题的数学底座。

## 核心知识与原理

### 集合：把东西归堆

零基础定义：**集合**就是一堆东西聚在一起，通常用大写字母 A、B 表示，里面的每个东西叫**元素**。a 属于 A 记作 a∈A，不属于记作 a∉A。（来源：Wikipedia "Set theory"，Basic concepts 节——集合论始于对象 o 与集合 A 之间的二元关系，o 是 A 的元素记 o∈A；集合用花括号列出元素或用特征性质描述。）

**列举法**：A={1,2,3}。**描述法**：{x | x 是偶数}。两种写法指同一堆时，元素的重复与顺序都不改变集合。

**三个常用底集**：ℕ 自然数集、ℤ 整数集、ℝ 实数集。**空集 ∅** 是不含任何元素的集合，任何集合与它求并集都不变。

### 子集、相等与幂集

**子集**：A 的每个元素都在 B 里，就叫 A 是 B 的子集，记 A⊆B。每个集合都是它自己的子集。（来源同上，subset 关系——{1,2}⊆{1,2,3}，且每个集合都是自身的子集。）

**真子集**：A⊆B 且 A≠B，记 A⊂B。**相等**：A=B 当且仅当 A⊆B 且 B⊆A——两集合互为子集就相等，与列举的写法无关。

**幂集 P(A)**：A 的所有子集构成的集合。（来源同上，power set 节——P({1,2})={∅,{1},{2},{1,2}}，包含 A 自身与空集。）A 有 n 个元素时，P(A) 有 2ⁿ 个元素——这是"每个元素要么在子集里、要么不在"的乘法计数。

### 集合运算：并、交、差、积

以下运算把两堆变成新的一堆（来源同上，Algebra of sets 节）：

- **并集 A∪B**：属于 A 或属于 B（或两者都属）的全体。{1,2,3}∪{2,3,4}={1,2,3,4}。
- **交集 A∩B**：同时属于 A 与 B 的全体。{1,2,3}∩{2,3,4}={2,3}。
- **差集 A∖B**：属于 A 但不属于 B 的全体。{1,2,3}∖{2,3,4}={1}。
- **对称差 A△B**：恰好属于其中一个的全体，(A∖B)∪(B∖A)。{1,2,3}△{2,3,4}={1,4}。
- **笛卡尔积 A×B**：所有有序对 (a,b)，a∈A、b∈B。{1,2}×{红,白}={(1,红),(1,白),(2,红),(2,白)}。

**文氏图**：用两个圆圈的重叠示意交集，是教人集合运算的直观工具（来源同上，文氏图在基础概念节提及）。

### 一一对应与"一样大"

两个集合**一样大**（等势）当且仅当它们的元素可以一一配对，没有剩余。（来源同上，History 节 Early history——Bolzano 1851 年在《无穷的悖论》中引入无穷集合的一一对应，如 [0,5] 与 [0,12] 通过 5y=12x 配对。）

**有限集比大小**：元素个数多的更大。**无穷集的怪处**：真子集可以与全集一样大——偶数集与自然数集能一一对应，这是无穷集的标志。

### 罗素悖论：为什么"所有集合的集合"不能说

"所有集合的集合"这种话会撞上矛盾。（来源同上，Naive set theory 节与 Russell 悖论——Frege 的 Basic Law V 说"任何性质都对应一个集合"，罗素构造了 R={x | x∉x}，于是 R∈R ⟺ R∉R，自相矛盾。）

**土话版**：问"这个集合包不包含自己"，两个答案都错。这就是**罗素悖论**，它逼出一件事：**不能随便说"所有满足某条件的东西构成一个集合"**。

**后果**：20 世纪初数学基础受冲击，催生了**公理化集合论**——用一套 carefully 限制的公理（ZFC：Zermelo-Fraenkel 公理 + 选择公理）来代替"随便构造"。（来源同上，Formalized set theory 节——ZFC 是最广为研究的公理化系统；Cantor 1874 年创立集合论，其后出现悖论，20 世纪初提出各种公理系统。）

### 图：点与线

**图**由**顶点**（点）与**边**（连接两点的线）组成，用来 modeling 两两之间的关系。（来源：Wikipedia "Graph theory"，Definition 节——图由顶点与边构成， modeling 对象间的成对关系。）

**有向图 vs 无向图**：无向图的边两端对称，有向图的边带箭头、方向不对称。（来源同上——有向图每条边有方向，用箭头表示。）

**简单图 vs 重图**：简单图两点间至多一条边、无自环；重图允许多条同端点的边与自环。（来源同上——multigraph 允许多边同端点与自环 loop。）

**加权图**：每条边带一个数（权重），如路长、路费。（来源同上——边可赋权，称加权图；可用于表示道路长度、旅行时间、费用。）

### 图的度数与握手引理

顶点的**度**是与它相连的边数。**握手引理**：所有顶点的度之和等于边数的两倍（每条边为两端各贡献 1 度）——因为每条边恰好被数两次。

**推论**：度为奇数的顶点个数必为偶数。这是判断"一笔画"能不能成功的第一步。

### 路径、回路与连通

**路径**：沿边从一顶点走到另一顶点，不重复边。**回路**：起点与终点相同的路径。**连通图**：任意两顶点间都有路径。（来源同上，route problems 节列 Hamiltonian path、shortest path 等路径类问题。）

**欧拉回路**：经过每条边恰好一次的回路。**欧拉 1736 年解了哥尼斯堡七桥问题**，这是图论史上的第一篇论文。（来源同上，History 节——Euler 1736 年发表《哥尼斯堡七桥问题的解》，被视为图论史上第一篇论文。）

**欧拉路径存在的条件**：连通图，且奇度顶点个数为 0 或 2（为 0 时是回路，为 2 时路径从一个奇度点起到另一个奇度点止）。

**哈密顿回路**：经过每个顶点恰好一次的回路。找它是 NP 难的，没有简单判据——这是它与欧拉回路的根本区别。

### 树与生成树

**树**是连通且无回路的图：任意两点间只有唯一一条路径。n 个顶点的树恰有 n−1 条边。（来源同上，History 节——Cayley 1875 年研究树，其成果对理论化学有深远影响；Cayley 还把树与当时化学成分研究联系起来。）

**生成树**：包含全部顶点、且是树的子图。任何连通图都有生成树。**Kirchhoff 矩阵树定理**：用拉普拉斯矩阵的任一余子式，可算出图的生成树个数。（来源同上，Algebraic graph theory 节——Laplacian 矩阵由度矩阵与邻接矩阵合成，Kirchhoff 定理借它计算生成树数目。）

**最小生成树**：边有权重时，总权重最小的生成树。土法是 Kruskal 算法——每次取最短的边，只要不形成回路就加上，直到加满 n−1 条。

### 平面图与四色定理

**平面图**：能画在平面上、边与边不交叉的图。**Kuratowski 定理**：一个图是平面图，当且仅当它不含 K₅（五顶点完全图）或 K₃,₃（三对顶点的完全二部图）的细分。（来源同上，Subareas 节的 planar graph 与 Kuratowski 相关内容——Wagner 定理：有限图是平面图当且仅当它不含 K₅ 或 K₃,₃ 作为 minor；Kuratowski 定理以细分形式给出同样判据。）

**四色定理**：任何平面地图，相邻区域不同色，至多四色就够。（来源同上，History 节——四色问题 1852 年由 Francis Guthrie 提出，首见于 De Morgan 致 Hamilton 的信；1976 年 Appel 与 Haken 用计算机证明，涉及 1936 种构型；1997 年 Robertson 等人用 633 种构型给出更简证明。）

### 最短路径与网络流

**最短路径**：两点间总权重最小的路径。土法是 Dijkstra 算法——从起点开始，每次扩展最近的未访问顶点。（来源同上，route problems 节列 shortest path problem。）

**最大流最小割定理**：网络中从源到汇的最大流量，等于把源与汇分开所需的最小割容量。（来源同上，Network flow 节列 Max flow min cut theorem。）

## 从零实现路径

依赖链：会四则与配比（[数与算术](02_numbers_arithmetic.md)）。以下全部用沙盘、木钉、绳子完成，无需现代器材。

**第一步：归堆（集合的实物版）**。把一堆东西按某一特征分成两堆，两堆各自的全体就是两个集合；公共的部分用手挑出来就是交集；合起来就是并集；只在左边那堆的就是差集。

**第二步：画文氏图**。两个圆圈代表两堆，重叠处放公共的，各自独放的放独有的。任何集合运算都能在图上一眼看出结果。

**第三步：把关系画成图（点线版）**。每个"地方"钉一根木钉作顶点，有路相通的两钉之间系一根绳作边。绳上可挂小石子当权重。有方向的路用不同色的绳或打单向结表示。

**第四步：数度数、判一笔画**。逐个顶点数相连的绳数（度），奇度点个数为 0 或 2 且图连通，才能一笔画（欧拉路径）。

**第五步：找最省连线（最小生成树）**。把所有绳按长短排序，从最短的开始取，只要不形成回路就钉死，直到钉满 n−1 条。这就是 Kruskal 算法的实物版。

**第六步：找最省走法（最短路径）**。从起点出发，每次走到最近的未访问钉，更新到各钉的距离，直到走到终点。

**第七步：验算**。生成树的边数必须等于顶点数减 1；最短路径的长度用另一条路复核；一笔画的奇度点个数用握手引理复核。

## 方法与应用

以下七张速查卡，每张都是"归堆/画图→算→验"的完整一路，全部可用沙盘、木钉、绳子完成。

### 场景一：两群人有多少公共的（交集）

两支施工队各报一份人名，公共的人就是两份名单的交集。用文氏图一摆，重叠处直接读出。

### 场景二：分物资不重不漏（并集与差集）

两仓粮合并分配是并集；甲仓有而乙仓没有的，单独调拨是差集。先求并集定总量，再求差集定独有。

### 场景三：判断两群是不是一样大（一一对应）

两群东西，逐个配对，都配完且无剩余就是一样大。无穷集要小心——偶数集与自然数集能配对，所以"一样大"。

### 场景四：一笔画通所有桥（欧拉路径）

数各点的度，奇度点为 0 或 2 且图连通，才能一笔画。哥尼斯堡七桥的四个奇度点，所以画不通。

### 场景五：拉通线路不绕路（最小生成树）

把所有可拉的线按长短排序，从短到长取，不形成回路的留下，取满 n−1 条就是最省的拉线方案。

### 场景六：两地之间怎么走最省（最短路径）

从起点每次扩展最近的钉，逐步更新到各点的距离，到终点后复核另一条路。

### 集合运算的组合恒等式（快速心算）

几条固定的组合关系，能把复杂的集合题化简：

- **分配律**：A∩(B∪C)=(A∩B)∪(A∩C)，A∪(B∩C)=(A∪B)∩(A∪C)——交与并可以互相"分配"；
- **包含律**：A∪(A∩B)=A，A∩(A∪B)=A——已经含进去的再并交都回到自身；
- **摩根律**：补集的并等于交的补，(A∪B)ᶜ=Aᶜ∩Bᶜ——"至少属于一个"的反面是"两个都不属于"。

**土法验算**：任何集合恒等式，用文氏图把两边各画一次，看填充区域是否相同。

### 图的矩阵表示（邻接表与邻接矩阵）

图除了画出来，还能写成表，便于整表地算：

**邻接表**：每个顶点列一张"它连着谁"的清单。省空间，适合边少的图。

**邻接矩阵**：行与列都按顶点排，第 i 行第 j 列是 1（有边）或 0（无边）。无向图的矩阵对称；有向图的矩阵不一定对称。加权图把 1 换成权重值。

**用途**：邻接矩阵自乘一次，第 i 行第 j 列的数就是 i 到 j 长度为 2 的路径条数——这就是"矩阵乘法算路径"的起点（与[线性代数](28_linear_algebra.md)的矩阵乘法同构）。

### 场景七：教人集合与图：从"归堆"起步

先演示按特征分两堆、挑公共的，讲集合运算；再用绳子钉钉子画图，讲一笔画；最后用"拉线不绕路"讲生成树。三件事用同一套路讲透：**先归堆、再画关系、最后求最省**。

## 常见错误与限制

- **说"所有集合的集合"。** 为什么错：撞上罗素悖论；后果：推理自相矛盾；正确做法：在 ZFC 公理内构造，不许无限制地概括。
- **把子集与元素混为一谈。** 为什么错：1∈{1,2,3} 但 1⊆{1,2,3} 不成立（1 不是集合）；{1}⊆{1,2,3} 成立但 {1}∈{1,2,3} 不成立；后果：包含关系说反；正确做法：先问"是元素还是集合"。
- **无穷集用有限集的大小直觉。** 为什么错：真子集可以与全集等势；后果：说"全集一定更大"；正确做法：用一一对应判等势，不比个数。
- **一笔画只看连通不看奇度点。** 为什么错：连通但奇度点超过 2 就画不成；后果：白试半天；正确做法：先数奇度点。
- **生成树多加边。** 为什么错：树要求无回路，多一条就有回路；后果：不是树，方案不成立；正确做法：加边前先查是否形成回路。
- **把有向边当无向边走。** 为什么错：有向图的边只能沿箭头方向走；后果：路径根本不存在；正确做法：先分清有向还是无向。
- **限制**：本篇只讲朴素集合论的基础运算与公理化集合论的入门结论、图论的基础概念与几条经典定理；ZFC 公理的完整表述、连续统假设、大基数、 forcing、描述集合论、代数图论（谱图论、群论与图的深层结合）、随机图理论的严格证明、四色定理的完整证明均超出范围；Kuratowski 定理与 Kirchhoff 定理本文只给结论与用法，未逐条推导。
