# 04 组织与文明（协作 · 知识传承）

部定位：突破邓巴数的两件武器——**制度**与**记录**。10 协作与文明讲群体怎么组织起来：分工专业化、历法与度量衡、贸易货币、法律治理、群体防御、信仰仪式、市场机制、艺术音乐；12 文字与知识传承讲知识怎么脱离人脑存续：文字、纸墨、印刷、教育体系、图书馆与记录规范。本部是阶段轴 5（信息与组织）的主体。

## 阅读顺序

1. 群体成形后先立规则与分工：群体组织 → 资源管理 → 决策与冲突处理 → 度量衡与历法。
2. 交换与货币先朴素后制度化；与 06 现代域的 19 经济与金融互为表里——10 域讲"怎么长出来"，19 域讲"怎么设计好"。
3. 知识积累到必须外存时上文字与纸墨（12 域），印刷之后教育体系随之成型。
