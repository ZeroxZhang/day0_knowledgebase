# 牙、耳、眼与鼻的常见急症

层级：基础
视角：从零重建 / 通用
阶段：0～5
状态：待核验
更新时间：2026-09-12

## 解决什么问题

在没有牙科与抗菌药物的时代，一颗坏牙引发的感染足以致死——牙源性感染是历史上的顶级死因之一（历史背景为通识表述，考古与统计口径列入文末待核验），牙、耳、眼、鼻四个感官器官的急症共同特点是：**起病时都只是"小麻烦"，拖错方向就变成大问题**——牙痛拖成深部感染、耳痛拖成穿孔流脓、眼伤拖成单眼失明。本文回答六件事：

1. 牙痛怎么用五个自查动作一级一级判断到"多深"，感染扩散的六条红旗（本篇最重的部分）；
2. "该不该拔牙"的判断边界与不做什么的红线；
3. 牙齿磕断、磕掉的保存纪律与牙龈出血的分岔；
4. 耳痛的两个动作测试（这两个动作能分掉一半的耳痛）；
5. 眼的"会不会瞎"分级：异物、化学溅入、红眼三分岔、眼外伤遮盖；
6. 鼻出血的正确压迫与反复出血的警惕。

判断导向总链（本篇每一节都按它走）：症状 → 自己能做的判断动作 → 分级（**自愈观察级 / 需要照护级 / 危险级**）→ 无药处置边界 → 何时转入 [无医条件下的医疗体系](12_care_system_rebuild.md) 的可救性分诊。

分工边界：急救动作（止血、冲洗、包扎的手法）在 [基础急救流程](../05_health/01_first_aid_basics.md)；生命体征与病情三级在 [症状评估与病情判断](02_symptom_assessment.md)；本篇管四个感官器官的专门识别与判断。[无医条件下的医疗体系](12_care_system_rebuild.md) 的卫生员规程应把本篇的判断卡并入：晨巡表加"张口几指、牙龈有无鼓包、眼白颜色、耳道有无渗液"四项，牙、耳、眼各配一张判断卡（见"从零实现路径"）。

阅读前提：知道病情三级与问诊八要素（[症状评估与病情判断](02_symptom_assessment.md)），认识口腔与耳的结构（[人体结构与生理基础](01_body_systems.md)）。

## 核心知识与原理

### 1. 牙：从刺激痛到脓肿的判断树

**为什么牙痛要一级一级判断**：牙不是一块死骨头。牙最外层是**牙釉质**（零基础解释：牙表面那层最硬的壳），里面是**牙本质**（零基础解释：釉质下面稍软的一层，布满通向内部的细管），再里面是**牙髓**（零基础解释：牙中心含神经与血管的活组织，俗称"牙神经"）。感染从外向内走一层，判断升一级，风险也升一级。

#### 判断树（痛的规律 → 级别）

| 病名（判断） | 痛的规律 | 级别 |
| --- | --- | --- |
| 龋齿（零基础解释：俗话的虫牙——细菌在牙面腐蚀出的洞，不是真有虫） | 冷、热、甜刺激时痛，刺激一走就停，痛只在一颗牙，能指准 | 自愈观察级 |
| 可逆性牙髓炎 | 同龋齿，但难指准是哪颗牙 | 自愈观察级（复测频度加密） |
| 不可逆性牙髓炎 | 不碰它也自发地一阵阵痛；刺激后痛持续数分钟不止；夜里躺下更重（夜间加重为通行经验，所查来源页未列，见文末） | 需要照护级 |
| 牙髓坏死→根尖脓肿（根尖：零基础解释——牙根最尖端扎在颌骨里的那个头） | 持续痛、咬东西加重、能准确定位患牙；牙有"浮起来变高"的感觉 | 需要照护级（无红旗时） |
| 牙周脓肿（零基础解释：牙龈边上、牙根旁的脓包，脓在牙龈里不在牙心） | 牙龈边鼓包、按痛明显 | 需要照护级（无红旗时） |
| 智齿冠周炎（智齿：零基础解释——最里侧最后长出的磨牙；冠周炎：牙冠周围盖着的牙龈发炎） | 最里面牙龈肿痛、咀嚼时钝痛、张口痛 | 需要照护级（无红旗时） |

任何一级只要出现下文红旗征，直接升危险级。

#### 五个自查动作（无装备也能做）

1. **照**：让人背对日光，用磨亮的金属片或一碗清水的水面把光反进嘴里（有手电更好），看可疑牙面有没有黑褐色洞、牙龈上有没有鼓包——鼓包中央发白，就是脓在包里。
2. **含**：含一口凉水在可疑牙那侧，心里数两个数后吐掉，再数几个数看痛停没停。吐掉后两三个数内痛停=还停在龋齿～可逆牙髓炎这级；痛好几分钟不停=升到不可逆级（来源页口径：可逆性牙髓炎刺激除去后 1～2 秒疼痛停止，已核对）。
3. **咬**：把干净布卷成小卷，用可疑牙咬紧再突然松开——咬紧痛加重=根尖有炎症；咬紧不痛、松开瞬间尖锐痛=牙冠有裂纹（已核对：牙冠不完全折裂的表现）。
4. **按**：洗净手指隔着嘴唇按压痛点对应的牙龈——根部鼓包且一按像按熟透的果实那样软弹（**波动感**，已核对：波动性触痛提示脓肿将破溃），是脓已聚起的标志。
5. **量**：把并拢的手指竖着往上下门牙之间放。能放进三根以上为开阔口；只容一两根、或比疼痛之前明显变窄=**张口受限**（现场度量口径为通行做法，未系统核对，见文末）。

一个假牙痛要排掉：多个上颌后牙一起敏感、低头系鞋带时痛加重、伴流鼻涕——方向是鼻窦不是牙（已核对），按 [呼吸系统常见病](05_respiratory_diseases.md) 的鼻窦线走。

#### 感染扩散红旗征（最高优先级，出现任一即危险级）

牙的感染不老实待在牙里——它顺着颌骨与筋膜间隙往深部走。以下任何一条出现，说明感染已不只是牙的问题：

| 红旗 | 说明感染到了哪 |
| --- | --- |
| 面部/牙龈肿胀在蔓延（从牙根一路肿向脸颊、眼下） | 蜂窝织炎（零基础解释：细菌在皮下组织里弥散蔓延的感染，红肿边界不清、一天比一天推远） |
| 张口受限（按上条"量"） | 咀嚼肌间隙受累，下磨牙感染常见（已核对：牙关紧闭——咀嚼肌痉挛把嘴锁住） |
| 吞咽困难、咽东西剧痛、口水多到咽不过来往外流（**流涎**：零基础解释——口水咽不下去往外淌）、舌头被顶得抬高或伸不直 | 下颌下间隙感染（已核对） |
| 口底（舌头下面）肿胀发硬、按痛 | 口底蜂窝织炎（路德维希咽峡炎）——能把气道挤闭，是下颌牙感染最凶险的走向（已核对） |
| 发热 | 一般的牙源性感染不发热；一旦发热=感染明显扩散的信号（已核对——这是牙病判读里最重要的发热纪律） |
| 睁眼困难、看东西重影、眼球鼓出、瞳孔异常 | 感染经静脉丛向眼眶与颅底走，海绵窦血栓性静脉炎的前奏，有致命危险（已核对） |

红旗出现的纪律：立即按最高级病情对待（[症状评估与病情判断](02_symptom_assessment.md) 第 7 节），执行支持治疗四支柱（[感染性疾病总论](03_infectious_diseases.md)），按 [无医条件下的医疗体系](12_care_system_rebuild.md) 的可救性分诊决策资源，并全力寻找任何外部医疗力量。同时记录：每半天用手指比一次肿胀边界，在脸颊上画线——"在扩"或"在退"就有了可读的趋势（同蛇咬伤画线法，[中毒与咬蜇总论](11_toxicology_envenom.md)）。

#### 无药条件下的缓解与处置边界

能做（自愈观察级与需要照护级的共同底盘）：

- **温盐水漱口**：一杯（约 250 毫升）温到不烫手的净水里，两指捻一小撮盐搅化，含在痛侧鼓着腮帮子漱十几秒再吐，一天多轮（配比为通识量级，未经来源核对，见文末）。目的不是立刻杀菌，是冲走脓液与残渣、减少堆积。
- **冷敷**：浸凉水的布拧半干敷在脸颊对应处，布温了重新浸凉；皮肤发麻就先停。
- **保持清洁、避开患侧**：其余牙照常清洁（方法见"从零实现路径"），患侧换另一侧嚼；洞里看得见的大块残渣用细木签顺洞口轻剔出来——只剔看得见的，不往深处捅。
- **记录与复测**：每天用五动作复测一次级别、量一次张口几指、看鼓包大小——趋势比单次感受可靠。

红线（不是"少做"，是"不做"）：

- **不用针、钉、硬物捅牙洞或扎鼓包**：病灶深藏在颌骨里，硬物捅不到，反而把表面的菌推入深处；扎破鼓包可能让脓倒灌。
- **不挤牙龈鼓包**：挤压把脓推向深部。波动感明显且恒定的脓包，切开引流属外科操作，本库一律不写步骤（同 [皮肤与软组织疾病](07_skin_soft_tissue.md) 的脓肿边界）；等它自行向口腔内溃破——多数会破，破后继续温盐水漱口保持引流通畅。
- **"该不该拔牙"的判断边界**：
  - 松动分度（通行分度法，未系统核对）：前后向轻晃=一度；加上左右向=二度；三向都能晃、咬合下压有下沉感=**三度**。
  - 三度松动的残根（牙冠已烂光只剩根）：按"等它自行脱落"预期观察，多数会自己松脱；脱落前后保持漱口清洁。
  - 牢固的病牙一律不拔。拔一颗牢固牙要斩断它在颌骨里的固定结构：无麻醉下的剧痛是小事，**出血难止、感染被压进深部间隙、断根留在骨里成为新感染源**——三条都是历史上真实的死因路径。本库不做"教拔牙"：拔与治一样超出无医能力，只能交给有工具、有经验、能处理后果的人。

#### 牙齿外伤

**磕断（牙折）的判断**（已核对的分类）：

- 只崩了壳（釉质）：摸着粗糙或锐利，无冷热敏感——锐边留待有工具时磨钝，别用舌头反复去刮。
- 崩到牙本质：对冷水与吸气明显敏感——按龋齿级的刺激纪律处理，避免刺激。
- 断口见血或有渗血点=牙髓暴露（已核对：露髓的识别标志就是出血）——危险级，感染通道已开。

**完全磕掉（撕脱）——以分钟计的保存纪律**（已核对）：

1. 恒牙（换过牙之后长出的那副）磕掉：只捏牙冠（露在嘴里的部分），不碰牙根；冷水下轻轻冲掉泥，**不超过十个数，绝不擦洗**（牙根表面一层活的纤维膜——牙周膜——是再植愈合的关键，擦掉就失败）。
2. 随即把牙按原方向按回牙槽窝（零基础解释：颌骨上容纳牙根的坑窝）里，让伤者咬一块干净布保持咬合。
3. 实在放不回去时，依次浸入盐水、牛奶，或用湿布包着；都不行且伤者清醒能配合时，把牙含在口中两腮处带去寻医。
4. 时间窗：**30 分钟到 1 小时内复位，牙可能永久保住；拖过 1 小时，保留率明显下降**（已核对）。固定（细丝夹板）属牙科操作，本库不写——保存好、记录磕掉时刻、全力寻找能固定牙的人。
5. 乳牙（婴幼儿那副小牙）磕掉了：不再植——它易坏死感染，等恒牙即可（已核对）。
6. 接触过污泥的牙外伤：按破伤风风险评估（[感染性疾病总论](03_infectious_diseases.md)）。

**牙龈出血**：

- 刷牙或咬硬物时渗血、牙龈红肿边=牙龈炎起点，是清洁不足的信号——对策是清洁升级而不是停刷（越出血越要清洁到位，数日内血会退；此为通行经验，未系统核对）。
- 无诱因自发出血、渗血不止、伴全身多处瘀斑——查全身这条线：血小板与凝血方向见 [血液与循环系统疾病](06_cardiovascular_blood.md)；长期不吃新鲜食物时想到维生素 C 缺乏（牙龈松肿出血是其表现之一，食源见 [营养基础](../03_food/01_nutrition_basics.md)）。

### 2. 耳：两个动作测试定一半

耳痛先做两个动作测试，再谈判断——这一对测试是本节核心：

- **拉耳廓、压耳屏**（耳屏：耳道口前方那块小软骨凸起）：拉扯耳廓、按压耳屏时痛明显加重=痛在外耳道（外耳道炎的标志性体征，已核对）；拉压不加重=痛在鼓膜里面（中耳方向；这一侧为通行鉴别常识，见文末）。
- **想前因**：前几天感冒流鼻涕=中耳方向的燃料；最近游泳、洗头进水、掏过耳朵=外耳道的燃料（已核对：进水与棉签是外耳道炎两大主因）。

| | 中耳炎（急性） | 外耳道炎（急性） |
| --- | --- | --- |
| 诱因 | 感冒后，经咽鼓管（零基础解释：鼻咽通到中耳的管子）上行（已核对） | 耳道进水、棉签掏伤（已核对） |
| 痛 | 深在胀痛；发热多见（幼儿可伴呕吐腹泻，已核对）；婴儿可能只表现为烦躁、睡不安（已核对） | 拉耳痛明显；痒重于痛=真菌可能（已核对） |
| 听力 | 闷、下降 | 耳道肿胀堵满时下降 |
| 耳道外观 | 耳道干净，痛在深部 | 耳道红肿、可有脓屑与臭味 |

**中耳炎的一条关键判断**：耳痛突然减轻+开始流脓，不是"好了"——最可能是鼓膜（零基础解释：分隔外耳道与中耳的那层薄膜）被压力顶破了，脓流出后痛随之缓解（已核对：自发穿孔通常可迅速缓解疼痛）。此后按穿孔纪律生活（见下）。

**并发症观察**（已核对）：耳后乳突（耳廓后下方骨头隆起处）红肿压痛=感染进乳突骨；严重头痛、意识模糊、面歪、天旋地转的眩晕=感染向颅内或内耳走——危险级，立即按 12 篇分诊。

**耳道异物与昆虫**：

- 昆虫入耳：先试"灯引"——暗处把手电（火把）照在耳道口外，一部分趋光昆虫会循光自己爬出（通行做法，未系统核对）。不奏效就不掏不灌：鼓膜状态未知时向耳道灌任何液体（油、酒、水）都可能与穿孔撞车；交由能看清耳道的人处理。
- 膨胀性异物（豆类、种子、面团类）**绝对禁止灌水冲洗**——遇水膨胀，越冲越取不出（已核对）。
- 圆滑异物（小珠、小石）：不掏（越掏越往里滑），交由能取的人。
- 幼儿往耳鼻里塞东西是高发情形——预防（小物件收好）比取出容易一万倍。

**鼓膜穿孔**：

- 表现（已核对）：掌击、爆炸声浪、进水灌压、异物捅入、头部撞击后，突发剧痛、耳内出血、听力下降、耳鸣（零基础解释：耳里响但没有外界声源）；眩晕=内耳受累信号，比穿孔本身重。
- 纪律（据已核对内容归纳）：多数穿孔能自愈——前提是**干燥**。洗澡洗头时用涂了油脂的布团松松挡在耳道口（医学页写"沾凡士林的棉球"；从零条件下用煮过的油脂布团替代，只挡口、不塞深），不下水游泳；**穿孔未确认愈合前，任何东西不进耳道**——油、奶、草汁、湿布团一律不滴不塞。24～48 小时后才出现的脓性耳漏=感染信号（已核对），按中耳炎+穿孔双纪律观察。
- 穿孔超过两个月不愈、听力持续差——记入病历（12 篇），作为长期观察对象。

**听力下降的排查顺序**（从最常见排起）：

1. 耵聍栓塞（耵聍：零基础解释——耳垢，外耳道皮肤正常分泌物的积块；它是外耳道堵塞最常见的原因，已核对）：闷、听力下降、耳鸣、无痛。照光看，棕黄色硬块堵住耳道即为它。软化取出的边界：软化剂可滴入软化数日后随冲洗排出（医学页列明过氧化氢、甘油、矿物油一类，已核对；从零条件下的就地替代物未核对，见文末）；**红线（已核对）：鼓膜穿孔或耳道可疑感染时不得冲洗**；棉签掏只会把耵聍推到深处压实（已核对）——耵聍栓塞多半正是棉签掏出来的。
2. 感冒后+耳痛→中耳炎（上表）。
3. 外伤后→穿孔（上节）。
4. 缓慢进行、无痛、照光见鼓膜完整耳道干净→需要照护级，记入病历观察，累积记录再判。

**流脓的处理与干燥纪律**：流脓=耳道内感染活跃的信号，来源（中耳经穿孔流下/外耳道自身）用上表对号。处置核心是"干"与"畅"：不用东西深塞堵脓（引流不畅反而封住感染）；每天用净布沾干耳道口外溢的脓（只擦看得到的地方，不深入）；洗头洗澡堵口防水；脓超过一周不减、或伴痛与发热——升级照护级。

### 3. 眼：先分"会不会瞎"

眼病判断的第一问不是"什么病"，是"会不会瞎"——眼组织的耐受窗口比任何器官都窄。总分级：

- **自愈观察级**：眼红有分泌物、擦掉分泌物视力清楚、无剧痛无畏光（结膜炎方向）；
- **需要照护级**：异物感持续、轻度擦伤、传染性分泌物的隔离管理；
- **危险级**（任一即入）：化学溅入；异物嵌入或可疑穿入眼球；视力突然下降；剧烈眼痛+头痛；看灯有彩虹色光晕；**真性畏光**（零基础解释：怕光怕到遮住另一只眼、患眼仍痛——角膜或深层组织受累的信号，已核对）。

**异物**：

- 第一反应永远是冲，不是找：净水最好，没有就用手边任何相对干净的水（判水见 [水净化](../02_water/04_water_purification.md)）；水流从内眼角侧流向外眼角侧（防好眼污染的方向，规范出处待核验），横扫过眼球表面把异物带出；**不把水流直接怼在异物上**（已核对：勿将冲洗液直接对准异物）。先冲够再判断；揉眼是绝对禁手——揉一次，擦伤多一道。
- 冲不出再翻眼睑找（动作分解，据已核对方法改编）：
  1. 让人往脚的方向看，拇指轻拉下眼睑（下眼皮）往下——看下睑内面与下穹窿（零基础解释：眼皮与眼球之间的折袋）里有没有粘着的小粒；
  2. 让人往头顶方向看：一根干净细棍（筷子杆、光滑小枝）横压在上眼睑中上部的眼眶骨上，捏住上睫毛把上睑缘向上翻起搭在细棍上——看上睑内面（此即"上睑双重外翻"的无工具改编，原法用棉签，已核对）；
  3. 无工具的替代手法：捏住上睫毛向下向外拉，让上睑盖过下睑再松开，用下睑内面刷带上睑内面的异物（通行手法，未系统核对，见文末）；
  4. 看什么、怎么判：**上睑内面有异物时，眼球上的擦痕是竖直的细线**（眨眼刮出来的）——见到多条竖线状的眼红磨痛，翻上睑找，多半能找到（已核对）。找到的小粒用湿布角轻轻一沾即出；**一沾就动=表面异物，可取；扎进黑眼珠（角膜：零基础解释——黑眼珠表面那层透明窗）里不动=嵌入异物，红线：不取**。
- 嵌入与穿入的红线（已核对）：受伤机制是敲石、金属对金属、锤击、爆炸碎屑——哪怕伤口看起来轻微，也按"异物已进眼球"对待。纪律三条：**不对眼球施加任何压力**（不揉、不压、不加压包扎）；**不取异物**；**做眼盾罩住**——眼盾（零基础解释：罩在眼眶骨缘上、不接触眼球的硬质杯罩）从零条件用树皮卷成的浅杯、掏空的瓜壳、磨光滑的陶碗沿代替，布条绕头固定，压力全部落在眶骨不落在眼球（医学页明确：纸杯或泡沫杯修剪后置眶缘即为合格临时眼盾，已核对）。然后按危险级转 12 篇分诊，并记录受伤机制。

**化学溅入**（石灰水、草木灰水、皂液属碱类——碱灼伤液化坏死、穿透更深，重于酸；已核对机制）：

- 立即冲、就地取水：**任何液体都比等待强**（已核对：生理盐水、无菌水、自来水均可）——为找"最好的水"多耽搁的每一分钟都是损失；
- **冲多久：至少 30 分钟**（已核对口径），量级以持续不断地冲为准（医学页建议 1～2 升量级，已核对）；
- 冲法：头侧偏、伤眼朝下，水从内眼角流向外眼角，别让它流进另一只好眼；让人不停眨眼转动眼球；
- 冲完翻开上下眼睑检查折袋里有没有残留颗粒（已核对：穹窿残留是持续灼伤的第一原因），有颗粒用湿布角沾出再冲；
- 冲完仍属危险级：化学伤的损伤在之后几天内继续演进，按 12 篇分诊并记录观察至少数日。

**红眼的三个分岔**（结膜炎/黄疸/青光眼）：

- **结膜炎**（零基础解释：白眼珠表面那层透明膜的发炎，俗称红眼病）：眼红+分泌物+磨感，无剧痛无畏光。分泌物性状给线索（已核对）：脓稠黄=细菌性；清水样=病毒性；痒到钻心、清水丝状=过敏性。一条简易视力判断（已核对）：稠分泌物糊住视线造成的模糊，擦掉后视力应当恢复清楚——**擦了仍模糊=不是普通结膜炎，升级**。
- **传染纪律**（传播方式已核对：飞沫、污染物、手眼接种）：病人专用毛巾与枕巾，毛巾用后煮沸晾晒；摸过病眼的手立即洗（[感染预防与个人卫生](../05_health/03_infection_prevention.md)）；病人暂离共餐共劳（隔离逻辑同 [感染性疾病总论](03_infectious_diseases.md)）；不摸病眼后摸健眼——一眼传另一眼是最常见的自家路径。
- **巩膜黄染**（零基础解释：白眼珠被染成黄色）不是"眼病"——它是黄疸（零基础解释：血中胆色素升高把组织染黄）在眼白上最准的显示窗，指向肝胆与血液：白眼珠黄+尿呈深茶色=黄疸信号，根因排查见 [症状评估与病情判断](02_symptom_assessment.md) 第 9 节与 [血液与循环系统疾病](06_cardiovascular_blood.md)。
- **青光眼急性发作**（零基础解释：眼内压力急升、损伤视神经的眼病；已核对，来源为大众版页面）：剧烈眼痛伴同侧头痛+眼红+视物模糊+看灯泡周围有彩虹色光圈（俗称虹视）+突发视力下降——**不及时治疗，视力可在 2～3 小时内完全丧失**（已核对）。它是危险级里时间最急的一种：鉴别提示——结膜炎按眼球是软的，青光眼按起来硬如石（通行手法，未系统核对）——确认后全力转 12 篇分诊；头痛红旗的其余鉴别见 [神经与精神常见问题](09_neuro_mental.md)。

**眼外伤与遮盖**：

- 角膜擦伤（黑眼珠表面被刮花）：磨痛、流泪、怕光、视力多数不差——冲净后静养，愈合以天计；**不按压包扎**（已核对：加压眼垫不减痛不促愈、反增感染风险）；遮盖只做"松松挡光"，压力不落在眼球。
- 单眼遮盖的用途：异物伤后护眼、畏光难忍时减光——一律松罩不加压；穿透伤只用眼盾（见上红线）。
- 雪盲（雪地强反射光灼眼）的预防与处理已在 [皮肤与软组织疾病](07_skin_soft_tissue.md) 晒伤节覆盖，本篇不重复。

### 4. 鼻：压迫的纪律

**鼻出血**：多数来自鼻中隔（两个鼻孔中间的隔板）前下方的一片血管网——利特尔区（已核对）——这正是"捏鼻翼"能止血的解剖原因。

- **位置**：拇指食指捏紧两侧鼻翼（鼻孔外下方软的那两片软骨翼），把鼻孔捏闭合、压向鼻中隔方向——不是捏鼻梁（捏鼻梁什么也压不住）。
- **头位**：坐直（医学页口径：坐直、捏住鼻孔 10 分钟，已核对）；身体稍前倾让血从前鼻孔流出、不咽下（通行补充，未系统核对）；**不仰头**——仰头把血顺咽部咽下，既掩盖出血量又刺激呕吐（通行常识，未系统核对）。
- **时长与复测**：捏住 10 分钟，用口呼吸；松开看还流不流——还流，再捏 10 分钟（复捏口径为通行做法）；两轮不止=按"直接按压无法止血"的红旗对待（已核对列为危险信号），手压无效可用鼻夹或两根压舌板绑扎的自制鼻夹（已核对）。
- **出血后纪律**：不擤鼻、不抠、不低头猛起身；让结痂自己掉。
- **红旗**（已核对危险信号清单）：按压不止；出血伴面色苍白、脉快、皮肤湿冷（失血量级判断见 [血液与循环系统疾病](06_cardiovascular_blood.md)）；反复发作尤其找不到诱因；**固定单侧反复出血**——要想到鼻腔里长了东西（肿瘤是不常见但明确的病因之一，已核对）或异物存留。
- **鼻腔异物**（多见于幼儿往里塞东西）：线索单侧鼻涕带脓带臭（典型信号，未系统核对，见文末）。边界：**不掏、不冲、不逼猛擤**——掏把异物推深，冲可能让它膨胀，猛擤把它顶进咽部有呛入气管的风险；交由能看清鼻腔的人取出。营地里任何"两极金属小件"（电池类）入鼻属立即危险——其内容物短时间能烧穿隔板（未系统核对，从零条件下无此类物件，应急视角保留此条）。

## 从零实现路径

本篇的"从零"指：没有牙科器械、没有耳镜、没有裂隙灯，只有手、光、凉水与盐。路径按"无装备条件下的判断与处置"写。

**第 1 日：口腔清洁制度落地。** 每天饭后与睡前，每人用煮过的软布缠在指尖蘸温盐水（配比同第 1 节）擦牙面与牙龈内外两面，或咀嚼嫩枝末端压散成刷状擦牙（嫩枝清洁法通行于多种文化的历史清洁实践，未系统核对）；牙缝残渣用细木签顺缝轻剔，不横捅。制度的意义：本篇大多数牙痛的源头是龋，龋的源头是残渣与甜食的滞留——清洁是从零条件下唯一可执行的"治未病"，甜食入账与清洁挂钩（食物分配见 [盐糖油脂获取](../03_food/06_salt_acquisition.md) 一带的甜食纪律）。

**第 1 周：四张判断卡上墙**（规程册形式见 12 篇）：

- 牙卡：自查五动作（照、含、咬、按、量）+ 红旗六条 + 三条红线（不捅、不挤、牢固牙不拔）；
- 耳卡：两动作测试 + 穿孔三禁（禁进水、禁滴物、禁冲洗）+ 膨胀异物禁水；
- 眼卡：危险级六问（视力降没降？剧痛不痛？怕光畏不畏？擦掉分泌物清不清？灯有没有彩圈？机制是不是敲击飞溅？）+ 冲眼三步 + 眼盾制法；
- 鼻卡：捏鼻翼十分钟 + 红旗四条。

**第 1 月：晨巡加列。** 卫生员晨巡表（[无医条件下的医疗体系](12_care_system_rebuild.md) 的病历制度）每人加四项：张口几指、牙龈有无鼓包、眼白颜色（黄/红/正常）、耳道有无渗液——四个器官的病都适合"看一眼"式筛查，儿童由家长代查。

**演练一次：** 假想三个病例各走一遍——"半夜自发牙痛"（含冷水测试复测到不可逆级）、"敲石头崩了眼"（穿透红线三纪律+眼盾制作）、"洗头后耳痛"（两动作测试定方向）。判断卡的用途在肌肉记忆，不在阅读。

**长期：外伤源治理。** 敲石、磨石、劈柴、窑口作业的工位固定，站位避开他人面部与作业面切线——眼外伤的预防成本是零（换工位），治疗代价可能是半只眼。作业面与眼外伤的第一机制（敲击飞溅，已核对）直接对应（工位组织见 [石器打制](../07_tools/01_stone_tools.md)）。

**依赖链**：[人体结构与生理基础](01_body_systems.md)（器官正常态）→ [症状评估与病情判断](02_symptom_assessment.md)（三级与记录卡）→ 本篇（四器官专门判断）→ [无医条件下的医疗体系](12_care_system_rebuild.md)（分诊与照护装配）。支持动作：[基础急救流程](../05_health/01_first_aid_basics.md)、[伤口处理与止血](../05_health/02_wound_care.md)；冲眼用水的判断：[水净化](../02_water/04_water_purification.md)。

## 方法与应用

有残留物资时：

- **手电与放大镜**：照口腔、耳道、眼睑内的标准装备（照法同前，光更稳、可双手操作）；
- **生理盐水与冲洗器**（注射器、洗瓶）：冲眼、冲洗牙缝；冲耳道仅在鼓膜确认完好时；化学伤按 30 分钟口径执行；
- **牙线**：替代木签，顺缝轻拉，不压牙龈；
- **成品眼盾**：合格标准不变——硬质、扣在眶骨缘、不触眼球；
- **鼻夹**：手压无效时代替手指（医学页亦列此物，已核对）；
- **体温计**：牙源性红旗"发热"的客观化——手背对比法照常可用（02 篇）。
- 仪器只提高精度，不改变分级界标——仪器缺席时本篇程序照常运行。

## 常见错误与限制

- **错误：牙痛硬扛到肿脸才处理。** 为什么会发生："牙痛忍忍能过"的经验。后果：跳过龋齿级直达脓肿级，失去最便宜的窗口。正确做法：每天用五动作复测级别，级别上行就升级处置。
- **错误：针挑牙洞、挤牙龈鼓包。** 后果：感染推深、脓倒灌。正确做法：漱口引流+三条红线。
- **错误：把"松了"当"该拔了"。** 后果：把可自行脱落的拖成强拔，把牢固牙拔出出血、感染、断根三个并发症。正确做法：松动分度判断+牢固牙不拔的边界。
- **错误：棉签掏耳朵。** 为什么会发生：耳痒的即时满足。后果：耵聍推深压实（栓塞多半正是掏出来的）、划伤耳道给外耳道炎开门、失手捅破鼓膜。正确做法：耳痒找原因（进水/真菌），要掏只到耳道口看得见的浅表。
- **错误：耳痛突然不痛=好了。** 后果：穿孔流脓被当痊愈，进水反复感染。正确做法：痛缓解后检查有无渗液，有渗液按穿孔纪律执行。
- **错误：眼化学伤先去找干净水。** 为什么会发生："不干净的水会感染伤口"的直觉在这里用错了对象。后果：找水的每分钟，碱都在眼球上继续烧。正确做法：就地任何水立即冲，时长优先于水质（已核对）。
- **错误：结膜炎病人与健康人共用毛巾脸盆。** 后果：全营红眼（手眼接种+污染物传播，已核对）。正确做法：专巾煮沸、摸眼后洗手、病人暂离共劳。
- **错误：流鼻血仰头。** 后果：血咽下、出血量被掩盖、呕吐再撕开血痂。正确做法：坐直（前倾补充见文末）捏鼻翼十分钟。
- **错误：幼儿的耳鼻眼问题"问不出来"就当没事。** 后果：幼儿中耳炎可以只表现为烦躁睡不安（已核对），塞入异物自己不会说。正确做法：对幼儿把"看"提到"问"之前——看抓耳挠腮、看单侧流涕、看频繁揉眼。
- **限制声明**：本篇给的是"判断与保守处置"。凡切割、拔除、取出嵌入物、牙齿固定，均属本库不写的操作（安全边界：不提供手术细节）；无医条件的真实上限是"不让轻症变重症、不让重症无人知"——牙源性感染扩散、青光眼、眼球穿入伤三类的最终结局不由判断水平决定，判断的价值是让这三类尽早被识别并进入 12 篇的资源决策。儿童与老人按成人同表使用，特异性界值未核对（文末）。本篇不含任何药物用法用量。
