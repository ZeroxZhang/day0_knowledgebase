# 14 基础医学

解决的问题：身体怎么运作、疾病怎么识别判断、在没有医院与药品的条件下怎么照顾病人。**重点参考来源：《默沙东诊疗手册》专业版**（https://www.msdmanuals.cn/professional ）——已核对子项均注明所查页面。

与 [05_health](../05_health/README.md)（急救与健康）的分工：05_health 是**动作导向**的现场处置（急救、伤口、卫生、公共卫生）；本领域是**知识与判断导向**的医学基础（生理、评估、疾病识别、无医条件下的照护逻辑）。互链不重复。

**安全边界（最高优先）**：本领域不写处方剂量、不写药物用法用量、不写手术操作细节；一切"做什么"以支持性照护与预防为限；识别"超出无医条件能力"的情形并转照护/等待，本身就是核心技能。

## 写作纪律（本领域特有）

1. 已核对子项必须注明默沙东诊疗手册专业版页面名与检索日期；未核对项诚实列入待核验。
2. 每篇给"无医条件适配"：没有 X（药/器械/检验）时，能做什么、判断什么、何时认定超出能力。
3. 不给剂量、不给处方；公共健康标准配方（如 WHO 口服补液盐）须声明性质并标注来源。
