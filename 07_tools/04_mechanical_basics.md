## 解决什么问题

手推不动、拧不紧、转不起来的东西，靠什么原理能省力？坏了的轮轴、链条、皮带、螺栓，怎么判断问题、怎么拆装更换？

本文解释手动工具和常见机械背后的力学原理，让使用者理解"为什么这样用"，而不是死记操作。

适用场景：修理手推车/自行车/水泵/门窗铰链，选择省力方案（撬、滑轮、绞盘），拆装螺纹连接和常见传动件。

## 核心知识与原理

**简单机械只有两类母体**：杠杆和斜面。轮轴、滑轮是杠杆的变形；螺纹、楔子是斜面的变形。判断任何省力装置，先找"支点在哪、力臂比是多少"——**支点**就是装置绕着转或抵着顶的那个不动的点。

**杠杆**：

- 省力比等于力臂比（施力点到支点的距离与重物到支点的距离之比）。撬棍垫块越靠近重物越省力。
- 代价是用力端移动距离按同比例增大——**省力必然费距离，能量不凭空产生**，这是所有机械的第一条铁律。

**滑轮组**：

- 改变拉力方向的定滑轮不省力；动滑轮省一半力。
- 滑轮组省力倍数≈承担重量的绳段数 n（忽略摩擦与绳重），绳端拉过的距离是重物上升距离的 n 倍。
- 绳段数数法：只数"直接连在动滑轮上、随它一起走"的绳段。

**斜面与螺纹**：

- 斜面用较长路径换较小推力。把斜面卷起来就是螺纹：**螺距**（螺纹转一整圈前进的距离）越小越省力、锁得越紧，拧得也越久。
- 千斤顶就是典型的斜面/螺旋省力机构。

**轮轴与齿轮传动**：

- **传动比** = 主动轮（动力先进入的那个轮）与从动轮（被带动的轮）的直径（齿数）比。变速自行车、手摇绞车都是通过传动比在"力量"与"速度"之间交换。
- 降速增扭、增速减扭，功率（力×速度）在忽略损耗时不变。
- 判断要省力还是要快：小轮带大轮 = 降速省力；大轮带小轮 = 提速费力。

**摩擦与润滑**：摩擦既是阻力（轴承发热、磨损）也是咬合的来源（皮带传动、刹车、螺纹自锁）。常见润滑思路：

- 相对滑动面用油（油膜隔开表面）；
- 重载低速用脂（不易甩出）；
- 粉尘环境宁可用干式自润滑材料也不要油（油粘灰变成研磨膏）。

**螺纹连接的可靠性**：螺纹靠拧紧产生的夹紧力和摩擦**自锁**（不外加力时靠自身摩擦保持不松的状态）。振动会逐步克服摩擦使螺母回松——这是机械故障中占比极高的一类。

防松手段（弹垫、双螺母、尼龙圈锁紧螺母、螺纹胶）本质都是维持摩擦或机械限位。

## 从零实现路径

没有现成机械件时，省力装置全部可由木、石、绳搭建（依赖链：先有石器加工木件，先有纤维绳索承担拉力）：

1. **撬棍**：直纹硬木棍 + 一块垫石即支点。使用铁律：垫石尽量贴近重物，木棍受力端不出裂纹、不闻"吱嘎"声。

2. **滑轮组**：轮子可用刻槽的硬木圆盘或陶轮替代滑轮（绳走槽不走棱）；没有轮时直接"绳绕树干/横梁"摩擦改向——损耗大但仍可用。

   绳用植物纤维三股绞合绳（见 [绳索与绳结](../09_materials/03_cordage_knots.md)），承重前先吊超重物两倍的重物试拉。

3. **斜面**：土坡垫木搭斜桥拖重物上高台，比垂直吊拉省力且稳。

4. **绞盘**：立柱缠绳数圈、推杆转动立柱收绳——省力巨大但速度极慢，适合平地拖曳重物（船、巨石）。

5. **螺纹从零**：无机床阶段没有真螺纹，靠木销、绑缚、楔子完成"紧固"功能；螺纹件的出现依赖阶段 4 的简易车床（见 [简易机床与车削](07_primitive_lathe.md)）。

6. **轴承从零**：木轴与木孔间抹动物油脂，轴孔嵌硬木或骨套减磨——寿命短、需常保养，这是"轴承为什么值钱"的直观教材。

## 方法与应用

**省力方案选择**（按移动重物的常见顺序）：

1. 能滚不撬：圆柱体和带轮设备直接滚动或垫滚杠（圆木或钢管垫在重物下当滚轮），比重撬安全。

   操作要点：滚杠与行进方向垂直，前方随时续垫新滚杠、身后抽出的滚杠移到最前——三根滚杠轮换即可连续前进；改向时用锤轻敲滚杠端头调整角度。

2. 撬：撬棍+垫块（垫块就是支点），抬起量小但可控，配合垫木块"逐步顶进"——每撬起一点就塞进一块垫木，撬空时重物永远被垫着。

   判断省力程度：垫块到重物的距离越短越省力；撬棍吃力后出现吱嘎声或压痕，说明换支点或加长撬棍。

3. 顶：千斤顶顶升，顶起后**必须垫实枕木再进入重物下方**，千斤顶只顶不撑。垫实标准：枕木与重物底面之间塞不进手掌的缝隙才算垫实。

4. 拉：滑轮组或绞盘水平牵引，先评估固定点强度，固定点失效比绳断更常见——判断固定点：选立柱根部、大梁等整体结构，晃动时整栋结构一起动才可用；挂绳后先拉到半载再停车检查一次固定点，无位移异响再拉满。

**螺纹拆装规范**：

- 判别旋向：绝大多数螺纹右旋（顺时针拧紧）。左手边受力的连杆、部分风扇和自行车脚蹬可能是左旋（端面有 L 或反牙标记）——拧不紧先怀疑旋向，别先用力。
- 锈死螺栓：按顺序处理，每步见效果才进下一步：
  1. 渗透油浸润（滴到螺栓杆与螺母结合缝，看到油渗入即可，静置十分钟以上）；
  2. 轻敲震松锈层（锤头对准螺母侧面敲两三下，看到锈屑从缝里掉出来为准）；
  3. "紧半圈再松"往复松动——先向拧紧方向拧四分之一圈（把锈层压碎），再向松的方向拧，每次幅度不超过半圈，往复到能整圈转动；
  4. 实在不行加热膨胀或破坏性切除。一次性破坏螺母（錾开或锯断）比反复硬拧损伤螺杆更划算。
- 装配：螺纹对正后先手拧到位，再上工具；感觉到"发涩、有沙粒感"立即退回，那是错牙在硬攻，继续拧必滑丝。
- 成组螺栓（缸盖、法兰）：对角交叉、分两三次逐步拧紧，保证受力均匀不变形。
- 防松：经常振动部位用尼龙自锁螺母或加弹簧垫圈；关键连接可加开口销或止动垫片。

**常见传动件的检查与更换**：

- 皮带：
  1. 看裂纹——横向裂纹（垂直于带长方向的）多条即更换，纵向裂纹尚可用；
  2. 按压力判断张紧度——拇指按压皮带中段，一般以按下挠度约为两轮中心距的 1%～2% 为经验参考（具体值待核验）；
  3. 听——运转中"啪啪"拍打声说明过松，"啸叫"声说明过滑。
  4. 更换时先完全卸张紧再取带，不硬撬。
- 链条：测拉伸——拉起一段链条看能否脱离链轮齿根，链条拉长后"咬不上齿"会跳齿，跳齿继续用会打断。链条可截短重接（有截链器时）作为临时恢复；截短的前提是链条仍能绕齿一周，截短后先空转一圈确认不卡再加载。
- 齿轮：检查齿面点蚀（麻点状剥落，指腹能摸到凹凸即重）、断齿和旷量（手掰齿轮正反向晃动，晃角超过半个齿即旷量大）；旷量大表现为冲击异响，多数只能换件。
- 轴承：转动手感有颗粒感、卡滞、异响即换——判断动作：手指捏住内圈慢转，匀滑无声为好；有"沙沙"细粒感尚可用，有"咯噔"卡点即换。无新件时清洗旧轴承并补脂可短期续用，但重载部位不宜。

**失效判断的基本顺序**（三步，每步比上一步投入更多）：

1. 先看：裂纹（尤其孔口、键槽等截面突变处）、变形（弯、扭、鼓）、磨损痕迹（磨亮的接触面、金属粉末堆积）。
2. 再转：徒手转动或扳动，感受旷量（晃动幅度）与卡滞（转动阻力是否均匀）。
3. 后测：量尺寸、查间隙——间隙是否超标，对照同类好件比较最快。
4. 总纲：异响和发热是机械件失效最灵敏的两个前兆，声音变了或温度升了，当天就查，不隔夜。

**绳与拉力的常识**（滑轮组作业的前置）：

- 绳的拉力对固定点的作用是"拉塌"而非"推开"：选固定点时优先整体结构（立柱根部、大梁），而不是看起来结实的孤立物件。
- 受力绳旁禁止站人：绳断瞬间的回弹范围大于绳长，操作者在受力方向侧方，其余人后撤。
- 金属丝和链条传力不打结使用：弯折损伤后承载能力大幅下降（降幅待核验），打结的钢丝绳只应视为废品。

## 常见错误与限制

- 撬动时身体处于撬棍回弹线上：撬棍滑脱或断裂时撬杆会向回弹方向甩出，人永远站在侧面。
- 千斤顶顶起后人进入车底/重物下方无垫实支撑：千斤顶可能缓降，这是致命错误，重物必须另加枕木或支架支撑。
- 用管子套在扳手上加长力臂拧小规格螺栓：超过螺栓**屈服强度**（金属被拉到产生永久变形、卸力也回不去的临界受力）即拉长滑丝，小螺栓的失效是突然的。
- 滑轮组吊重时绳径与滑轮不匹配、绳结不防滑：重载时绳的固定端必须用可靠结或卸扣，不能靠缠绕摩擦。
- 认为润滑越多越好：过量油脂挤入密封外吸附粉尘，反而加速磨损；链条上油后要擦去表面浮油。
- 忽视"省力必费距离"在时间上的代价：滑轮组省 4 倍力就要拉 4 倍绳长，人工作业时要估算总行程再决定方案。
- 左旋螺纹不知情硬拧"越拧越紧"的方向判断错误，直接拧脱或拧断。

## 来源与待核验项

本文为模型通识整理，编写时未逐项比对外部资料。可靠参考入口名称：《机械设计手册》（螺纹连接与防松、传动件章节）、《理论力学》/《机械原理》教材（简单机械与传动比）、《钳工工艺》教材（拆装工艺）。

待核验项：

1. 皮带张紧度的经验挠度比例（中心距 1%～2%）无标准依据，不同带型差异大。
2. 滑轮组省力倍数、斜面/螺纹省力公式为理想状态推论，实际摩擦损耗比例未核对。
3. 锈死螺栓处理步骤中"加热"的适用温度与安全边界（附近有可燃物、密封腔体时不可加热）需要专项资料支持。
4. （扩写新增）滑轮组绳段数数法、"两倍载试拉"的安全倍数、链条旷量"晃角超过半个齿"等经验判断，均未核对资料。
