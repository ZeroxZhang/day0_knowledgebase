# 01 根基层（认知与识别）

部定位：全库的地基，回答两个先于一切技术的问题——**身边的物质是什么、数怎么算**（认知），以及**吃之前、动手之前怎么认出对象**（识别）。不默认读者见过现代世界：从"物质与元素""数与算术"讲起，经数理、物理、化学、生命、地球宇宙到科学方法与现代科学深化；识别体系则给出一套从零建立"认得出"能力的方法论与手册。

根基层是阶段 0 的前置阅读，也是全部技术文章的引用基础——读者"认不出、算不动"，后续任何重建步骤都无从谈起。识别先于制作：吃之前要会认植物，打石器之前要会认石料，冶金之前要会认矿石；本部文章只写"辨认与判断"，制作步骤留在技术各部（用链接互指）。

## 阅读顺序

1. 先读 11_science 的物质与元素、数与算术两篇（全库最底层引用），再按需进入数理、物理、化学、生命分块。
2. 识别篇按需即读：吃之前读可食植物与剧毒蘑菇，打石器前读岩石识别，冶金前读矿物矿石识别——技术各部的依赖链会指回来。
3. 天气气候与地质地貌在选址、找水找矿时读。
