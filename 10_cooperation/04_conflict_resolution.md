# 冲突处理

层级：基础
视角：应急
阶段：0～4
状态：待核验
更新时间：2026-09-12

## 解决什么问题

资源紧张、恐惧与疲劳会让平时好相处的人爆发冲突。
本文讲怎么在小群体里预防冲突升级、调解纠纷、处置破坏性行为，维持群体不散。

## 核心知识与原理

**灾害期冲突的结构性来源**：不是"人变坏了"，而是——

- 资源稀缺放大得失感；
- 未来不确定放大焦虑；
- 信息不透明滋生猜疑；
- 日常礼貌的"缓冲带"（面子、退让空间）消失。

对应的预防手段：资源规则透明（见 [资源管理](02_resource_management.md)）、信息公开、保护每个人的基本尊严。

**升级阶梯**：分歧 → 争执 → 对立阵营 → 破坏行为。
每级的识别信号：
分歧=两人说法不同但还在摆事实讲道理；
争执=音量升高、开始翻旧账、给对方贴标签（"你就是自私"）；
对立阵营=各自找人诉苦、旁人开始站队、饭桌上明显分两拨坐；
破坏行为=藏对方的东西、故意不配合值日、动手或砸东西。
介入越早成本越低；
到"阵营对立"阶段调解者要面对的已经不是事实之争而是面子之争（双方都要争"谁认输"，此时讲清事实没用，要给台阶）；
介入层级的判断：还能坐到一张桌上讲理，就在"分歧/争执"级处理；
一旦出现"各自找人站队"，先拆阵营（分开各自谈话），再谈事情本身；
出现破坏行为则不再调解，转入下文纪律程序。

**情绪的生理机制**：
愤怒/恐惧时人的理性评估能力实际下降
（应激反应：身体进入"战或逃"的应急状态，心跳加快、注意力收窄、思考变慢——这是生理反应，不是装出来的），
此时讲道理几乎无效。
**先降温后处理**不是客套，是让大脑恢复评估能力。

**先降温的具体做法**（比一句"冷静点"有效得多）：

1. 拉开物理距离：把两人分到不同房间或院子两端——距离拉开后心跳和音量都会自然回落。
2. 给手找事做：递一杯水、请对方帮忙搬东西——手的动作能消耗应激状态的紧绷感。
3. 降温期不谈对错：分开后只确认"现在先各自歇会儿，明天上午碰头会说"，不追问、不劝架。
4. 调解人自己先降：发现自己声音提高、想插话时，主动说"我也缓几分钟再来"——两个应激的人只会互相点燃。

**调解的基本结构**：
分开听取 →
各自陈述利益（真正想要的东西：安全感、被尊重、孩子吃饱）而非立场（嘴上咬死的要求：必须他道歉、必须换房间）→
找重叠利益 →
共同拟定方案 →
当场记录 →
约定复核。
区分两者的意义：立场常常互斥（一个要道歉一个不肯道歉，僵死），
利益往往能两全（一方要的其实是"别再发生"，另一方要的是"不当众受辱"，完全可以同时满足）。

## 方法与应用

**预防机制**（事前建立，成本最低）：

- 分配规则公开且有记录，例外（伤病加量）当众说明。
- 私人空间与私物边界明确：什么共享、什么不动——写进接收新人时的三问清单，并当着全群宣布一遍。
- 劳动量可见：排班上墙，避免"都在干活/都在偷懒"的互相指控。
- 设"冷却期"规矩：冲突当场各自离开，次日碰头会处理——不让情绪当场的决定生效。
  落地做法：任何一方说出"我需要停下来"或协调人喊"暂停"，双方立刻分开到不同位置，当晚不做任何结论；
  约定时间（24 小时内）再谈。

**调解操作**（逐步执行）：

1. 调解人不评判、不站队，优先选双方都信任的人；实在没有则由协调人担任。
2. 让每人不受打断地说完"发生了什么 + 我要什么"。
   打断出现时调解人的动作：抬手示意暂停，说"让他说完，马上轮到你"，
   并把插话人的要点记在纸上保证不丢。
3. 把指控翻译成需求："他总是偷吃" → "他对食物分配的公平性没有信心"。
   翻译的动作要领：把"人怎么了"改成"什么事没保障"，把形容词（总是、故意、从来）删掉换成具体次数和场景。
4. 产出具体可核对的方案（谁、做什么、到什么时候），写在记录本上——
   "以后互相尊重"不是方案，"食物只从保管处领取，领用记账，每周日对账"才是方案。
5. 一周内复核一次，防复发。
   复核时对照记录本逐条问"这条做到了吗"，做到的画钩，没做到的先查是规则不好执行还是人不执行。
   复核结果也记进本子——第二次调解时，第一轮的复核记录就是最有力的凭据。

**处置破坏性行为**（偷拿、暴力、屡次违规则）：

- 先私谈警告并明确后果（私谈用"我观察到 X，这违反 Y 规则，再发生会 Z"三句式，不翻旧账、不带第三人偷听）；
- 再犯则群体规则处置（限制某些权利、赔偿、最后才是驱逐）。
- 处置的取证与记录：每一步都留字——私谈后记一行（日期、内容、本人是否承认），
  再犯时的记录就是升级处置的依据；没有记录的"再犯"只能从零说起，处置会变成口水仗。
- 驱逐是极高成本决定（结怨且信息外泄），须经过 [群体决策方法](03_decision_making.md) 的方向类程序，
  不留人时给对方体面与基础物资
  （体面的含义：不当众宣布罪名细节，给一天时间收拾与告别，发三天口粮——树敌一次要防一辈子，多花三天口粮买少一个仇人是便宜的）。

**情景演练：调解"偷拿电池"的指控**：

- 情况：保管发现电池少了 4 节，指认是某人拿的；对方否认，两人吵到面红耳赤，围观者开始站队。
- 先降温：两人分开到不同屋，各递一杯水，当晚不定论，次日再谈（执行冷却期规矩）。
- 分开听取：各自只说"发生了什么 + 我要什么"——
  保管要的是"账实相符、规则有效"；被指认者要的是"不当众被当贼"。
- 翻译指控："他偷电池" → "电池领用没有登记流程，谁都可能拿而无人知道"——把矛头从人转向流程漏洞。
- 产出方案：电池收进带锁的箱，领用写条（谁、几节、用途），每周日对账——方案对事不对人，被指认者不必认罪也能接受。
- 复核：一周后查领用条是否在执行、账实是否一致；
  那 4 节电池查不出下落就到此为止，不追人、只修流程（追不出结果的追究只会制造冤屈）。
- 成功标准：下周起账实相符，两人没有再提此事，围观者散去。
- 失败信号：调解滑向逼供（"你不承认就是你有问题"）——调解人立即叫停，回到"对事不对人"；
  若后续确凿证据指向某人，也改走纪律程序（私谈三句式起），不回头重开调解桌。

**情绪先于纪律的一条例外**：
灾害后的易怒、失眠、麻木可能是应激反应（见 [基础急救流程](../05_health/01_first_aid_basics.md)），
先按"人受了伤"处理（减负、陪伴、规律吃饭睡觉），观察几天有没有好转，再决定是否走纪律程序。

## 常见错误与限制

- 当众批评或逼人当场认错：逼出的道歉不会带来合作，只会积累怨恨。
  为什么错：当众认错=当众丢面子，人的本能是先保面子再谈对错；
  后果：嘴上认了心里不服，几周后同样的事换个由头再爆一次，且更难调解；
  正确做法：批评放私谈，公开场合只宣布"已解决"与方案本身。
- 各打五十大板的和稀泥：是非被模糊，规则失去威信；
  为什么错：调解者图省事各罚一半，等于告诉所有人"规则可以讲价"；
  后果：守规矩的人觉得自己傻，下次也先闹再说；
  正确做法：调解不是不辨对错，而是对错之外还要修复关系——先按规则认对错，再谈关系修复（道歉、补偿）。
- 用"都是一家人"回避规则：亲属小团体是资源分配与劳动排班里最常见的隐性不公来源。
  为什么错：亲属间互相多让一步，挤压的就是非亲属的份额与班次；
  后果：非亲属表面不说、心里记账，一有机会整批离开；
  正确做法：规则面前不认亲，排班与分配以名单为准，亲属关系只在替补顶岗时作为便利。
- 调解者成为新冲突方：调解人卷入站队后应换人，不要恋战。
  为什么错：调解人一旦被一方视为"对头"，他说的每句话都被过滤成偏袒；
  后果：调解桌变成第三战场，矛盾从两方变三方；
  正确做法：察觉自己被卷入（开始为一方辩解、音量升高）就当场交棒给中立者，退出时说明"不是不管，是换人管"。
- 忽视慢性低烈度摩擦：小摩擦不断说明规则有漏洞，处理摩擦之外要修规则。
  为什么错：同类小摩擦反复出现，是规则在同一个位置绊倒不同的人；
  后果：调解做了一箩筐，摩擦照旧，群体疲于救火；
  正确做法：每次调解结束加一问"下次怎么让它不再发生"，把答案变成规则修订。
- 把调解当审讯：调解桌上追细节、对时间线，会让人自保而撒谎；
  为什么错：审讯姿态触发自保本能，人开始修饰说法，真话反而出不来；
  后果：拿到两套互相修饰的版本，更没法裁；
  正确做法：桌上只要"发生了什么（各方版本）+ 各要什么"，事实核对放到复核阶段做。
- 恐惧与创伤性行为被当作"性格问题"：灾害后易怒、失眠、麻木是常见应激反应，
  需要的是照护（见 [心理健康] 进阶主题与领域 README），不是纪律处分。
  为什么错：应激是生理状态不是品行，处分改变不了生理，只会雪上加霜；
  后果：被处分的人症状加重、群体以为"闹情绪=受罚"，更没人敢表露状态；
  正确做法：先按"人受了伤"处理（减负、陪伴、规律吃饭睡觉），观察几天有没有好转，再决定是否走纪律程序。
- 冷却期被滥用为逃避工具：
  有人每次冲突都喊"暂停"来拖过处理时间——
  冷却期只管"当晚不定论"，不能取消"次日必须谈"，协调人要盯着约定时间兑现。

- "偷拿电池调解演练"为教学用合成场景，其"只修流程不追人"的取舍适用于小额损失，大额损失的处理边界未核验。
