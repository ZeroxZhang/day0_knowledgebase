## 阅读顺序

1. 医学知识阶段 0 就要用：误食、咬蜇、腹泻脱水、创伤判断——应急速查入口见 00_使用指南 第四节。
2. 历史在两条线上按需读：做"别人做过的事"之前（农业、冶金、印刷）查对应文明阶段；做重大制度决策之前读崩溃与复原规律。
3. 地理在选址、踏勘与长期规划时读：气候带 → 大洲档案 → 资源分布 → 区域踏勘。
