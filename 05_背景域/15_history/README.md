# 15 人类历史

解决的问题：重建者需要知道**人类先做到了什么、靠什么条件做到、什么顺序走得通、文明为什么崩溃又如何复原**。历史在这里不是通史教学，而是"文明重建的先行者试验记录"——每篇都以"对重建者的启示"落回可操作结论。

主线：起源 → 农业革命 → 早期文明 → 青铜与铁器 → 古典与轴心 → 中世纪 → 科学革命 → 工业革命 → 近现代 → 崩溃与复原的规律。

## 写作纪律（本领域特有）

1. 时间一律给绝对年代量级；叙事具体到"谁在哪里靠什么活下来"。
2. 每篇"对重建者的启示"≥5 条，必须可操作（"所以你应该先做 X"），不是感想。
3. "常见错误与限制"写成"重建者重蹈的历史覆辙"：错误 → 为什么会发生 → 历史后果 → 历史上成功者怎么做。
4. 历史常识可写，但不编造文献与页码；抽查核实的年代/论断标"已核对子项"并注明来源与检索日期。
