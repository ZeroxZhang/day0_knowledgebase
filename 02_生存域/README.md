# 02 生存域（火 · 水 · 食物 · 住所 · 急救）

部定位：人与聚落的生存底线，阶段轴 0～2 的主体。五个域按"能量 → 水 → 食物 → 居住 → 伤病"排列，对应一个人、一群人从第一夜活到第一个丰收年所需的全部条件。核心视角是从零重建：火靠摩擦、容器靠陶土、绳索靠手搓纤维、药靠辨认植物；应急视角的存量文章保留并逐步改造。

## 阅读顺序

1. 阶段 0（一无所有）：火（01）→ 水（02）→ 避难（04）→ 食物（03）→ 伤照护（05）；救命识别（可食植物、剧毒蘑菇、危险动物）先回 01 根基层补齐。
2. 阶段 1～2 沿各域 README 的序号推进：容器（陶器）、储粮、打井供水、卫生制度。
3. 每篇动手前先读"常见错误与限制"；本部多篇带安全红线（水质判据、一氧化碳、井筒进入条件、高温处置），未核对的待核验项按保守方向执行。
