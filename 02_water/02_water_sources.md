# 水源类型与取水

层级：基础
视角：应急
阶段：0～4

## 解决什么问题

在供水系统停水、自来水不再可靠或需要撤离转移时，快速判断身边有哪些水可以取用、哪些优先用、怎么取才不把水和取水者自己置于危险中。

本文只解决"找到水并取出来"这一件事：

- 水的安全判断见 [水污染类型与风险判断](03_water_contamination.md)。
- 如何变成饮用水见 [饮用水净化方法](04_water_purification.md)。
- 本主题的从零重建（两手空空找水）见 [无装备找水与净水](01_water_from_scratch.md)。

先解释两个贯穿本文的词：

- **市政自来水**：由城市水厂统一净化消毒、经地下管道送到各家的水。
- **地表水**：江河湖塘里暴露在天地间的水。
- **地下水**：藏在土壤和岩石缝隙里的水。
- **大气水**：从天上落下来的雨水、雪、冰，和凝在物体表面的露水。

## 核心知识与原理

水源按形成方式大致分四类，风险特征各不相同：

**市政自来水**：

- 正常情况下已在水厂消毒，消毒后留在水中的少量消毒剂叫"**余氯**"——就是自来水偶尔闻到的淡淡药味。
- 但停水期间管道里水压会下降甚至变空，此时管道外部的污水可能被"倒吸"进管道——就像吸管里的水倒流。
- 因此"停水后再恢复来水"的水要当作被污染水处理，先烧开再用。
- 临时停水时，管道和家用水具里往往还存有水，是最容易拿到的第一笔水。

**地表水**（河流、溪流、湖泊、池塘、水库）：

- 最容易找到，也几乎必然含微生物污染（微生物即细菌、病毒、寄生虫这类肉眼看不见的致病小东西）。
- 上游有任何人类或牲畜活动都会影响下游——水往低处流，上游进了脏东西，下游全都有份。
- 流动水通常优于死水，但这只是相对更好，不代表可直接饮用。

**地下水**（水井、泉眼、地下水位渗出；打井全流程见 [打井与家庭供水](08_well_water_systems.md)）：

- **地下水位**指往下挖到开始渗水的那个深度，挖到渗水说明挖到了地下水层顶面。
- 地下水经过土壤层层过滤，微生物风险通常低于地表水。
- 但土壤过滤挡不住硝酸盐（化肥和污水中含的、溶解在水里的含氮物质）、重金属等化学污染。
- 浅井和靠近地表水源的井，更容易被地表污水顺着缝隙渗入。

**大气水**（雨水、积雪、冰、露水）：

- 相对"新鲜"，因为落下前没接触过地面脏物。
- 但会被屋面材料、空气污染物和收集装置本身污染。
- 积雪在飘落和堆积过程中裹挟了大量灰尘和杂质，含杂质量高，融化后通常需要净化。

核心原则一：**水源的安全性与"上游发生过什么"和"水停留了多久"关系最大**。取水点的选择比取水技术本身更重要——选对了点，后面省一半功夫。

核心原则二是水源分级使用：最干净的水留给饮用和做饭，洗漱、清洁、冲厕可以用明显更差的水，不要把净化成本花在所有水上。

判断方法：每取一份水先问自己"这水是进嘴的，还是只碰皮肤和马桶的"——进嘴的才走完整净化流程。

## 从零实现路径（跳转）

从零重建视角下没有容器、没有净水剂，取水依赖链完全不同：

1. 先读地势与生命迹象定位水源 → 2. 用坑、叶槽、露水布就地收集 → 3. 澄清 → 4. 煮沸。

完整流程见 [无装备找水与净水](01_water_from_scratch.md)；本文余下部分默认是应急视角（有部分残留物资可用）。

## 方法与应用

**取水点选择（地表水，按动作分解）**：

1. 先沿水岸向上游走：小溪走够一百步以上再回头观察，大河沿堤岸目视巡查上游一段。
2. 边走边看两岸有无这些痕迹：牧场牛羊、厕所或粪堆、垃圾堆、彩色或发黑的排污口水流、死鱼死畜、水面白沫（可能含洗涤剂）。
3. 选上游一段没有人畜活动痕迹的位置作为取水点。
4. 在同一条河里，选流速较快、水深、水色清澈的河段取水；避开岸边浅滩的死水区（水不流动、发绿发臭的湾子）和藻类密集区（水面飘绿膜、水底挂绿毛的地方）。
5. 取水姿势：如果水较深，站在稳固处或从石块、堤沿探身，把容器口朝下按入水面以下 5～10 厘米再翻转进水——水面漂浮的浮沫和杂物留在表层，取中层水最干净。
6. 不要蹲在岸边伸手搅泥取水，岸边搅起的泥沙会加重后续净化负担。
7. 记录并固定取水点：用布条、石头堆记号标记位置，不要每次随机换地方，这样才能对比水质变化。

**家庭应急存水（停水时优先翻找，常被忽略）**：

- 电热水器（储水式）内胆：
  1. 这种热水器是一个大保温罐，通常存有几十升水。
  2. 断电或关燃气（水放空后加热会烧坏设备甚至起火）。
  3. 打开任一热水龙头泄压。
  4. 在罐体底部的排污阀（一个小阀门或带盖小口，一般在水罐最底部）下方放盆，缓缓拧开阀门接水。
  5. 刚放出来的是罐底的水，先放掉一些再接取。
  6. 罐内是常温水且未烧开，饮用前仍要消毒。
- 马桶水箱（不是便池！）：
  1. 马桶后上方那个方形储水箱，在没投放洁厕剂时是干净的。
  2. 判断方法：掀开盖看水是否清亮、有无蓝色或绿色——有颜色说明放了洁厕块，绝不可用。
  3. 掏净水件后用瓢舀出即可，可作洗漱和清洁用水。
  4. 便池里残留的水绝对不可用。
- 热水壶、锅具、水桶、饮水机桶中已有的水，以及暖水瓶里的存水。
- 冰箱冰格和冷冻层中的冰，融化后可用。

**雨水取用（按动作分解）**：

1. 选承接面：干净的塑料布、雨衣、大口容器都可以。
2. 避开金属屋面（尤其是有锈蚀或涂层的）、沥青屋面（淋出的水有油味）和有鸟粪、落叶的表面。
3. 没法避开时，先等雨水把屋面冲淋一遍再接。
4. 铺设方法：四角绑高、中心压低成漏斗形，水汇到中心后引流进容器，或直接在中心最低点下方放盆。
5. **弃流**：刚下雨的头一段时间，冲刷下来的是积在承接面上的灰尘和鸟粪，这部分水颜色明显发浑发暗，倒掉不用，等水流变清亮了再开始正式接。弃流量级（已核对：Texas A&M AgriLife 建议每 100 平方英尺集水面弃流约 1～2 加仑，约合 0.4～0.8 L/m²，随屋面污染程度与降雨强度调整）。
6. 接到的雨水装进带盖容器，当天不用完就盖紧防虫。

**冰雪取用（按动作分解）**：

1. 取雪：不取贴地的最底层（混泥沙和动物粪尿），不取树底下被鸟粪污染的，取离地一段距离的**中层雪**。
2. 取冰：取颜色清亮透明的；乳白色多气泡的冰含杂质多。
3. 化雪：锅里先放小半锅雪——量宁少勿多，雪化水后体积缩到近十分之一（已核对：10:1 为常用规划值，实际随雪型约 4:1～30:1 波动——NSIDC），塞满一锅化得很慢且容易糊底。
4. 小火让锅底先化出一点水，再分次往里添雪。
5. 化出的水往往混有沙尘，静置或过滤后再消毒（见 [饮用水净化方法](04_water_purification.md)）。
6. 不要直接吃雪——雪在嘴里融化要大量吸走体温，寒冷环境下可能诱发**失温**（身体核心温度过低导致的危险状态），也越吃越渴。

**取水工具**：

- 大口桶：水面高、口宽的水源用。
- 带盖水袋、折叠水桶、瓢和漏斗：常备一套，收在撤离包旁。
- 狭小水源（如井口、石缝）：一根系了小石块坠底的绳子加取水容器（瓢、瓶），比直接灌瓶效率高得多——把坠着石子的容器抛下去，容器沉歪灌满后提上来即可。

**取水后立即处理（三步，缺一不可）**：

1. 盖好容器，防虫防尘。
2. 贴标签注明取水日期和地点（没有标签就用记号笔写在瓶身上或拴纸条）。
3. 与已净化水分开存放——生水和熟水放在一起，紧张时拿错就是腹泻。
4. 浑浊的水先静置：放在平坦处至少一两小时、过夜更好，让泥沙自然沉底（这个原理叫沉降：泥沙比水重，静下来就会往下掉）。
5. 取上层水进入净化流程，倒水时留底部约两指深的浑水弃掉，不要倒到底。

**按条件选择水源的优先顺序（供参考，需结合实际情况调整）**：

1. 家中已储存的密封水、储水容器中的水——最省事、风险最低。
2. 电热水器内胆、清洁马桶水箱等家庭应急存水——量较大且通常无需处理即可作洗漱用水。
3. 有遮盖、来自清洁集水面的雨水。
4. 保护良好的泉水、深井水（仍应消毒后再饮用）。
5. 流动且上游清洁的地表水——必须完整净化后才能饮用。
6. 静止的池塘、水洼——只在别无选择时使用，且要最大限度净化。

这个顺序的意义在于：越靠前的水源，需要付出的净化成本越低。把有限的燃料、消毒剂和时间优先用在低级水源上。

判断方法：动手取水前先过一遍这六个位置——家、热水器、屋檐、附近的井和泉、最近的河、最差的水洼。多数人第一步就跑去第六个，这是最吃亏的顺序。

## 常见错误与限制

- **"清澈=安全"**：清澈的水仍可能含致病的微生物和溶解性化学污染物（溶解在水里、过滤不掉的东西，如硝酸盐、砷）。感官判断只能排除最明显的污染，详见 [水污染类型与风险判断](03_water_contamination.md)。
- **"流动水能自我净化"**：上游几公里处有死畜或排污口，下游水照样危险。判断依据是上游活动，不是水的流速。
- **忽略家庭存水**：很多人第一时间跑去河边，而家里热水器里就有几十升更安全的水。先翻家，再出门。
- **直接从井里取水喝**：井水和泉水通常微生物风险低，但未经检测的井可能含硝酸盐、砷等化学污染，长期饮用风险高；短期的、灾后未知状态的井水也应消毒后再喝。
- **用嘴直接对着水源或水管吸水**：取水器具与口接触后会把口腔细菌带入整份水，几个小时后整份水都可能变质。正确做法：倒入杯中或碗里再喝。
- **在夜间或洪峰中冒险取水**：洪水期地表水混入了下水道、粪坑、养殖场的东西，污染程度剧增，且取水本身有溺水风险，应优先使用家中储备。
- **灌瓶取水时容器口露出水面**：容器口若一半在水外，灌进去的是"水+水面杂物"。应整个按入水下翻转进水。
- **放空的热水器继续通电点火**：罐内无水干烧会烧坏加热管甚至起火，放水前先断电断气。

## 来源与待核验项

本文为模型通识整理，编写时未逐项比对外部资料。可参考的可靠入口包括：WHO《饮用水水质准则》、红十字会与红新月会的家庭应急手册、中国疾病预防控制中心发布的灾后卫生防病指引。

待核验项：

- 电热水器内胆存水量（常见容量范围）与排污阀放水操作细节，因产品差异大，应以产品说明书为准。
- 雪的净化要求（是否需要额外消毒、含杂质量）未与资料核对；"取中层雪"的选雪口径需核对野外生存手册。
- 停水恢复后自来水需放流多长时间再使用，未查证，建议以当地供水部门指引为准。
- "按入水面下 5～10 厘米取中层水"的取水深度说法为通识量级，未查证。
- 沿上游排查取水点的具体步行距离（本文按"小溪一百步以上"的通识量级表述），需与野外生存/应急手册核对。

已核对子项（2026-09-12，检索日期 2026-09-12）：

1. 雨水"弃流"量——✓ 定性口径成立并已补数值。Texas A&M AgriLife《Pre-Storage Treatment》（https://rainwaterharvesting.tamu.edu/pre-storage-treatment/ ，实际打开核对）：首段径流含屋面杂物最多，建议弃流，"每 100 平方英尺集水面约弃流 1～2 加仑"（≈0.4～0.8 L/m²），弃流腔需在每次雨后排空；弃流量随附近树木与雨强而变。数值已写入正文。
2. "雪化水体积缩到近十分之一"——✓ 口径成立，已补波动范围。NSIDC《Science of Snow》（https://nsidc.org/learn/parts-cryosphere/snow/science-snow ）："10:1"为常用规划假设，实际随雪型变化（新干粉雪 20:1～30:1，湿春雪 4:1～5:1）。已写入正文。
3. "不要直接吃雪"（失温风险）——✓ 口径成立。Pentair《Turning Snow into Water》（https://www.pentair.com/en-us/home-water-treatment/resources/blog/snow-into-water.html ）等多来源共识：吃雪需身体消耗核心热量将其融化，可致体温下降、加速失温，且"越吃越渴"。正文该条无需改动。

其余待核验项维持原状；本文状态保持"待核验"。
