# 02 水与卫生

解决的问题：找到水、判断是否安全、净化、储存；以及缺水条件下保持卫生、处理废弃物。

## 安全复审（2026-09-17）

找水、净水、卫生与打井四篇已修正本轮明确发现的问题，均为待核验。沉淀与普通砂布过滤不等于消毒，疑似化学污染不能只靠煮沸；缺少可靠检测、支护与救援能力不进入井筒。打井篇保留原理与不需下井的替代供水路线，不是施工许可。
