# 03 生产与技术（通信 · 工具 · 农业 · 材料）

部定位：生存底线之上的"造物"能力，阶段轴 1～4 的主体。四个域覆盖技术栈主线：从石器打制到简易机床与精密钟表，从采集驯化到灌溉轮作，从陶器到玻璃与铜铁冶金，从原始信号到无线电。文明百科深化战役（CP-040～047）的各域支柱篇多数在本部。

## 阅读顺序

1. 沿阶段轴推进：阶段 1 工具与容器（石器、绳索、陶器）→ 阶段 2 定居与农业（种植、灌溉、储粮、盐）→ 阶段 3 材料革命（木炭窑、石灰、冶金、玻璃）→ 阶段 4 动力与机械（水轮风车、机床、蒸汽）。
2. 每篇动手前回查 01 根基层的对应识别篇：石料、黏土、矿石、纤维。
3. 高危工艺（冶金、窑炉、蒸馏）先读"常见错误与限制"，安全边界沿 EXECUTION_GUIDE 第 4 节。
