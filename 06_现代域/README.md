## 阅读顺序

1. 计算线依赖 01 根基层的大学数学与现代科学篇（26～38），从计算简史读到收官综述，再按装配表回补前置。
2. 心理线在群体成形、重大伤亡或灾变事件后即用：心理急救五原则 → 创伤与复原 → 心理支持体系装配表。
3. 经济线与 04 组织与文明的贸易货币篇互为表里：市场怎么从生存需求里长出来（10 域），怎么设计得更好（19 域）。

## 与其他部的关系

- **01 根基层**：数理逻辑、微分方程、原子物理、化学键等现代科学篇是计算与医药理解的前置；
- **04 组织与文明**：10 域的市场货币、12 域的知识记录与 17/19 域互为表里；
- **02 生存域 / 05 背景域**：18 心理与 05 急救、14 医学在伤病与伤亡场景闭环；19 经济的公共品与财政承接 10 域的治理制度。
