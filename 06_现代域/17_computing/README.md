# 17 计算与信息

解决的问题："算得快、算得准、存得住"这三种能力从哪里来、怎样从零重建——从结绳刻数到算盘算表，从齿轮进位到继电器机器，以及为什么"可控开关+两态编码"是把逻辑变成机器的全部秘密。本域 11 篇构成一条从零重建计算能力的阶梯（收官综述 [11 重建计算能力阶梯](11_rebuild_computing.md) 给出六级装配表与越级陷阱）。

与相关领域的分工：

- **11_science**：进制、数论、概率等数学语言是本域的原理底座（30/31 篇互链）；本域讲"怎么把数学变成可执行的机器与制度"。
- **06_comms**：电报/无线电讲信号传输；本域讲信息本身的编码、压缩、纠错与保密（10 篇是两域的桥）。
- **12_knowledge**：文字/印刷讲知识的记录与传播；本域 07 篇把"存储"扩展为完整介质谱系（从结绳到磁芯）。
- **07_tools**：精密齿轮与车床是机械计算机的制造前置（04 篇依赖链已标注）。

**安全边界**：10 篇密码学一节只写历史与原理方法学（频率分析属公开教育内容），不提供对现代加密系统的攻击方法与工具。

## 写作纪律（本领域特有）

1. 每篇给出能力边界与"现实终点"：重建路线的现实终点是**继电器计算机**——电子管/晶体管/集成电路的停步条件必须写死并给出判据，不写"想办法造"。
2. 算例（真值表、差分表、哈弗曼、汉明码、机器码轨迹）一律逐行验算后写入；来源分「已核对/待核验」两段，年份与器件数字未核实即列待核验。
3. 器件谱系对照表（速度/功耗/寿命/从零可制造性）是本域的统一口径，各篇引用不另造数。
