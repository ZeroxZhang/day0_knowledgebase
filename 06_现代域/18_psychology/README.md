# 18 心理与行为

解决的问题：人是怎么感知、学习、行动的；崩溃与重建的极端环境下，个体的恐惧、创伤与群体的恐慌、士气怎么管理；如何用可操作的制度把"心理支持"从运气变成基础设施。落点是重建环境下的心理照护体系（收官综述 [10 重建社会的心理支持体系](10_psych_support_system.md) 给出三层体系与全域装配表）。

与相关领域的分工：

- **14_medicine**：器质性急症红旗（脑膜炎/中风/癫痫）、各系统疾病识别归 14 域（09 篇互链）；本域讲行为与情绪的持续模式和心理机制。
- **05_health**：现场处置与公共卫生制度归 05 域（07 公共卫生重建篇与 06 社会心理学的危机传播分工互链）。
- **10_cooperation**：组织制度本体（治理、市场、仪式与意义系统）归 10 域；本域讲制度背后的心理机制。
- **12_knowledge**：教育制度本体归 12 域（05 教育体系篇）；本域 07 篇讲发展规律与教学机制。

**安全边界**：本域不写处方与剂量、不给任何精神活性物质的获取/制备/使用信息；自杀与自伤内容只写"识别信号＋直接询问＋不离人＋移走工具＋求助"的支持方向；约束与隔离只写伦理边界（最小必要、有人陪伴、定期复核）。

## 写作纪律（本域特有）

1. 每篇明确"机制/制度/现场处置"三层分工声明并与既有域互链，不重复内容。
2. 所有心理学结论标注证据强度与可重复性状态（可重复性危机是本域常识底座）；实验数字实读核实，拿不准列待核验。
3. 心理危机内容一律"识别＋支持＋转介"三段式；本域不提供任何治疗处方。
