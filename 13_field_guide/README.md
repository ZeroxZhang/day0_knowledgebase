# 13 野外识别

解决的问题：一无所有时，身边的一切都是"没见过的东西"——哪种植物能吃、哪种会毒死人，哪块石头能打刃、哪种黏土能烧陶，哪只动物能追、哪种不能惹。本领域提供一套从零建立"认得出"能力的**识别方法论**，以及按对象分类的**辨识手册**（植物、动物、岩石矿物、黏土土壤、木材纤维）。

定位：识别先于制作。吃之前要会认植物，打石器之前要会认石料，冶金之前要会认矿石。本领域只写"怎么辨认与判断"，制作步骤留在各技术领域，用链接互指。

## 写作纪律（本领域特有）

1. **不放无法核对的区域物种清单**：识别文章写"全球通行的类群与规则"（如橡子脱毒、蘑菇红线、莫氏硬度替代法），具体区域的物种名录留待读者按方法论建立本地标本册，不虚构"某地有某物"。
2. **致命错误优先**：每篇先把"认错会死"的情形写足（剧毒近缘种、蘑菇、毒蛇），再写效率技巧。
3. **单一特征不定论**：所有辨识要点必须写明"需多特征交叉确认"，并给出最易混淆对象。
