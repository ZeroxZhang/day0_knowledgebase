# 木材与纤维

层级：基础
视角：从零重建
阶段：1～2
状态：待核验
更新时间：2026-09-12

## 解决什么问题

阶段 1 用量最大的材料就是木头：石斧要柄、弓要坯、碗勺要料、棚屋要架、火堆要柴；绳与布的一切源头是植物纤维。认错材的代价是直接的：柄挥到第几十下断裂、弓拉开瞬间崩断（断弓能伤人）、碗用几天就渗味开裂、绳在承重瞬间崩股。

本文解决五件事：

1. 把树认到"记账"的水平：针叶/阔叶两大类、树皮特征语言、松针束数、果实认树——识别纪律沿用 [识别方法论](01_identification_methods.md)（三特征底线、描述卡），不重复。
2. 用六件套试验测出"这一根材"的软硬韧脆——材性比树名更重要，同种不同株差异很大。
3. 给六类用途配对材料（用途→选材矩阵），含弓材测试与食器的毒理红线。
4. 认出纤维植物并判定"能不能搓绳"——详细制绳与纺织不展开，链接材料域。
5. 收树脂与蜡，立下采伐纪律。

## 核心知识与原理

### 1. 树木辨认基础

- **两大类**：零基础解释：针叶树=叶细如针或鳞片、多数四季不落的树（松、杉、柏类），木材多松软含脂，通称软材；阔叶树=叶宽大、多数秋冬落叶的树（橡、榆、槭类），木材多数硬重，通称硬材。注意"软硬不绝对"：有的阔叶树（椴、杨）比松还软——树名只做初分，材性靠下文六件套实测。
- **树皮特征语言（三个词覆盖大半张嘴）**：
  - **纵裂**：树皮深沟沿树干纵向裂成条（老橡树、老松树的"沟壑皮"）。
  - **片状剥落**：树皮成片翘起、剥落，露出下层新皮（松树干上部、桦树能整层卷剥）。
  - **光滑+皮孔横线**：零基础解释：皮孔=幼树皮上用来透气的小孔。树皮光滑、带横向细线或小点（樱桃属、桦属幼树的"横线皮"）。
- **松类针叶束数法**：零基础解释：束=几根针叶从同一个基部长出，基部包着一层纸质小鞘。松属的针叶按"2 根一束 / 3 根一束 / 5 根一束"生长，**数一束几根是分松类最硬的数**（数目极少变——01 篇观察维度的原则）：2～3 针一束多为硬松类，5 针一束多为软松（白松）类（已核对子项，见文末）。云杉、冷杉的针是单根着生不成束——先确认"成束"再谈松类束数。
- **果识树（三条通行对应）**：橡子（戴"壳斗帽"的坚果）=栎树；翅果（两片"螺旋桨"翅膀里包着种子）=槭树；荚果（豆荚）=豆科乔木。叶形+树皮+果实**三特征交叉**才下结论（01 篇三特征底线），单凭叶认树是误判主渠道。叶果形态的完整描述法见 [植物识别总纲](02_plant_id_basics.md)。

### 2. 材性试验六件套

零基础解释：材性=一块木材的物理脾气（软硬、韧脆、耐不耐腐、轻重、干缩大小）。六件套全部就地可做；每根打算重用的材**单独测**（同种树不同株、同株不同部位差异都大）：

1. **硬度——指甲压痕**：拇指指甲垂直抵住新鲜断面（刚削出来的面），匀力下压到指节发白。**算数标准**：指甲陷进去、压出月牙痕=软材（好削好雕，做碗勺）；压不动、指甲打滑=硬材（做承重件、耐磨件）。
2. **劈裂性——顺纹劈**：零基础解释：顺纹=沿纤维生长的方向。用石斧或木楔对准端面中心沿纤维方向往下劈，看劈缝走向：**一路直下劈到底=直纹**（好劈，做板料省工）；**劈两下就拐弯跑偏、劈不直=扭转纹**（零基础解释：纤维呈螺旋状绕着树干长）。同一段材从端面与侧面各试一次才作数。
3. **韧性——细条弯折**：削一根筷子粗、小臂长的细条，双手各握一端**慢慢**往胸前弯（快弯测不出差别）。**算数标准**：弯成明显弓形时外表面发白、纤维一根根撕开、断口发毛=韧（受震动不裂——柄与弓要的材）；没弯几下"啪"一声平口崩断、断口平整光亮=脆（只配做不受震的件）。
4. **耐腐——心材气味+老倒木对比**：零基础解释：心材=树干中心颜色深的老木质；边材=外圈颜色浅的新木质。削心材新鲜断面，按 01 篇扇闻法闻：**树脂香或单宁涩香=含防腐成分、耐腐倾向**（这类气味来自化学防御物质，原理见 [化学基础](../11_science/05_chemistry_basics.md)）。再加一条实证：林下找同一树种的倒木，倒地多年不糟心不烂皮=耐腐实证。**边材几乎都不耐腐**，耐腐的是心材——记录里两者分开写。
5. **干湿——断面裂纹**：看新伐材的横断面。放射状细裂纹从心向外张=干缩大、易裂的材（做板料必须慢干阴干）；断面平整无裂=干缩温和。判干湿：敲声闷、断面色深带湿光=生材（零基础解释：刚伐下、含水多的材）——生材不能用，会弯会裂会松；**立着枯死的树（立枯材）已在树上天然干透**，是从零条件下最省等待的用材来源。
6. **密度——沉水试**：干透的拇指大木块放静水。浮起=轻材（好搬运、隔热）；平悬或沉底=重材（硬实耐磨，但件件压手）。**必须用干材**——生材都偏沉测不出差别；只取心材块（边材孔隙多会假浮）。

### 3. 用途→选材矩阵

| 用途 | 要什么材性 | 六件套里的判据 |
| --- | --- | --- |
| 器柄（斧、锄、锤） | 韧 + 扭纹 | 弯折不断 + 劈不直 |
| 弓 | 能弯不断、回弹快 | 弯折韧 + 压弯回弹测试 |
| 板料（背架、门板） | 直纹易劈 | 顺纹一劈到底 |
| 雕碗勺 | 匀质软材 | 指甲压出痕 + 纹理细匀 |
| 燃料 | 硬木炭久、软木引火 | 硬度 + 树脂香气 |
| 食器 | 匀质软材 + 无毒汁液 | 硬度 + 乳汁红线（见下） |

- **斧柄为什么选扭纹**：柄的工况是反复震动与弯折——直纹柄一受震就顺着纤维缝劈开（头部一松就裂到根）；扭转纹的纤维互相咬住、劈缝跑不直，裂不开。再加一条：柄的纤维要顺着柄身连续走过弯头（用天然弯的枝干削柄，让纤维包着弯走），比直木料挖出的柄更抗折。此组说法是传统经验与现代木工通识的混合，量化结论列入待核验。
- **弓材的压弯回弹测试**：把削好的弓坯架在两块石头上（间距一臂），双手压中间压到明显弯曲，松手看两件事：**回直快、不留弯印=合格**；留下弯印（压弯后直不回去）=受压疲劳，做弓会越拉越"疲"；压出裂响=直接淘汰。弓的具体制作属工具域（本篇不展开）。
- **燃料分工**：硬木（指甲压不动）烧得久、炭质好，做夜火与烧炭；软木与含树脂的针叶引火快，做引火与晨火。取火与火的全部工艺见 [摩擦取火与火种管理](../01_energy/01_fire_making.md)。
- **食器毒理红线（先于一切选材）**：**有白色乳汁的树一律不做食器、不做接触食物的柄**——零基础解释：乳汁=枝条折断处渗出的白色浆液，许多含刺激性或毒性成分，会渗进食物。具体类群与红线见 [剧毒植物与蘑菇](04_toxic_plants_mushrooms.md)；漆树科的木材同样禁做食器（见第 7 节生漆警示）。红线不因"闻着没味"豁免。

### 4. 树皮附加资源

- **桦树皮**：含油脂，湿天也引得着，是引火物里的一等品；整张卷筒可扎成水桶与收纳盒。剥皮只在已伐倒的或本就要清除的树上取——活树环剥见第 8 节。
- **榆、椴内皮**：零基础解释：内皮=树皮贴着木质部的那一层（外层老皮下面的韧皮）。长条可搓绳、可编席，属第 5 节纤维植物类群。
- **栓皮栎软木**：栓皮栎类的树皮厚软有弹性、轻而浮水——割成块做渔网浮标、瓶塞（渔具应用见 [采集渔猎入门](../03_food/05_foraging_hunting.md) 的渔具节）。
- **采皮通用纪律**：只取侧面的竖条（不超过树干周长的三分之一），留足够的皮让树活着——整圈剥=杀树（见第 8 节）。

### 5. 纤维植物辨认与判定试验

- **判定试验（一撕二搓三分丝）**：取一段手指粗的茎或枝，从断口撕下一条皮，看内层（贴木质的那面）：**能揭出连续长条、指腹间捻搓不断、能再撕成细丝=可用纤维**；一撕就碎成粉屑、发脆=不可用。撕不动的外层老皮不算数，要的是内层韧皮（零基础解释：韧皮=皮层里由长纤维细胞组成的、有韧性的一层，"韧皮纤维"由此得名）。
- **常见类群（按类群认，不按种认）**：
  - **荨麻类**：草本，茎直立、叶对生、茎叶带刺毛（碰了起疹——操作垫叶、垫布），秋后取老茎剥皮。
  - **柳、椴、桑的内皮**：取较直的一年生枝撕内皮；桑内皮自古兼作绳料与织布候选。
  - **棕榈类叶柄**：叶柄基部的纤维鞘直接撕丝。
  - **龙舌兰类剑叶**：厚质硬叶——叶片压在石面上，石刃斜贴着刮走绿色叶肉，留下白亮纤维束，清水摆洗。
  - **豆科藤本**的藤皮：老藤撕皮，判定试验同上。
- **采集季节**：**生长季（春夏）内皮好剥**——此时形成层活跃，皮与木之间"滑"，一撕就开（零基础解释：形成层=皮与木质部之间一层会分裂生长的组织）；秋冬皮贴死难剥，但纤维更成熟——初学者先在生长季取，成功率高。
- **初加工一句带过**：沤（泡水数日让胶质腐松）、刮（刮净表皮残肉）、捶（垫石捶散纤维束）。搓捻手法、股数与强度关系、纺线织布的完整工艺见 [绳索与绳结](../09_materials/03_cordage_knots.md) 与 [植物纤维获取与原始纺织](../09_materials/04_plant_fiber_textile.md)——本文只管"认得出、判定可用"，不重复工艺。

### 6. 动物纤维与植物纤维的燃烧鉴别

猎物的毛、残存的织物都要先分清是毛（动物纤维）还是麻棉（植物纤维），办法是烧一根：

- **安全纪律**：沿用 01 篇燃烧试验的全程纪律——露天上风处、样品指甲盖大、备水备沙、扇闻。
- **动物纤维（毛、丝）**：烧时有**烧毛发的臭味**（蛋白质烧焦的腥臭）、边烧边卷、离火常自熄、灰是**发黑的脆珠**，一捻即碎成细粉（已核对子项，见文末）。
- **植物纤维（麻、棉、草）**：烧时有**烧纸味**、火势旺不卷曲、灰是**灰白色软灰**，一碰就散。
- **应用与毡化**：毛纤维在湿热加压下互相咬缠成毡（零基础解释：毡化=毛纤维表面的鳞片互相勾住，越揉越紧成块布），是冬衣冬帽的从零路线（一句带过）；皮革与毛皮的完整处理见 [鞣制皮革](../09_materials/05_tanning_basics.md)。

### 7. 树脂与蜡

- **松脂采集（割口法）**：选松柏类树干，用石刀斜着削开树皮与边材成一个斜口或 V 形口（削到见湿木），树脂渗出流下，在口下方插一片大叶或陶片承接；过几天去收凝块。**每棵树一次只开一两个口、隔季再开**——口太多树会衰弱（与采皮同一逻辑：取用不弄死）。
- **熔化+炭粉调胶（简版）**：松脂放进陶勺或贝壳，**小火**熔化（冒泡即化，火大烧焦失效）→ 撒入细炭粉约树脂量的五分之一到三分之一搅匀成稠胶 → 趁热涂在要粘的缝上（绑石斧头前先涂接缝再捆扎，冷后硬如玻璃）。**用途**：粘结（绑柄、堵缝）与防水（涂陶器裂缝、涂布缝）。
- **蜂蜡**：取蜜的副产品，熔点低、防水、可封罐可照明——获取与用途见 [糖与油脂的获取](../03_food/07_sugar_fat_sources.md)。
- **生漆类接触过敏警示**：产漆的漆树与毒葛、毒栎同科近缘，汁液含同一类致敏物质——**没接触过的人第一次也可能起疹起疱**，沾染处会变黑。从零条件下不取漆（生漆工艺属后期技术），先做到"认得出、不乱碰"：识别红线与属级规避口诀见 [剧毒植物与蘑菇](04_toxic_plants_mushrooms.md)。

### 8. 采伐纪律（取材不留绝户手）

- **留种树**：砍伐区里结果最丰、材性最好的树留下不砍——它们是未来林子的种子来源。
- **剥皮环杀伤**：零基础解释：环剥=绕树干剥掉整整一圈树皮。皮断=树冠向根送养分的通道断，**整树必死**。两面性：要清除劣树腾空地时，环剥是最省力的伐除法；要取皮时，环剥等于杀鸡取卵——**只要皮，只取侧条**（不超过周长三分之一）。
- **间伐优于皆伐**：零基础解释：间伐=隔株疏伐；皆伐=一片推光。稀疏留距的林子持续产出柴与材，推光的林坡十年缓不过来——取材计划按"这片林子明年还在"来排。

## 从零实现路径

依赖链：**观察记录（01 篇描述卡）→ 树种账本（炭条+树皮纸）→ 六件套实测（一把刀或石斧；石器的打制见 07_tools 域石器篇 ../07_tools/01_stone_tools.md，纯文字提示）→ 六类需求配材 → 纤维判定（生长季）→ 树脂采集（有火之后）**。

1. **第 1 周：建"树种账本"。** 每棵典型树一张卡（沿用 01 篇描述卡字段，追加本文专属格）：皮（三词语言记是哪种）、叶（针/阔，松类记束数）、果（何时何形）、六件套六项结果、用途结论。先记营地活动半径内 10～20 种级的主要树——不贪全，记账优先。
2. **第 2～3 周：六类需求各锁定两个备选树种。** 柄（韧+扭纹）×2、弓（压弯回弹过测）×2、板（直纹）×2、碗勺（匀质软材）×2、柴（硬木炭+软引火）×2、绳纤维（撕茎三步通过）×2。**每个需求备两个树种的原因**：一防季节与取材点变化，二防单株误判——两处独立来源都通过才算数。
3. **顺序按工期排**：柴当天就要（当天认出引火与耐烧两类）→ 柄与纤维数日内（柄材优先选立枯材，免阴干等待）→ 弓坯与碗料按周计（要干材，伐下先阴干）。
4. **持续动作**：每次伐树前先查账本"这棵的六件套记录"；没记录的树先补测再伐——补测只花十分钟，误判浪费的是数天工期。

## 方法与应用

有残留物资或现代条件时：钢斧与手锯让劈裂性、韧性试验几分钟出结果；10 倍放大镜看导管与年轮细节；木材图鉴对照树名；棉、麻、毛线各备一段做燃烧鉴别的"对照样"（各烧一次记牢两种灰的差别，比文字可靠）；木材湿度计替代"敲声听干湿"。识别纪律（三特征、找反面证据）在任何条件下不变。

## 常见错误与限制

- **生材急用做柄**：为什么会发生——急缺工具，伐下就削；后果——柄干缩后与器头松动、弯裂，挥动中飞脱伤人；正确做法——柄材用立枯材（天然干透），或伐后阴干数周以上；临时应急柄每用前检查松紧，楔口随时紧楔。
- **凭叶形单特征认树**：为什么会发生——叶最显眼、图鉴也以叶为主；后果——叶形相似的异种错配材（"像橡叶"不等于结好橡子），到结果期才发现认错，工期错配；正确做法——皮+叶+果三特征交叉（01 篇三特征底线），无果期只给"候选"标签，等结果再定。
- **直纹扭纹用反**：为什么会发生——"好劈=好材"的直觉；后果——直纹柄受震开裂、器头飞脱；扭纹当板料，劈不直浪费大半材料与工时；正确做法——先劈后定用途：劈得直的做板料，劈不直的做柄；每根重用材两个方向各试一次。
- **食器用了乳汁树或漆树科木材**：为什么会发生——新伐材无味或味淡，误判安全；后果——乳汁与漆酚类物质渗入食物，轻则口唇肿痒，重则全身致敏；正确做法——食器选材前先看折断处有无乳白汁液、对照 [剧毒植物与蘑菇](04_toxic_plants_mushrooms.md) 红线，漆树科一律排除；做好的碗先装清水泡两天、换水观察有无变色异味再用。
- **整圈剥皮取皮**：为什么会发生——"皮要完整就剥整圈"的直线思维；后果——树必死，皮源与种树源双双断绝；正确做法——侧条剥取、取三留二，或只取已倒木的皮。
- **纤维植物只看外表不撕茎**：为什么会发生——"长得像麻"就当麻用；后果——外表相似的植株内皮一撕就碎，搓绳到一半崩股，捆扎物散架；正确做法——判定试验（一撕二搓三分丝）通过才入账，入账后同一采集点复测两三株。
- **能力边界**：六件套测的是"这一根材"，不是"这个树种"——换树要重测；燃烧试验只分动植物两大类，分不出物种与品质；沉水试受含水与边材干扰，只给粗分；纤维强度没有从零定量法，"对拉不断"（两端各缠手上一圈对拉，同 05 篇渔线测强法）是唯一现场标准。
