# 黏土与土壤

层级：基础
视角：从零重建
阶段：1～2
状态：待核验
更新时间：2026-09-12

## 解决什么问题

脚下这层土决定三件大事：**吃的**（这块地种什么、肥不肥）、**住的**（能不能夯墙、打土坯）、**用的**（哪一撮土能进窑烧成陶）。三件事用的不是同一种土——种地要壤土，烧陶要黏土，夯墙要黏土掺砂。认不出土，三条线全部卡住；认错了土，轻则一季庄稼绝收、一窑碗全裂，重则土墙雨后垮塌。

本文解决四件事：

1. 把抓到手里的任何一把土，分进"砂 / 粉砂 / 黏土"三组里——干搓、吹气、湿搓三步手感，加上能把比例变成数字的沉降瓶。
2. 判断一把土肥不肥、酸不酸（四查 + 两条家庭试验）。
3. 判断它能不能进窑（陶用三连测）、能不能上墙（配比试验条与渗水坑）。
4. 把每个土样的结论归档进记录卡，形成营地自己的"土账"。

试验工具箱里已有的醋酸试验、水试、燃烧试验不在此重复，本文只引用（见 [识别方法论](01_identification_methods.md) 第 4 节）。

## 核心知识与原理

### 1. 土是什么：三种颗粒决定了土的一切脾气

零基础解释：土壤=覆盖在地表的疏松层，由矿物质颗粒、有机质（动植物残体腐烂形成的黑褐色物质）、水、空气四样混成。颗粒按大小分三组，行为天差地别：

- **砂**：零基础解释：肉眼可辨的粗颗粒，粒径像砂糖到盐粒。不保水、不保肥，但透水透气、不成团不黏手。
- **粉砂**：零基础解释：比砂细得多、比黏土粗的中等颗粒，肉眼已分不清单粒。湿时略黏、干时滑如粉，最容易板结成硬壳。
- **黏土**：零基础解释：颗粒细到显微镜级（比面粉细几十倍），表面能吸住一层水膜，因此湿时黏滑可塑、干时硬结收缩。它是陶器的唯一原料，也是土坯的"胶"。

一句话记牢：**砂给骨架，黏土给胶，粉砂居中两头不靠**。判断土，就是判断三者的比例。

### 2. 三组分手感体系（干搓、吹气、湿搓三步）

取样与编号沿用 01 篇描述卡的规则（土样记成"河湾泥-01"这类自定名）。三步分辨全程只需一捧土、一瓶水、十几分钟：

- **第一步：干搓。** 取拇指大的一撮干土（没有干土就掰一块晒半天），放在拇指与食指的指腹之间捻搓。**看到什么算数**：硌手、摸得出单粒、指缝掉粒=砂多；滑腻如面粉、完全摸不出颗粒=粉砂多；又细又涩、捻开后指腹挂着一层泥膜=黏土多。
- **第二步：吹气。** 一小撮干土摊在摊平的掌心，凑近**轻轻**吹一口。**看到什么算数**：扬起一层细尘雾=粉砂多（颗粒细而轻）；纹丝不动=砂（太重）或黏土（颗粒互相黏着）。黏土与砂的最终区分交给第三步。
- **第三步：湿搓**——核心判据，单独写在下一节。

### 3. 湿搓条试验（判别土质的定盘星）

这是土壤工作"手感法"的核心判据，从零条件下第一个做，因为它只需要水。

- **加水**：一拳头土摊在石板或大叶上，挑净石子草根。另一只手蘸水，一次往土里弹三五滴，揉匀后再蘸再揉。**加水终点（可复制）**：土能捏成团、摊开手掌抖两下土团不粘手——粘手=水多，撒一把干土重来；捏不拢、一掰就散=水少，再弹水。
- **搓条**：把泥团放在掌心，另一只手掌压上去**前后直搓、不要转圈**（转圈会把条搓成两头尖的纺锤，量不准），搓到小指粗细（约 3 毫米，即一根筷子细的量级）、约一拃长。
- **判断（三条口径背下来）**：
  - **砂土**：根本搓不成条——一搓就散成碎块。
  - **粉砂**：能搓出短条，但**一拿起来或一弯就断**，断口整齐。
  - **黏土**：搓成长条不断，捏住两头**能绕手指弯成一个环**，环的表面不开裂、内侧不生裂纹。
- 同一块地至少三个点各测一次，三次一致才算数（单点常被一窝蚁穴、一堆粪土带偏）。

### 4. 沉降瓶试验（把手感变成数字）

手感分到"偏黏 / 偏砂"就够了；要定"黏土到底占几成"（陶土筛选、土坯配比都要这个数），用沉降瓶。零基础解释：沉降=颗粒在水里按重量先后落底，重的先沉、轻的后沉——三种颗粒大小不同，落底时间也不同。

- **器材**：一个透明容器（捡到的玻璃瓶、透明塑料瓶——属残留物资，试验不消耗它）。完全没有透明容器时，用浅色陶盆做降级粗判（见本节末）。
- **动作**：瓶内装土到约三分之一（去石子草根），加水到约八分满，加一撮分散剂（零基础解释：让抱成团的细粒互相散开的东西，现代做法用一小勺洗涤剂；从零条件下用草木灰滤出的碱水替代，效果未核验，列入文末待核验）——用掌心堵住瓶口，**上下猛摇到整瓶浑浊看不见底**（摇 2～3 分钟，摇到手臂发酸）。
- **平放静置，分三次读数**：
  - **约 1 分钟**：底层先积出一层粗粒——这是砂。用炭条在瓶外壁刻一条线。
  - **2～5 小时**：砂层上面又积出一层细粒——这是粉砂。再刻一条线。
  - **1～3 天**：上层水由浑转清，顶上薄薄一层——这是黏土。刻第三条线。浮在水面的碎屑是有机质，不计入。
- **算组成**：目测比（或用棍量）三条线之间各层的厚度，各占总土厚的比例就是三种颗粒的百分比——写成"黏 25 / 粉 45 / 砂 30"这种格式。**占比最高的一层决定土名**：黏土层最厚叫黏土质土，砂最厚叫砂质土，三者接近（各三分之一上下）就是壤土——种地的理想土。
- 无透明容器时的降级粗判：把浓泥浆倒进浅陶盆摊成薄薄一层静水，半天后用棍尖挑底部：底部粗粒厚=砂多；挑起的细泥滑腻挂棍、一挑一条=黏土多。精度差，只回答"偏哪头"。

### 5. 陶用黏土三连测与淘洗提纯

不是所有黏土都能烧陶。三连测是三道关，每一步都有专属的失败模式——**失败的土多数能救**（掺砂、淘洗），别急着扔。

- **第一测：湿塑弯环。** 搓一根食指粗、一拃长的泥条，捏住两端**绕手指弯成环**。**看到什么算数**：环外表面不出裂纹、不断=塑性合格（零基础解释：塑性=湿泥能捏成形状并保持住，像揉好的面团，而不是湿沙）。一弯就裂口=含砂多、塑性差。**失败原因**：砂粒撑在颗粒之间，泥没有连续性——救法：淘洗（见本节末）。
- **第二测：晒干坯不开裂。** 用第一测合格的泥捏一只拇指厚的小碗坯（零基础解释：坯=成型后未烧的湿泥器物），放阴凉通风处**阴干 3～5 天**，不许暴晒。**看到什么算数**：干坯通体无裂纹、指甲压不出痕=过。**失败原因分两种**：表面炸开网状细裂纹=黏土太纯、干缩过大——救法：掺细砂或碾碎的干坯粉五分之一到三分之一（熟料的原理与细则见 [陶器制作](../09_materials/06_pottery.md)）；只裂一侧、顺着风口裂=干得太快受晒不匀——移到阴处重阴干。
- **第三测：入火烧后不炸不酥。** 把干坯放进灶膛炭火边缘过夜（离明火约一拳），或明火堆烧透。三种失败模式与原因：
  - **烧的过程中坯体崩裂、碎块弹跳**=含石灰粒（零基础解释：土里混进的小颗石灰石，烧时变成生石灰，回潮时吸水膨胀，把周围的坯体顶炸）——救法：淘洗弃粗粒，或换土。
  - **烧后发黑、断面起蜂窝孔、泡水后有土腥臭、指甲能刮下泥**=有机质多（零基础解释：草根腐叶烧掉了、留下孔洞，器物渗水）——救法：弃用表层土、挖下层净土，加强淘洗。
  - **烧后一碰就酥散掉渣**=火度不足（温度不够没烧透）或砂太多没有连续性——救法：换更旺的火堆、延长烧的时间，或换塑性更好的土。
  - **合格线**：敲之声音发脆（清脆带余音=致密）、泡水一夜不散不化不腥。烧制全程见 [陶器制作](../09_materials/06_pottery.md)，本文不重复。
- **淘洗提纯（救土与提质的通用法）**：土晒干、捣碎 → 加水搅成稀糊，用棍**搅到全浑** → **静置 30 秒**——砂与粗粒先沉底 → 把上层泥浆**缓缓倒进第二个容器**（沉底的粗粒留下倒掉）→ 第二容器静置半天到一天，倒掉上层清水，下层细泥摊开晾到"捏团不粘手"。**重复两遍**，第二遍淘出的泥最细。沉降原理与第 4 节相同，30 秒是留给粗粒下沉的最低时限（参数列入待核验）。

### 6. 找黏土的地方

找土先找"水待过、且水流慢过"的地方——细颗粒只在静水或缓流里沉得下来：

1. **河湾内侧（凸岸）**：河流拐弯处内侧水流慢，细泥沉积成滩。零基础解释：凸岸=弯道内侧那半边岸，水贴着外岸冲刷、内侧淤积。退水期露出的细泥滩优先。
2. **池塘与水坑底**：干涸池塘的底层常是一整层细黏土，挖开上面的黑腐泥往下找。
3. **坡脚残积**：零基础解释：残积=山体岩石长期风化后留在原地的碎屑。山坡上若有黏土岩层，风化下来的黏土顺坡堆在坡脚——沿坡脚隔十步挖一个一锹深的探坑，找细腻土层。
4. **灰白或红色细腻土层露头**：零基础解释：露头=地层裸出地表的位置。挖开表层黑土后见到的灰白/红色细土（红=含铁，不妨害烧陶）都值得取一捧回来过三步手感。
5. **地质线索**：页岩与泥岩本身就是"黏土压成的岩石"——看到这类层状细石，它风化的坡脚与下游河湾大概率有黏土。岩类的辨认判据见 [岩石识别与采集](07_rock_id.md)；更大尺度上"往哪找沉积区"的地质与地貌逻辑，见 11_science 领域的地质地貌篇（待写，../11_science/09_geology_landforms.md，纯文字提示）。

### 7. 土壤肥力判断（四查 + 两条酸碱试验）

同一片地哪块能种、先种哪块，用四条现场检查，从快到慢：

- **一查颜色**：深黑褐=有机质多=肥。**反例要记**：常年积水的洼地也发黑发灰，但那是水泡出来的，不代表肥——颜色必须结合位置判读（洼地存疑，坡地可信）。
- **二查蚯蚓**：一锹挖下去翻面，数断面和翻出来的蚯蚓——**3 条以上=活土**；一条没有=板结、贫瘠或过酸过碱（口径与 [土壤基础与改良](../08_production/01_soil_basics.md) 一致）。
- **三查团粒**：捏开一块指甲大的土块。零基础解释：团粒=土粒被有机质黏成的小米粒到黄豆大的小团。**看到什么算数**：碎开后是许多松脆小团粒、像掰开的面包=结构好（既保水又透气）；散成单粒=砂性瘠薄；硬成大块掰不动=板结黏闭。
- **四查植被**：同地块对比——杂草茂密、叶色浓绿的地比杂草稀黄的地肥。指示植物各地差异大，只做旁证（与 01_soil_basics 的杂草指示法同一限定）。
- **酸碱两条家庭试验（只回答一半问题，局限写明）**：
  - **醋试（测碱）**：取一撮干土摊在陶片上，滴 1～2 滴醋。**明显持续起泡=含石灰、偏碱**（这就是 01 篇试验工具箱的醋酸试验，此处补一句用法：干土直接滴，比调成泥糊更能测出"有没有石灰粒"）。反应的化学原理见 [化学基础](../11_science/05_chemistry_basics.md)。
  - **小苏打试（测酸）**：另一撮湿土放进碗里，加水搅成泥汤，撒一小撮小苏打（零基础解释：碳酸氢钠，即发面用的碱粉；有现代残留时才可得）。**明显冒泡=土偏酸**。
  - **局限（必须记住）**：两条试验都只是"有/无"的二值粗判——**不冒泡不等于土壤是中性**，多数弱酸弱碱土都不反应；家庭园艺资料与园艺社区的一致评价是它只能粗分"明显酸 / 明显碱"、给不出数值（已核对子项，见文末）。真要定量调节（施石灰等），按 01_soil_basics 的试验田对照法走。

### 8. 工程土判断（能不能上墙）

- **配比起步值**：夯土与土坯（零基础解释：土坯=湿泥掺料入模制成的生泥砖，晒干使用；夯土=把湿土一层层填进两块木板夹成的模槽里捣实成墙）按"黏土:砂≈1:2"起步，即黏土约占三成、砂约七成——黏土多了干缩开裂，砂多了不黏、耐不住雨水冲刷（已核对子项，见文末；从零条件下不抄数字，按下面的试验条定出本地的最优配比）。
- **土坯试验条（可复制的配比优选法）**：取同一土四份各一拳头：不掺砂、掺砂 1:1、1:2、1:3 各拌一份（每份再掺一撮剪成两指长的干草茎——草茎像钢筋一样拉住泥，抗裂）。每份搓成小臂长、腕口粗的泥条，排在一起阴干 4～7 天。**判优**：裂纹最少、拿起来对折不断的那条就是最优配比；四条全裂=土太黏，整体再加砂；四条全酥散=太砂，换土或掺黏土。
- **渗水坑试验（选址的硬指标）**：在拟建宅基地面挖一个 30 厘米见方深的坑（一锹宽、一锹半深），灌水到满，等它渗完；**立刻灌第二次**——第二次的计时才算数（第一次的水被干土自己吸走，不代表渗水能力）。**判读**：半天内渗完=排水良好（地基干爽，也适合挖渗水厕坑）；两天后坑里还剩大半坑水=渗水极差（这种地建房返潮，倒适合做蓄水池坑）。

### 9. 记录卡衔接（土账）

土样记录沿用 [识别方法论](01_identification_methods.md) 第 6 节描述卡的字段（名称编号/地点/季节/质地/颜色/试验结果/风险标签），本文追加三格：

1. **沉降瓶三层比例**（"黏 25 / 粉 45 / 砂 30"格式）。
2. **三连测走到第几步、卡在哪**（如"过一测；二测网裂，掺砂 1:5 重测中"）。
3. **归档结论**：种（肥力线）/ 建（工程线）/ 陶（工艺线）——一个土样可以多线并存（壤土=种 + 夯土掺料）。

## 从零实现路径

依赖链：**取样与手感三步（当天，零工具）→ 湿搓条（一瓶水）→ 肥力四查（一把锹）→ 沉降瓶（一个透明罐，可延后）→ 陶用三连测前两测（依赖阴干场地）→ 第三测试烧（依赖稳定的火，[摩擦取火与火种管理](../01_energy/01_fire_making.md)）→ 试烧小碗（依赖陶器工艺，[陶器制作](../09_materials/06_pottery.md)）→ 归档成土账**。

1. **第 1～3 天**：营地活动半径（约 200 步）内取 5 处土样（河滩、坡脚、田里、洼地、塘边各一处），编号 T-01～T-05，做干搓 + 湿搓条，先分出"黏土质 / 壤土质 / 砂质"三档。
2. **第 4～10 天**：对全部土样做沉降瓶（读到第三天水转清），同时对耕作候选地做肥力四查——两份结果并排，得出"种什么、种在哪"的第一版结论（作物选择属 08_production 域，见 ../08_production/02_crop_basics.md，此处纯文字提示）。
3. **第 2～3 周**：对黏土质土样做陶用三连测的前两测；同时对最优样做两遍淘洗。过两测的土才有资格进"陶土候选"。
4. **有稳定火后**：第三测试烧小碗（拇指碗，一次多烧几个样的坯），按"敲声脆、泡水一夜不散"定陶土。
5. **建房启动前**：对备土做土坯试验条定配比、对宅基地做渗水坑定地基——两项结果写进土账；施工细节属 04_shelter 域（纯文字提示）。
6. **归档纪律**：每个土样一张卡，结论只允许落在种/建/陶三条线上；后续任何人取土、开田、筑墙，先查土账再动土。

## 方法与应用

有残留物资或现代条件时：透明玻璃罐/塑料瓶让沉降瓶成为常规仪器；pH 试纸与土壤酸度计替代醋碱粗判（湿土调浆静置后蘸测读色）；窗纱或细筛网（孔 1～2 毫米）让淘洗前的过筛一步到位；"土壤质地三角图"可把沉降瓶三层比例直接换算成标准土名；重建中后期值得送检实验室项目（颗粒分析、pH、重金属）——尤其是疑似污染区，家庭试验测不出毒性。

## 常见错误与限制

- **只取表层浮土下结论**：为什么会发生——表层最顺手、误以为草根少的浮土最"干净"；后果——腐殖混杂的浮土既不代表耕层也不代表陶土层，三连测全测了个寂寞，结论全错；正确做法——先去掉表土一锹深，取地表以下 5～15 厘米处的土，同一块地对角三点取样，三次结果一致才算数。
- **水加过头把粉砂当成黏土**：为什么会发生——"发黏=黏土"的直觉，而水多的任何土都发黏；后果——把粉砂土当陶土用，一窑小碗全裂全酥，浪费数天燃料与工期；正确做法——加水的终点永远是"捏成团、不粘手"，粘手就掺干土重来，再搓条验证。
- **沉降瓶 1 分钟读完就收工**：为什么会发生——看见砂层落底以为试验完了；后果——黏土根本没沉完，把黏土全算进粉砂，比例与土名全错，后续配比跟着错；正确做法——三次读数（1 分钟 / 半天～一天 / 第三天），上层水转清才收工。
- **湿坯直接进火**：为什么会发生——心急跳过阴干；后果——坯内水分剧烈汽化把坯炸裂，误判"这土不能烧陶"，白白放弃可用土源；正确做法——三连测每一步干燥到位（阴干 3～5 天、指甲压不出痕）才进下一步。
- **把醋碱试验当定量结果用**：为什么会发生——起泡现象直观，误以为"没泡=中性"；后果——在弱酸性土上误判安全，作物黄化减产找不到原因；正确做法——它只回答"有没有明显酸/明显碱"，定量与改良一律走 01_soil_basics 的对照试验田。
- **黑土一律当肥土**：为什么会发生——"黑=有机质多"的口诀背死了；后果——选中常年积水的灰黑洼地开田，作物烂根绝收；正确做法——颜色必须与位置、团粒、蚯蚓三查合用，洼地黑土存疑降级。
- **能力边界**：手感、沉降、醋碱只测颗粒组成与粗略酸碱，**测不出养分含量、测不出盐害与毒性**——地表泛白霜状的盐渍土、现代残留场景的工业污染区（垃圾场下游、旧矿区），一律不种入口作物；渗水坑也测不全地基承载力——建房前成人单脚踩地面，下陷超过一指的软土要换址或换填。
