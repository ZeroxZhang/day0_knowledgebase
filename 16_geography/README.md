# 16 全球地理

解决的问题：读懂"大地是一张资源与风险地图"——在哪里能活、哪里有水有石有土、哪里有什么天灾。地理在这里不是地名背诵，而是**生存与重建的选址与资源决策**：每篇都落到"怎么走、怎么认、怎么用"。

与相关领域的分工：[/13_field_guide](../13_field_guide/README.md) 管"一件标本怎么认"，[/11_science](../11_science/README.md) 的 [地质与地貌](../11_science/24_geology_landforms.md) 管"一块地方的地学原理"，本领域管"世界尺度的框架与区域档案"。

## 写作纪律（本领域特有）

1. 距离/面积/深度给可感知量级与本地校准法（如"步行一日约 30 公里""一度纬度≈111 公里"）。
2. 气候带与区域档案一律落到"生存要点"（水/食物/庇护/风险），不写旅游式描述。
3. 11_science 的天气与地质两篇已落成（../11_science/23_weather_climate.md、24_geology_landforms.md），需要时直接链接。
4. 关键数字抽查核实的标"已核对子项"并注明来源与检索日期；查不到的诚实列待核验。
