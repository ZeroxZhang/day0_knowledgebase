# 蒸汽动力原理与安全边界

层级：进阶
视角：从零重建
阶段：4
状态：已核对
更新时间：2026-09-12

## 解决什么问题

水轮要靠河，风车要靠风，都不能搬家、不能加班。蒸汽机第一次把动力变成"想放在哪就放在哪、想开多久就开多久"——烧柴烧煤的 anywhere 动力。但它是整条技术树上门槛最高的一级。**本文的目的不是教你造一台蒸汽机，而是三件事**：零基础理解它为什么能做功；明白为什么在没有冶金、机床、密封件之前**造不出来**也不该硬造；划出安全红线——错误建造的蒸汽锅炉不是动力设备，是炸弹。

它值得排队等待的理由：蒸汽机一出，矿山可以深挖（蒸汽抽水）、作坊可以离开河岸、锻造风炉可以满负荷鼓风，并且它最终通向阶段 5 的发电。在它之前，动力 = 水 + 风 + 人畜；在它之后，动力才真正"自由"。

## 核心知识与原理

**蒸汽为什么能做功——零基础拆解**：

1. **水变汽，体积膨胀数百倍**。在标准大气压下，1 升水全部烧成水蒸气，体积约变成 1600 多升（数值见待核验项）。为什么会这样：水是液态，分子挤在一起；变成气态后分子四散飞开，占据的空间是原来的上千倍。烧一壶水时壶盖"噗噗"跳，就是这股膨胀在顶盖子——盖子越重，跳得越猛，说明里面的汽压越大。
2. **压力推动活塞**。把蒸汽关进一个汽缸（一根内壁光滑的圆管），用活塞（一个能在管里滑动又不漏汽的圆塞）堵住一端：汽压从背后推活塞，活塞就被推着走。推力有多大，零基础算一遍：每平方厘米 3 公斤压力下，一根直径 20 厘米的活塞（面积约 314 平方厘米）受到的总推力约 940 公斤——蒸汽把火的热变成了宏观的巨力。
3. **往复变旋转**。活塞来回直线运动，用 ../01_energy/10_power_transmission.md 讲的曲柄连杆接上飞轮，就变成轴的旋转。
4. **热从哪来**：锅炉（一个封闭的受火容器）里的水被火加热成高压汽，汽经阀门进入汽缸做功，做功后排出。整个机器是一台"把柴火的化学能搬进活塞"的搬运工。
5. **为什么必须有锅炉、不能直接烧汽缸**：汽在工作前必须是干净的蒸汽而不是火。火在锅炉外烧，只把热传进水；汽缸保持在较冷状态（冷汽缸利于纽科门式造真空）。锅炉把"产汽"和"做功"分开在两个部件里，各司其职——也正因为如此，全部的高压都憋在锅炉这一个部件里，**锅炉是全机唯一也是最危险的承压件**。

**压力与大气压——先补一个概念**：我们头顶的空气本身就有重量，它压在一切物体表面，这个压强叫大气压（约每平方厘米 1 公斤）。"3 个大气压"就是比平时空气压在你手上多两倍的压强。封闭容器里的压力每比外面高一分，容器壁就多受一分拉扯——压力差的本质是"里面想炸开"。

**为什么"冷凝能造真空"（纽科门式的核心，零基础版）**：汽缸里塞满蒸汽时，内外压力差不多，活塞不动。往缸里喷一点冷水，蒸汽瞬间被冷却变回几滴水——一千多升的气体缩回几毫升的水，缸里一下子变得"空了"，几乎没有压力。而活塞另一面还压着整整一个大气压的空气。这一里一外的压力差，就是大气把活塞压下去的巨力。**蒸汽在这里的角色不是推，而是先占满、再撤走，让大气来干活的"布景师"**。

**两种历史结构思路**：

- **纽科门式（大气式，18 世纪初）**：汽缸里并不靠高压推活塞，而是靠"真空吸"。工作循环一步步是：①打开进汽阀，低压蒸汽进缸，把活塞**顶**上去；②关阀，向缸内喷冷水，蒸汽遇冷凝回水滴，体积骤缩成接近真空；③缸内几乎没有压力，外部大气压就把活塞**压**下去，这一压就是做功的行程；④再进汽，循环重来。它的好处是锅炉和汽缸只需承受很低的压力（略高于大气压即可）——**用蒸汽造真空、用大气做功**，对材料要求低得多，是从零重建时最现实的构型。代价是效率极低，烧很多柴只出很少功。
- **瓦特式（18 世纪后期）**：不让汽缸内冷凝（另设独立冷凝器），让蒸汽压力直接推活塞做工，并利用汽缸保温省下大量燃料。效率高出数倍，但要求高压密封、精密镗缸、阀门联动——材料与工艺门槛远高于纽科门式。
- **瓦特式改进的动机（看懂它就知道路有多长）**：纽科门机每做一次功都要把整个汽缸反复加热又冷却，大半柴火浪费在"反复捂热冷汽缸"上。瓦特让汽缸永远保温、冷凝另设一间小室，燃料消耗砍掉四分之三左右（通识量级，见待核验项）——这份效率差距，就是材料、机床、密封、仪器四项前置必须补齐的经济学理由。

**量级感：一台纽科门机能干什么**：历史上典型纽科门机汽缸直径约 1～1.5 米，活塞行程 2～3 米，每分钟往复十几次，功率折合十几到几十千瓦——顶几十匹马日夜轮班，主要用于矿井排水。从零重建若造出十分之一规模的小型机，也有数千瓦，等于一台中型水轮，且不受地点限制。这解释了为什么明知低效，它仍是值得排队的台阶。

## 从零实现路径（本文明确到台阶为止）

**依赖链**：柴与炉（有）→ 耐压容器 ← 卡点 ← 密封材料 ← 卡点 ← 精密汽缸 ← 卡点。每个卡点展开：

1. **冶金（最大卡点）**：锅炉必须是一整块致密金属——铸黄铜、铸铁或铆接铁板，壁厚均匀、无砂眼无隐裂。陶器（见 ../09_materials/06_pottery.md）壁厚不匀、有隐裂，受内压必然炸，**任何陶制锅炉都不许试**。铁冶炼与铸造见 13_metallurgy_iron.md（待写，见 ../00_roadmap.md）；燃料前提是成规模烧炭，见 07_charcoal_kiln.md（待写，见 ../00_roadmap.md）。
2. **机床**：汽缸内壁与活塞必须贴合到"不漏汽但能滑动"的程度，公差以毫米的十分之一计。这需要能镗内圆的机床——先有 ../07_tools/07_primitive_lathe.md 的脚踏车床，再在其上发展镗床，属于更后面的台阶。历史上瓦特的关键突破之一正是威尔金森的镗床让汽缸终于够圆。
3. **密封**：活塞与缸壁之间、各接缝处，需要浸油麻绳填料、皮革涨圈或橡胶一类弹性密封件（皮革可自制，见 ../09_materials/05_tanning_basics.md，仅够低压纽科门式使用）。
4. **仪器**：没有压力表，就没有任何手段知道锅炉里憋了多大的劲；没有水位计，就不知道锅炉里的水还剩多少。这两样是运行的眼睛，缺失就不能运行（见安全边界）。压力表和水位计的最原始替代——玻璃管连通水位计（透明管下端接锅炉下口、上端接上汽空间，管内水位即锅炉水位）——在造出耐热玻璃（09_glassmaking_basics.md，待写，见 ../00_roadmap.md）之前同样缺位。
5. **阀门与配汽**：纽科门式至少需要两个手柄阀门（进汽阀、喷水阀），由机械联动按活塞位置自动开合。手工拉绳配汽是调试期的过渡做法，最终必须自动化，否则人力跟不上节拍。

**合理的攻关顺序（把大卡点拆成可推进的小台阶）**：

1. 先稳定烧炭与铁冶炼（13_metallurgy_iron.md，待写，见 ../00_roadmap.md），能出致密铁锭与简单铸件；
2. 用脚踏车床与水轮动力磨镗出第一根够圆的小汽缸（直径 10～20 厘米级，不要贪大）；
3. 先造**敞口低压锅炉+安全阀**，只做提水试验，绝不做封闭加压；
4. 表与阀齐备后，才尝试纽科门式小机，且首台远离人群、掩体后操作。

**到达该台阶前的替代路线**（本文的正面产出）：

- 动力需求先用水轮与风车解决（../01_energy/08_waterwheel.md、../01_energy/09_windmill_basics.md）；
- 可以先做**不承压的蒸汽应用**：蒸汽蒸馏提纯水、蒸汽加热（低压敞口），这些不需要耐压容器；
- 用蒸汽做功的**非受压演示**：在敞口壶上装一个叶轮风车（汽轮雏形），其安全性等同于一壶开水，可用于理解原理。

**安全边界（本文重点，逐条红线）**：

1. **无压力表、无安全阀，不得运行任何封闭受压容器。**这不是保守，是数学：压力表缺失意味着你把"运行还是爆炸"的决定交给运气。安全阀的最原始形态——一块压在排汽口上的配重铅块/杠杆阀，压力超限自动顶开排汽——也必须先于锅炉存在。
2. **锅炉爆炸的破坏量级**：一台卡车汽缸大小（约半立方米）的锅炉在几个大气压下爆炸，储存的能量相当于把上百公斤的碎片加速到炮弹初速——铁壳变成破片雨，能掀翻作坊的墙，爆炸瞬间闪蒸出的过热蒸汽还会烫伤周围所有人。历史伤亡记录极多。**距离也是保护：试运行时人必须躲在掩体后。**
3. **低压也不等于安全**：纽科门式锅炉设计压力低，但排汽口堵塞、水垢过热、火势失控都会让"低压"悄悄变"高压"，设计上就要装安全阀并每次运行前检查是否被锈卡死。
4. **陶器、石容器、木桶、玻璃容器永远不得作为锅炉**，无一例外。木桶能承几个大气压是啤酒桶级的错觉，受热后接缝松脱即喷汽伤人。
5. **低水位烧干**：锅炉水位低于火面，钢板直接受火，强度骤降，几秒内爆裂。补水与停火必须优先于一切。
6. 本知识库**不提供锅炉建造图纸**。知道原理、知道门槛、知道危险，就是本文要传达的全部。

**未来若真走到运行那一步，每次点火前的检查单（哪怕设备来自残留物资也照此执行）**：

1. 压力表：轻敲表盘指针回零、读数正常；
2. 安全阀：手动提抬一次，排气顺畅、落座复位；
3. 水位：水位计显示在最低线以上，补水通道畅通；
4. 受热面：肉眼检查锅炉外壳无鼓包、无渗水锈迹（渗水点是减薄的信号）；
5. 排汽管：无堵塞、出口朝无人方向；
6. 人员：操作者就位、观察者撤到掩体后、无关人员清场；
7. 预案：备好湿毯与沙土，约定"异常响声立即撤"的暗号——爆裂前常有嘶鸣与颤动，那是最后的逃生窗口。

七项有任何一项不过，当天不点火。检查单本身应抄在窑口或门边的陶片上，成为不依赖记忆的规程。

## 方法与应用

- 若残留有成品压力表、安全阀、锅炉钢板，可评估用于纽科门式低压试验——但仍以"表+阀齐全"为运行铁条件。
- 蒸汽的非动力用途可立即做：敞口蒸馏（净化水、提取精油与酒精，注意乙醇易燃）、蒸汽灭菌（处理伤口布巾）。
- 教学演示：壶嘴汽吹纸风车，向群体直观展示"汽能推轮"，为后续动员资源建立共识。
- 知识传承角度：把纽科门循环四步（进汽-顶起-喷水-真空压下）画在陶片上做成教学板，配文字说明（若阶段 5 文字已建立），让"为什么现在不能造、要先补什么"成为群体共识，防止有人冒进试锅炉。
- 排期定位：按 ../00_roadmap.md，本节点排在阶段 4 末端——水轮风车运转、车床能出精密圆件、冶金过铁之后才轮到它，早于任何一项前置都是拿命试错。
- 技术储备清单（造蒸汽机前必须逐项打勾）：稳定产铁/黄铜、能铸无缺陷的厚壁件、能镗圆汽缸、有密封填料、有压力表与安全阀、有懂得盯水位盯火压的值班规程。
- 应用排序建议：第一台蒸汽机应固定安装做**抽水**（矿坑排水或灌溉提水）——往复运动直接用，不需要精密的旋转传动；磨面、锻打等旋转负载等第二台。

## 常见错误与限制

- **"陶炉烧水没问题，加个盖就是锅炉"**——致命错误。陶器承内压的能力接近于零，盖紧的陶罐就是土制炸弹。
- **低估水垢**：硬水在锅炉内壁结的水垢是隔热层，垢下金属过热软化，是真实历史上锅炉爆炸的首要原因之一。从零重建没有除垢药剂，只能定期拆洗，这又要求锅炉可拆。
- **跳过水轮直接攻蒸汽**：水轮提供的机械动力正是造镗床、锻设备的能源。没有水轮/风车就想造蒸汽机，等于没有梯子爬楼。
- **把"原理"当"工艺"**：理解四步循环与造出密封汽缸之间隔着冶金、机床、密封、仪器四座山，任何一座没翻过去就是爆炸或白干。
- **忽视操作规程**：锅炉一旦运行，需专人盯火盯水位——水位烧低让火直接烧到无水钢板，是另一种爆炸路径。
- **以为纽科门式"安全"就免检**：低压机组的危险在于"从低压悄悄漏成高压"，安全阀锈死等于没装。
- **单点依赖操作者**：锅炉运行的每一分钟都必须有人值守，"离开一会儿添柴"是事故高发时段；值守交接必须口头逐项过一遍水位、压力、火势。
- **忽视冬季冻害**：锅炉与管道露天过夜，残余水结冰胀裂壁体，来年开炉即漏——停炉必须放空。
- **把蒸汽演示扩大化**：敞口壶吹风车是安全的，一旦有人提议"给壶加个盖压力就大了"，必须按安全红线当场制止——从演示到爆炸只隔一个盖子。
