# 植物纤维获取与搓绳、原始纺织入门

层级：基础
视角：从零重建
阶段：1
状态：待核验
更新时间：2026-09-12

## 解决什么问题

你一无所有地站在野外，手里没有一根绳子。没有绳子，你无法把树枝捆成棚架、无法把石斧头绑上木柄、无法系住渔网的网眼、无法拖拽重物、无法捆扎柴火过夜取暖。本文解决三件事：

1. 从植物和动物身上把"纤维"取出来；
2. 把零散的纤维搓成结实可用的绳线；
3. 再用搓好的线完成最原始的编织（席子和带子），为之后做渔网、织布、缝衣铺路。

## 核心知识与原理

- **什么是纤维**：植物的"筋"。
  - 植物体由无数细长的小盒子（细胞）拼接而成，每个小盒子的墙（细胞壁）主要成分是纤维素——一种又韧又难溶于水的物质。
  - 如果某种组织里的细胞特别长、细胞壁特别厚，并且成束排列，撕开时就能看到银丝一样的细丝，这就是纤维。
  - 通俗地说，**韧**的意思是"能弯能拉而不断裂"。玻璃硬但一敲就碎；麻绳软却吊得起石头，因为麻绳由上千根长纤维互相抱紧组成，拉力被分摊到每根纤维上。
- **为什么绳索是文明的根基**：石头可以砸，木头可以削，但两块材料要"合为一体"必须连接。在没有钉子和胶的世界里，唯一的连接手段就是**捆扎**。
  - 捆扎 = 建筑的前提：横梁绑上立柱，才有屋架。
  - 捆扎 = 工具的前提：斧头绑上柄，才叫斧。
  - 捆扎 = 渔猎的前提：网靠结，弓靠弦，陷阱靠活套。
  - 捆扎 = 搬运的前提：背架、拖橇全靠绳。
  - 结论：技术上先有绳，才有后面的一切组合。
- **捻与股**：
  - 单根纤维又短又滑，捏住一捻，它们靠摩擦互相咬合成长线——这个过程叫**捻**（像搓烟卷那样把散纤维搓转起来）。
  - 搓好的每一根线叫一个**股**；单股线的致命缺点是：一端松开，整根散掉。
  - 解决法：把两根（或三根）都捻好的股，再向**相反方向**合在一起，这叫**反向捻合**（ply back-twist）。
- **反向捻为什么会自锁**：
  - 单股线是向右搓转的（想象螺丝拧进去的方向），它内部存着"想转回去"的劲，所以放着不管会自己松开。
  - 把两根右捻的股向左合捻时，合捻的外力正好顶着股内想回松的劲——股越想松开自己，就越把合股缠得更紧。
  - 松紧互相抵住，绳就**自锁**：剪断一端也不会整根散架。
  - 口诀：**单股向右，合股向左**（反过来"左股右合"也成立，全程一致即可）。
- **纤维来源的取舍逻辑**：好纤维从优到劣大致是——韧皮（树皮内层、麻类茎皮）＞棕榈叶脉／椰壳＞动物筋腱毛发＞草茎。
  - 韧皮纤维最长最韧，做承重绳；草茎短而脆，只做一次性捆扎。
  - 动手前先做**指甲掐折测试**：取一根细丝弯成 U 形反复折——折两三下就断的是脆纤维（只能粗用）；能折十几下不断、越拉越起毛成丝的才是好纤维。

## 从零实现路径

依赖链：**先要有带刃工具，才能剥皮刮纤维；先有火，才能烘干纤维与线**。

- 石刀打制：见 [../07_tools/01_stone_tools.md](../07_tools/01_stone_tools.md)。
- 取火与烘干用火：见 [../01_energy/01_fire_making.md](../01_energy/01_fire_making.md)。
- 骨锥、木刮板等辅助工具：[原始木工](../07_tools/06_woodworking_primitive.md)。

### 第一步：辨材与测试

1. 认准三类目标：树皮内层（柳、椴、桑三种树的内皮最常用）；草本的茎皮（荨麻、苎麻）；权宜材料（棕榈叶、椰壳、茅草、蒲草）。
2. 对每类候选材料各撕一小条，做上面的指甲掐折测试，先小试再大量采集。

### 第二步：取树皮内层（以椴为例）

1. 选手臂粗以上、生长旺盛的活树——活树内皮湿润有韧性，枯树皮脆。
2. 用石刀在树干上环形切断树皮：两道环切相距一臂长，再竖向切一刀连通两环。
3. 手指抠进切口，沿木头表面整片撬起树皮。
4. 边撬边用石刀刃**贴着木头**平推，切断连着的细韧皮束——刃口要几乎平放刮，不要立着砍，否则会割断内皮。
5. 树皮整片剥下后，外层（深色、易碎的那面）朝上，用石刀刃以"刮"而非"切"的方式斜着把外层栓皮推掉，只留下浅色、能撕出丝的**内层韧皮**。
6. 判断刮净的标准：撕一窄条，撕口能拉出连续的丝而不断成粉渣。

### 第三步：沤泡软化

1. 新剥的内皮又硬又挺，直接搓会扎手断裂。
2. 把内皮一卷一卷松松地捆好（不要捆死，水要能进出每层），沉入静水塘或溪流回水湾，上面压块石头防浮起。
3. 浸泡天数参考：夏季温水约 5～14 天（随水温差异大，列待核验项）。
4. **每 2～3 天捞起来检查一次**：捏住一端撕一条——撕口整齐脆断，继续泡；丝能撕长而不断、手感发滑发软，就到位了。
5. **换水**：死水塘里泡出的水会发黑发臭。检查时顺手把材料挪到水流稍动的地方，防止烂过头——判断烂过头的标准：一拉整条纤维成糊状断掉，而不是分出丝。
6. 没有水塘时改用**焖沤**：内皮铺在湿草堆里盖严，每天浇一次水，7～14 天左右达到同样软化效果（天数待核验，以撕丝测试为准）。

### 第四步：撕刮出丝

1. 捞出沤好的内皮，清水里漂洗，洗掉黑水和腐屑。
2. 左手捏住皮条一端，右手拇指和食指捏住皮条横截面的薄薄一层，**顺着纤维方向撕**；每层撕成火柴棍到筷子宽的窄条，宽条不匀没关系，后续搓捻会自动找平。
3. 遇到硬块（节疤、残留栓皮）：把窄条平铺在膝盖上，用石刀刃或贝壳刃与纤维约成 30 度角**轻轻推刮**，刮掉硬点而不切断丝。
4. 撕好的湿丝条挂起来晾晒，干到发白但不脆（捏一把不扎手）即可搓绳。

### 第五步：草本茎皮（荨麻、苎麻）

1. 草本取的是茎的外皮，做法与树皮不同：不剥皮，而是**收割整根茎**。
2. 荨麻刺毛扎皮肤，先在手上裹布或垫大叶再操作；从根部割下整茎，去掉叶和花穗。
3. **碾压**：把茎平放在光滑石面上，用圆木棍前后滚压，茎髓（中间白芯）碎裂，外皮与芯分离。
4. **开缝抽皮**：指甲在茎节处掐开一条纵向缝，从缝处把整条外皮像剥香蕉皮一样整条揭下。
5. 揭下的湿皮直接撕成窄条用；若皮仍发脆，按第三步泡水软化。
6. 苎麻皮更厚：平铺石上，用石刀刃刮去外表面胶质层，留下的内层即为上等纤维。

### 第六步：棕榈与椰壳

1. 棕榈叶：撕下整片老叶，从叶缘开始顺着叶脉把叶片撕成细条；或取叶柄基部的纤维鞘撕散。
2. 鲜叶条可以直接搓临时绳；干后变脆，仅够短期用。
3. 椰壳（椰棕）：用石刀把老椰子外壳切成拳头大块，垫石砸散、踩散，纤维与碎壳屑分离。
4. 用手像抖毛毡一样抖出碎屑，留下的棕色丝束就是纤维。
5. 椰棕耐海水浸泡，适合渔网与船缆；但纤维短而毛糙，只能搓较粗的绳。

### 第七步：动物筋腱与毛发

1. 筋腱取自猎物腿部，取筋与剥皮处理见 [鞣制皮革](05_tanning_basics.md)。
2. **干态分层**：把筋平铺石上，用石刀刃横着轻刮，再用指腹反复揉搓，筋会分层散开成白丝束。
3. 这一步必须在筋**完全干燥**时做——湿筋刮不成丝。
4. **干态捻合**：丝束极短（几厘米），端头错开搭接，放在两掌之间，两掌相对前后搓捻，边捻边续丝。
5. 捻紧的干筋线硬挺如现代尼龙线，是缝皮、绑箭头最好的线。
6. 毛发：兽毛（马鬃、长毛兽的背毛）表面光滑无咬合，捻合性差——必须与筋丝或植物纤维混捻，单用只适合编发辫式的短绳。

### 第八步：草茎粗用

1. 茅草、蒲草、稻草不沤不撕，捆成小把直接当"绳"用。
2. 方法是**辫**：把草把分成三束，像编辫子一样左右交替压编。
3. 辫出的草绳能捆柴、铺床、盖棚顶，但拉力弱、遇雨即腐，只做一次性用途。

## 方法与应用

### 搓绳核心一：手搓式反向捻（两股线）

1. **准备**：两束纤维条，各先搓成一股右捻的单股线。每束长度取目标绳长的 2 倍以上（捻合会吃掉长度）。
2. **搓单股**：
   - 左手拇指与食指捏住纤维束距端头约一拳处。
   - 右手拇指、食指捏住下方一段，**向前（向右）滚搓**，让纤维束在指间转起来。
   - 右手不移开，紧跟着把搓转的那段**向左对折靠拢**到左手边——单股就靠这一折固定住捻度。
   - 左手松开、移到新位置捏住，右手下移搓下一段；全程口令：**搓、折、移、搓**。
3. **合股反向捻**：
   - 取两根已右捻的单股线，端头并齐打一个死结固定。
   - 左手并排捏住两股，右手把两股**合在一起向左（反向）搓转**，搓紧后立刻向右对折——两股就绞成麻花。
   - 右手下移到新的未捻段，重复"反向搓、对折、下移"。
   - 关键手部细节：右手搓转时拇指食指要**夹紧两股不让它们互换位置**，一换位就打结废掉。
4. **两股如何"交替捻"**：
   - 合股时并非两股一起死转，而是右手每次只多搓紧**靠上或靠下的一股半圈**，搓完立刻对折锁定，再搓另一股。
   - 这样两股始终轮流被上劲，粗细和松紧才均匀。
   - 若发现一股明显松于另一股：停下，单独给松的那股补搓几圈再合。
5. **接长**：
   - 单股纤维用完时，新纤维束的端头**削薄成斜面**，与旧端头重叠一掌长，继续搓捻——斜面重叠让接头处粗细不变。
   - 接长必须在合股前完成。
   - 同一位置不要让两股同时有接头，错开一掌以上。

### 搓绳核心二：从 2 股细线到 3 股粗绳

1. 细线承重不够时升级：把 3 根已反向捻好的细绳并排，端头结在一起，挂高固定。
2. 三根分开悬垂，右手捏最右一根，**向其自身捻向补捻上劲**（右捻的继续向右）。
3. 补过劲的那根立刻压向左移一根位，换中间那根补捻。
4. 如此循环：每根被"上劲"后立即压移换位，三股就互相绞紧成粗绳。
5. 合格的现象：绳身出现均匀紧密的麻花纹，捏起来发硬。
6. 若局部鼓包，说明某股没上够劲——把鼓包处那股单独补捻再合。

### 搓绳核心三：大腿搓法（产量更高）

1. 坐在地上，左手捏住纤维束端头。
2. 右掌外侧把纤维束**压在大腿上向前推滚**：推时手掌发力搓转纤维，回抬时让纤维束空转回松半圈（靠纤维自身弹性）。
3. 每推滚一次，左手跟着捻松方向放出一点新纤维。
4. 推滚 10～20 次即可出一段长捻单股，比手搓快数倍。
5. 合股时同样在大腿上反向推滚。
6. 注意：裤料或腿毛会被夹住，先垫一块皮革或厚布。

### 强度测试

1. **吊重测试**：绳中段系住一捆柴（或石块），离地悬空静吊约 20～30 分钟。绳不断、伸长不再增加，方可用于承重；吊人的绳要能静吊不小于体重 5 倍的重物（现代生命安全绳惯例安全系数 5～10:1，已核对：NFPA 2500/OSHA 口径），倍数宁高勿低。
3. **绞勒测试**：两人各执一端向相反方向拧绞，绳身绞紧数圈不散股、不断裂，说明反向捻自锁可靠。
4. **结扣测试**：实际使用前，在绳上打一个你将用的结，收紧后吊重——结会削弱强度（原因见 [03_cordage_knots.md](03_cordage_knots.md)），必须带着结测试才算数。

### 绳的保养

1. 不用时盘成直径不小于小臂长的圈，悬挂在通风背雨处；不可贴地——地面潮气会让纤维霉变。
2. 被雨淋过要隔几天解开晾晒一次。
3. 与岩石、木棱摩擦的部位用皮子或草垫隔开，或定期把绳换一个磨损面。
4. 绳端头随时用纤维缠裹或打死结，防散股。

### 原始织造入门

1. **经纬概念**：把一组线绷直固定，这组叫**经线**（"经"即纵向不动）；另一组线横向一上一下交替穿行，这组叫**纬线**（"纬"即横向穿行）。
2. 每穿一根纬线，把上下穿法反过来（上一根压住的这根变成被压），纬线就被锁进网里——布就是这么织出来的。
3. 先练两个不需要织机的东西：编席和织带。
4. **编席**：
   - 取长草（蒲草、茅草）对折成 U 形，U 形钩挂在一根横杆上排成一排。
   - 用第三根草从排头开始**一上一下**跨过每个 U 形臂，走到头折返。
   - 下一行的上下关系对调，每行织完用手指把草推紧压实。
   - 织到约一臂宽即成坐垫、睡席或棚顶衬层——这本质上就是最简单的经纬。
5. **织带（简易架法）**：
   - 两根光滑木棍，间距两臂，把 10～20 根搓好的线根根分开平行绷紧，两端分别系在两棍上。
   - 经线张力以拨动时"嘣"响为准。
   - 取一根纬线，一端系在最外侧经线上，右手持线头按"挑一根、压一根"的口诀穿过所有经线。
   - 每穿完一行，用一根扁木片（梭子的雏形）把纬线打紧，行行交替上下，即得一条扁带。
   - 扁带就是窄布：可做背带、绑腿、网纲。
6. **卡片式织带（进阶）**：
   - 取几片方形薄木片或硬贝壳，四角各钻一孔（钻孔用石钻，见 [../07_tools/01_stone_tools.md](../07_tools/01_stone_tools.md)）。
   - 每片穿 4 根经线；相邻卡片孔的穿法相反。
   - 转动卡片时经线自动分组上下换位，纬线穿过——捻转卡片即自动"开口"，比手挑省力，还能织出斜纹。
   - 卡片数量决定带宽，几片即可起步。
7. 织出的成品只到带、席为止。真正织整幅布需要织机（综、杼）——完整工艺见 [织机与织布](15_loom_weaving.md)。

## 常见错误与限制

- **跳过沤泡直接搓**：鲜内皮又硬又滑，搓时打滑掉渣、干后整根崩断。宁可多泡两天，以撕丝测试为准。
- **沤过头**：泡太久纤维被微生物分解，颜色深褐、一拉成糊。发现撕口发糊立即捞出。
- **捻向混乱**：单股右捻、合股也右捻，绳会自行松散。同一根绳全流程捻向必须固定，中途发现捻反必须拆掉重合。
- **捻度不足**：看起来像绳，一受力股间滑移、绳身变细拉断。合格标准：捻紧后捏不动、松手不回弹松脱；宁可过紧（绳会略扭卷），不可过松。
- **接头集中**：两股的接头挨在一段，那里强度减半。接长时把接头错开一掌以上。
- **湿绳估算强度**：植物纤维绳湿态强度下降明显（常见口径为下降 15%～25%，已核对：绳索技术资料），雨后吊重需重新测试。椰棕例外，较耐水。
- **用错场合**：草辫绳、棕榈鲜叶绳只做一次性捆扎，拿去吊重会突然断裂；承重只用沤制韧皮或麻类搓的绳。
- **筋腱受潮**：干筋线遇水变软失去强度，绑箭头、缝皮的筋线部位要避水或改用植物纤维线。
- **树皮取用要节制**：环剥一圈树皮会让树死亡。纵向条状剥取，或选将砍伐的树，维持长期纤维来源。荨麻处理全程护手，收茎前先除叶，避免刺毛折断留在皮上扎手。
