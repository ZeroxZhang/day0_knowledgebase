# 动物纤维：羊毛、毛毡与纺纱

层级：进阶
视角：从零重建
阶段：1～3
状态：待核验
更新时间：2026-09-12

## 解决什么问题

鞣制皮革解决了"挡风与耐磨"，但皮衣重、不透气、汗气闷在里头；植物纤维织的布挡得住风，却锁不住一层静止空气——夜里降温照样失温。毛是第三种衣料：轻、能把空气锁进纤维的卷曲缝隙里，湿了仍有余温，还能不纺不织直接压成毡。本文解决四件事：

1. 从动物身上把毛取下来（换毛季拾取、皮张取毛、畜群剪毛）；
2. 把带油带杂的原毛洗成可纺的净毛，再梳成顺直的毛条；
3. 用纺锤把毛条纺成纱、反向合股成线——为织布与缝线供料；
4. 不经纺纱，直接把毛压成毡片，做帽、靴、垫。

## 核心知识与原理

### 毛、绒、皮是什么关系

- **毛与皮**：毛是皮肤上的角质附属物（成分是角蛋白，与指甲同源），从皮的毛囊里长出来；皮是皮肤本体（成分是胶原，鞣法见 [鞣制皮革](05_tanning_basics.md)）。取毛不等于取皮：毛要从毛囊里分离出来，皮另作他用。
- **粗毛与绒**：兽的被毛分两层——外层**粗毛**（又称枪毛、护毛）长、直、粗，负责挡雨；内层**绒**（底绒、绒毛）短、细、卷曲，是保暖的主力。绵羊经长期选育几乎通体细毛、粗毛极少；山羊、鹿、野兔则粗绒分明——取毛优先取绒，粗毛留给毡垫与填充。
- **羊毛纤维为什么特殊**：羊毛表面覆盖叠瓦状的**鳞片**（毛干外层一片压一片的角质薄板，摸着发涩、看着哑光），内部是弹性皮质层。鳞片让两根毛互相"咬毛"（顺鳞片方向滑、逆鳞片方向卡），这是毛能纺成纱、能毡合成毡的物理根据；麻、棉纤维没有鳞片，所以不能毡。

### 毛的来源与获取

按"从零到有畜群"的顺序：

1. **换毛季拾取（阶段 1，无畜群）**：多数温带兽类春季换毛，旧毛成簇挂在灌木枝、树干蹭痕处、兽窝与卧迹周边。辨认动作：看见毛丛先看根部——带白色毛囊根点的是自然脱落毛（干净好洗）；带血肉残迹的是屠宰皮上的毛，另走第 2 条路。雪兔、鹿、狼的绒都可用；拾到的毛常混草籽，量大时按洗毛一节先手工拣杂。
2. **皮张取毛（阶段 1，有猎物时）**：猎物连皮剥下（剥皮手法见 [鞣制皮革](05_tanning_basics.md) 阶段一），趁皮张半干、毛根松动时用手掌或刀背把绒成把抓下；或走灰水脱毛工序时回收——灰水池中浮起的毛捞出、清水漂净、阴干。注意：过碱的毛鳞片受损、纤维发脆，只够做毡垫，纺细纱不用碱泡过的毛。
3. **畜群剪毛（阶段 2 起）**：羊入圈畜养后（见 [小型养殖基础](../08_production/07_small_livestock.md)），每年春末剪一次。没有剪刀时用两把石刀刃口对拉"铰"断毛，或用燧石片离皮一指削毛（贴皮削易伤羊，留茬高些宁可费工）。一只中等体型的羊年产毛数公斤量级（污毛，含油杂；随品种差异极大，待核验）。
4. **量的账**：一件成人毛背心约需净毛 300～500 g 量级（待核验）——拾取路线凑不齐，畜群路线一两成年的羊一年就够，这是"毛要成产业"的最低规模锚点。

### 洗毛：去脂去杂而不毡化

原毛上黏着**羊毛脂**（皮脂腺分泌的蜡状油脂，手摸发黏、带羊膻味）与汗盐、粪块、草屑。不洗的毛引条不顺、纺不出匀纱。

- **毡合三要素先记住**：毛鳞片 + 碱/皂 + 摩擦 + 温度。洗毛的矛盾在于：去脂需要热水和碱，而这俩正是毡化的助燃剂。但检索核实的口径是：**毡化的引爆点不是热水本身，而是温度骤变与搅动揉搓**（见文末来源）——热水只是让鳞片张开、纤维膨胀，一脚骤冷或一阵搓揉才让张开的鳞片互相咬死。所以洗毛铁律两条：**水温恒定、只按压不搅动**。
- 步骤：
  1. **拣杂**：毛摊在席上，手工拣净粪块、草棍、虫尸——洗之前不拣，脏东西泡开了更难除。
  2. **温水预浸**：手感温热不烫手的水（约与体温相当）泡 1～2 小时去汗盐；水变黄浊即倒掉换水。
  3. **热皂水洗脂**：水烧热到"手快速点试发烫、只能短时耐受"的程度（约 60 °C 量级；羊毛脂约 60 °C 熔化流动，检索口径 60～70 °C 有效）。皂用草木灰清液（草木灰装袋按灰:水约 1:5 泡出的清液，摸着滑腻）或自制皂化水（制法见 [草木灰制皂](10_soapmaking.md)）。毛按入水中全部浸没，**静泡一刻钟到半小时，中途只用手掌把露出的毛按回水下，绝不来回搅动**。水太脏就换第二次热皂水，同样静泡。
  4. **同温漂洗**：漂洗水必须与洗毛水**温度一致**（差一口热气都不行——骤冷让鳞片骤然咬合，整批毡成一块）。漂洗 1～2 次，每次泡一刻钟，同样只按压。
  5. **沥水与晾干**：双手托住整团毛从水里捧起，**只按压排水，禁止拧绞**；摊在席或网上阴干，半天翻动一次，干到抓一把松开即散、无黏感为止。
- 判断洗净：净毛抓一把松开后蓬松回弹、色泽发白、凑近闻无膻味；仍发黏结块 = 脂没洗净，重复第 3 步。

### 梳理：把乱毛理成顺条

- **为什么必须梳理**：洗后的毛仍是乱团——纤维方向各异、结块与短毛混着。直接纺，捻度吃不进乱纤维、纱面粗节不断。梳理让纤维**平行排列**并挑除结块，梳出顺直的**毛条**（一卷松松的、两头能拉出锥形的长条毛卷），引条才连续。
- **手梳制作**：两块巴掌大的骨板或硬木板（兽肩胛骨最合用），一面钻 3～4 排孔（孔距约小指宽），孔里紧插入削尖的硬签——硬木签、粗鱼刺、兽刺都行，露出一指高；紧配合不够时用烤软的松脂点在孔里黏牢。没有板料就用**刺果**：蓟类带倒钩刺的球头干花绑成一把，是天然的细毛手梳（传统用法，细节待核验）。
- **梳理动作**：左梳齿朝上持定，取一小撮毛（拇指粗）铺在齿上；右梳齿斜插进毛里、插入半深，两手向相反方向拉——齿间对拉几次，毛就从左梳转移到右梳并被理顺；拉出的结块杂质随手挑掉。把顺好的毛从齿上剥下、松松卷成卷，即成毛条。一撮毛梳 5～10 个来回即顺；成功的现象：手感滑顺，对着光看纤维都朝同一个方向。
- **顺毛纪律**：所有毛条让纤维尽量朝同一方向卷——纺纱时喂毛方向一致，纱面才匀。

### 捻度：线为什么会结实

- 单根毛纤维只有几厘米到十几厘米长，两端一拉就滑脱。**捻**（把纤维束搓转起来）让纤维互相压紧、靠摩擦咬合成整体：拉其中一根，摩擦力把拉力传给旁边一根，根根相传——这就是捻度让短纤维变成长纱的全部原理。
- **捻度不是越多越好**：捻少了纱松散（一拉就散股）；捻多了纤维斜着承受拉力、纱身起卷打结（过捻——纱自己拧成麻花圈）。合格口径：捻到纱身硬挺、两指捏住两端松手后**不回捻打卷**即为到位。
- **捻向**：右捻 = 顺时针搓（把纱竖起来看，表面斜纹从左下爬向右上，纺织学称 Z 捻）；左捻 = 逆时针（S 捻）。本库口径与 [植物纤维获取与搓绳、原始纺织入门](04_plant_fiber_textile.md) 一致：**单股右捻，合股左捻**（反过来"左股右合"也成立，全程一致即可）。

### 纺锤：结构、尺寸与动作分解

**纺锤（drop spindle）**是一台最简单的捻线机：一根直杆穿过一个配重盘（锤轮），靠盘的重量让杆像陀螺一样持续旋转，旋转把捻度加进引出的毛条。

- **结构三件**：锤杆——直、圆滑的干硬木杆，长 20～25 cm（加工见 [原始木工](../07_tools/06_woodworking_primitive.md)）；锤轮——配重盘，陶片敲圆磨边钻孔、硬木圆片、薄石片皆可，孔打在正中，直径约 7～8 cm；钩或刻槽——杆顶端绑一个弯钩（硬枝烤弯、骨签弯头）或刻一圈凹槽，用来挂住纱。
- **尺寸口径**（初学检索口径）：总重 25～35 g（纺粗毯纱可加重到 50～60 g）；**顶置轮**——轮装在靠近杆顶端、钩的下方，对初学者最友好（转速稳、不易脱线）；轮盘的重量越靠外缘，旋转越久越稳。
- **绕导线**：取一段约一臂长的现成纱（或临时搓一段粗线），顶端在杆顶钩上打死结，贴杆绕两三圈、绕过锤轮上缘，末端留一个能穿毛的小环——这就是**导线**，正式的纱都先捻在它后面。
- **动作完整分解**（坐姿，纺锤垂在右膝外侧，离地一拳，不触地）：
  1. **喂毛**：左手持毛条端头，把一撮毛与导线环的尾端搭接约一掌长。
  2. **搓捻**：右手掌贴杆，从杆顶向膝外方向推搓（从上往下看为顺时针 = 右捻），杆带动导线与搭接的毛一起转；搓到搭接段吃进捻、目测已转 10 圈上下再松手。
  3. **引条**：这是决定纱粗细的一步。左手拇指食指捏住毛条，位于捻点（已捻纱与未捻纤维的分界处）上方约一拃处，**匀速向后上方抽**——抽出的纤维量就是纱的粗细：抽出一根火柴棍粗的量，纺出的就是中粗纱。捻点上方未捻的纤维呈一个**锥形**（越靠近捻点越细）——锥形匀速后退 = 引条正常；锥形忽粗忽细 = 抽速不稳，纱上会出现串珠状鼓包。
  4. **加捻上行**：捻度顺着锥形往上爬，爬到左手捏点时该段纱完成；右手搓杆不停，杆停了就补搓几次——捻度不足的段宁可停下补捻，不要带着弱节往下走。
  5. **收纱**：该段够一臂长时，把钩上的纱退下，绕到杆上锤轮下方绕存，再引上钩，继续下一段。
- **什么算成功**：新捻出的一段纱能吊起整只纺锤悬空半分钟不断；两指捏纱身搓一下不散；纱面捻纹均匀、无鼓包无弱节。初学进度：手纺锤一天纺出 50～100 g 量级的纱算正常（经验量级，待核验）。
- **断了怎么办**：断头两端各搓出毛尖，重叠搭接一掌长，继续加捻——接头天然偏粗，绕线时把接头留在不受拉的位置。

### 合股与纱线用途

- 单股纱有致命弱点（同 [绳索与绳结](03_cordage_knots.md) 的单股绳）：一端松开，全线退捻散架。**合股**：把两根已右捻的单股纱并排，向**左**（反向）再合捻一次——合捻的外力顶住股内想回松的劲，两股越想松开缠得越紧，纱线自锁。
- **操作**：两根单股纱各绕成小纱球（或绕在两节小竹管上防乱），端头并齐结在纺锤导线环上；合股前先给两股各自补捻到"捏着明显发硬"（一股松一股紧，合出来必起疙瘩）；然后反向搓杆、引条合捻，两股绞成麻花。合格现象：纱身捻纹清晰，两手拉住两端提起，两股均匀绞紧无松股。
- **粗细与用途**：合股中粗纱（火柴棍粗）做缝线与织布经线；粗纱（引条喂到筷子粗）做毯子纬线与粗网；细纱（缝衣线粗）耗时数倍，留给衣料经纬——粗细完全由引条量控制：要粗多喂、要细少抽。

### 毛毡：不纺不织，直接成"布"

- **湿毡原理一句话**：碱水让羊毛鳞片张开竖起，热水让纤维膨胀软化，摩擦让定向排列的鳞片像倒刺一样互相单向咬死——纤维只能挤紧不能退回，最后缩成一块拆不开的实心布（检索核实，见文末来源）。
- **做一块毡片（巴掌大到一臂见方皆可）**：
  1. **铺毛**：在草席或竹帘上薄铺第一层毛絮（纤维朝同一方向），第二层与第一层**垂直**铺放，如此交叉铺 3～4 层；每层薄到能隐约透出下层轮廓。毡化后四边会缩进两成以上（幅度待核验），铺的时候四边先放大一圈。
  2. **浇水加碱**：浇热皂水（同洗毛口径：热、摸着滑腻）把全部毛层浇透，用手指从中心向四周推压**排出气泡**——气泡隔着的地方毡不到。
  3. **揉压**：先隔一块薄布用手掌根**画圈揉压**（先轻后重，防止毛层被水冲乱），每处揉到手指感觉毛层互相咬住、提起一角整片跟着走（一刻钟量级）；揭布后直接揉，再加重。
  4. **卷滚**：连席把毡坯卷成卷，两端捆住，在案上**来回滚压**（一次滚 50 个来回，开卷换 90 度方向再滚）——滚压就是把摩擦交给重量。
  5. **判断毡化完成**：捏住毡片一角向斜上方撕拉，**拉不出分层毛、角部紧实** = 完成；还能撕下一层毛 = 回去继续揉滚。完成的毡片明显变厚变硬、四边收缩起皱。
- **毡制品**：毡帽——找一只大小合适的葫芦、木碗或篮子当模，湿毡坯罩在模上揉压贴合成形，阴干脱模；毡靴——毡片按脚型围缝成靴筒（缝法见 [缝纫与原始衣物](17_sewing_clothing.md)），干冷区保暖第一，忌水需外罩皮套；垫——坐垫睡垫，最简单，第一块练手就从坐垫起步。

### 蚕丝：远期路线一句话

桑蚕茧在热水中可缫出连续长丝（一根茧丝可达数百米量级，待核验），无需纺捻直接织绸——但需要养蚕（桑叶供给、世代繁育）与缫丝工艺，属阶段 3 以后的远期路线，本文不展开。

## 从零实现路径

依赖链：**先有刀（割毛、制梳、制锤轮）→ 有火与容器（烧热水洗毛，容器见 [陶器制作](06_pottery.md)、火见 [摩擦取火与火种管理](../01_energy/01_fire_making.md)）→ 有梳（理条）→ 有纺锤 → 才有纱；有纱才有织物与毡制品**。

1. **毛的获得**：无畜群期靠换毛季拾取与皮张抓毛（猎物获取见 [采集渔猎入门](../03_food/05_foraging_hunting.md)、剥皮见 [鞣制皮革](05_tanning_basics.md)）；有畜群后按剪毛周期取毛（畜养见 [小型养殖基础](../08_production/07_small_livestock.md)）。
2. **洗**：草木灰清液或皂 + 恒定热水，静泡按压，同温漂洗，托压晾干。
3. **梳**：骨板手梳或刺果，把净毛理成顺向毛条。
4. **纺**：纺锤（总重 25～35 g）搓捻—引条—加捻—绕线，纺出单股纱，每段过吊锤测试。
5. **合股**：两股反向合捻成自锁纱线；细纱备缝线，粗纱备织毯。
6. **织或毡**：织布去 [织机与织布](15_loom_weaving.md)（同批新篇）；做毡按上文五步，第一件成品建议是坐垫。

## 方法与应用（应急视角）

现代条件下的对应：市售洗净毛条可跳过洗毛段，用商用或自制纺锤练纺纱；湿毡在家庭手作中常见（羊毛 + 皂水 + 气泡膜滚压），本文的揉压与滚压参数直接适用；洗毛的两条铁律（同温、免搅动）同样适用于处理现代原毛。理解"鳞片 + 碱 + 摩擦 + 温度"之后，还能解释并预防一切羊毛织物的缩水事故——热水洗毛衣不毡，洗衣机搅它才毡。

## 常见错误与限制

- **洗毛时图快用手搅动**：为什么错——搅动就是摩擦，皂水里一搅当场毡化；后果——整批毛结成硬块，只能降级做毡垫，纺纱报废；正确做法——只按压浸没、静泡，捞取时双手托底捧起。
- **漂洗水比洗毛水凉**：为什么错——骤冷让张开的鳞片骤然咬合（温度骤变是毡化主因之一）；后果——出池即毡，前功尽弃；正确做法——漂洗水与洗毛水同温，摸着热度一致再下毛。
- **跳过梳理直接纺乱毛**：为什么错——乱纤维捻度吃不进、短毛混在纱里成弱节；后果——纱粗节不断，织出的布坑洼；正确做法——每撮毛过梳再上锤。
- **引条忽快忽慢**：为什么错——引条量决定粗细，抽速不稳则粗细不匀；后果——纱面串珠状鼓包，合股后疙瘩更大；正确做法——捻点上方保持连续锥形，锥形一断就停手补喂毛。
- **捻度不足就收纱**：为什么错——纱看着成了，一受力纤维滑脱；后果——绕上去的纱一碰就散，全部返工；正确做法——每段收纱前做吊锤测试（能吊起纺锤不断才算数）。
- **碱泡过的毛纺细纱**：为什么错——碱损伤鳞片与皮质层，纤维发脆；后果——纱面起毛掉屑、强力下降；正确做法——碱退毛的毛只做毡垫，细纱只用皂洗的毛。
- **毡坯铺薄了**：为什么错——毡化靠层间咬合，层数不够则成品稀疏易裂；后果——毡片能撕开分层；正确做法——至少 3 层交叉铺，宁可多铺一层。
- **限制**：毛源依赖动物资源，无猎场无畜群时本篇全部工艺无从启动；湿毡只对带鳞片的毛有效（山羊绒可用，兔毛偏短需混毛，麻棉无效）；纺纱效率以"锤"计——量产纱线要等纺车（多锭机械，属阶段 4 主题，暂未编写）；文中温控与产量量级为通识与检索口径的混合，动手前见文末待核验项。
